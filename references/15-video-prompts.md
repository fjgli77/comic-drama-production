# 视频提示词：七段式、方言与词根清洗

这一篇是执行层最硬的一关。关键帧决定「长什么样」，视频提示词决定「动起来会不会崩」。

核心认知只有一句话：**视频模型按词找画面。** 它不读你的意图，它读你的词。

> ⚠ **七段式是「范式 A」的写法**，适用于支持分段与时间轴的模型
> （Seedance / H3 / 可灵 / 万相 / Vidu）。
> 如果你用的是 Veo / Runway / Luma 这类吃自然语言的模型，七段式会失效——
> 它的【】标记会被当成画面符号。**换范式看 `29-model-adapters.md`**，
> 那一篇讲五种范式怎么互转。

---

## 一、七段式

投喂稿用固定的七段结构。段名固定，顺序固定。

```
【画幅风格】→【场景资产】→【核心人物】→【站位声明】→【时间轴分镜】→【音效】→【强制禁止项】
```

| 段 | 写什么 | 不写什么 |
|---|---|---|
| **画幅风格** | 画幅比例、画风基底、光比与色板、美学短语 | 平台参数（移到框外） |
| **场景资产** | 场景锚点 `@SCN-`、关键道具 `@PRP-` | 场景里的普通陈设 |
| **核心人物** | 人物锚定、年龄锚、造型锚、在场标记 | 长篇人设 |
| **站位声明** | 每人的位置 + 依托物 + 朝向 + 姿态 + 手头事务 | 坐标、ASCII 图 |
| **时间轴分镜** | 逐镜的时间戳 + 景别机位运镜 + 可见动作 | 心理活动、比喻 |
| **音效** | 环境底声、动作音、人声、音乐 | 抽象「氛围音乐」 |
| **强制禁止项** | **只装负面清单**：画面/文字/音频三类瑕疵 | ⛔ 任何正向指令 |

### 【强制禁止项】最容易用错

模型把这一段当「规避清单」读。写进去的正向要求**既不被当禁令、也不被当执行指令**，两头不生效。

更糟的是：**被禁词根本身就是画面词。** 写「玉佩不发光」，模型看到「发光」两个字，玉佩就发光了。

所以这一段只能装三类：

| 合法内容 | 例 |
|---|---|
| 画面瑕疵 | 角色变形、多余手指、服装跳变、现代元素 |
| 文字 | 字幕、水印、Logo、UI 文字 |
| 音频 | 背景音乐（当你要纯环境音时） |

**正向要求去哪里**：动作→时间轴分镜；风格→画幅风格；站位→站位声明。

## 二、禁令失效：三改法

这是最有价值的实战经验，来自反复拉片。

**病根**：视频模型对否定不敏感、对词根敏感。被禁概念的词根留在提示词里（哪怕前面挂着「不」），就成了喂给模型的画面词。

### 改法一：换词（被禁词根零出现）

高关联视觉概念的字面词，**不许出现在提示词任何位置**（含禁止项）。

| 你想说 | ❌ 别写 | ✅ 写 |
|---|---|---|
| 玉不发光 | 不发光、不透光 | 玉面呈青玉原色，实心石质，哑光 |
| 不笑 | 面无笑意、不露齿 | 双唇抿紧，嘴角向下压，下颌绷紧 |
| 不要空镜开场 | 禁空镜开场 | 画面主体：她蜷在土炕上，一只手搭在破被外 |
| 不要有字幕 | 无字幕 | （这一条可以在禁止项写，因为模型本就不倾向生成） |

**判断标准**：这个概念是模型**倾向于生成**的吗？是 → 必须换词；不是 → 禁止项够用。

### 改法二：主体优先句式

每段第一个分句就是画面主体。

```
❌ 土炕上，房梁下，一只手搭在破被外
✅ 林清月蜷卧土炕，病容苍白。她的一只手搭在破被外
```

环境前置词开头会诱导模型渲染空场景。**镜 1 尤其致命**——它决定了整段的第一帧。

### 改法三：触发器移除

诱发被禁效果的动作/构图本身换掉。

- 「举向油灯冲光」是「透光自发光」的**构图触发器**（道具正对光源）；
- 「侧受光」实测仍会点火；
- 正解：**道具与光源彻底解耦**——只写材质本色，不写任何光效从句。

## 三、词根清洗：五遍扫描

投喂前逐层剥除五类词。剥完，正文只剩可见事实。

| 遍 | 剥什么 | 例 |
|---|---|---|
| 1 | **否定词** | 不要、没有、禁止、避免、毫无 |
| 2 | **元描述** | 镜头、画面、特写、构图、分镜、角度（写在镜行头之外时） |
| 3 | **抽象评价** | 压迫感、氛围、高级、电影感、张力、唯美 |
| 4 | **心理动词** | 意识到、想着、感到、明白、决定、犹豫 |
| 5 | **比喻与修辞** | 如钟、似箭、像刀、成线、成串、仿佛 |

### 第 5 遍最反直觉，也最容易翻车

**写「端坐主位如钟」→ 殿顶凭空挂下一口巨型青铜大钟。**

**写「三人列立呈金字塔」→ 地面长出三个人像桩子。**

**写「雨漏成线」→ 画面出现一条实体的线。**

AI 只渲染**可命名的具象形态**。「如钟」「成线」「似箭」这类词描述的是模型无法命名的过程形态，它只能找一个最接近的名词来画。

**判据一句话：这句里每个词都能画出来吗？画不出来的，就是修辞——删掉，或换成具象动作。**

| ❌ | ✅ |
|---|---|
| 雨漏成线砸在手背上 | 雨滴砸在手背上溅开 |
| 手指轻蜷 | （删掉，或写「五指收拢」） |
| 目光如刀 | 他盯着她，没有眨眼 |
| 怒气如潮 | 他呼吸变粗，鼻翼张开 |

### 抽象词的替代

| 抽象 | 具象化 |
|---|---|
| 压迫感 | 他坐着，所有人都站着 |
| 紧张 | 她的手指在桌下绞紧，喉结动了一下 |
| 冷 | 她把外套裹紧，呼出的气是白的 |
| 绝望 | 她看着那张纸，很久，然后把它折起来放进口袋 |

## 四、可生成性：四类高风险动作

不是所有动作视频模型都能做。四类高风险，见到就改：

| 类别 | 例 | 为什么难 |
|---|---|---|
| **精确拦截** | 两人同时争夺小物、用手挡住正在合上的物体、运动中截住某物 | 要求双主体时序与位置同时精确 |
| **不可见的内部状态** | 像是听见了什么、神色一凛、忽然明白过来 | 没有可见对应物 |
| **否定式动作** | 没有接话、没有按下去、不去看他 | 画面无法生成「未发生的事」 |
| **精细编排链** | 一拍内三步以上手部动作、左右手分工 | 多部位同时精确 |

### 五种改写

按顺序试：

| # | 方法 | 例 |
|---|---|---|
| 1 | **换承担者**（让物件/环境承担变化） | 「他用脚勾住门」→「门被风带上」 |
| 2 | **拆到相邻镜** | 「手掌挡住合上的笔记本边缘」→「他把笔记本合上」+「手按在盖子上没有移开」 |
| 3 | **换成停留** | 精细操作 → 「做完后手没有拿开」 |
| 4 | **交给声音** | 动作不可见时，由已声明声源承担 |
| 5 | **标注高风险与降级** | 确实不可替代时，写明风险与可接受的降级实现 |

### 直接可写的动作（安全区）

```
走进、坐下、起身、回头、点头、递物、接过、抱住、推门、放桌面、翻页、伸手去够、抬头、松手、转身
```

这些是日常影像里高频、整体、单部位可完成的动作。

## 五、动作量预算

**一镜一个主角动作 + 正文 ≤ 70 词（中文约 110 字）。**

超过会怎样：模型抓不住重点，随机挑一个动作渲染，其余丢弃。你写得越全，它丢得越多。

| 词数 | 结果 |
|---|---|
| < 35 词 | 太薄，模型自由发挥（加镜头、加空镜） |
| 35–70 词 | 最佳区间 |
| > 75 词 | 开始丢动作 |
| > 100 词 | 严重崩坏 |

超了怎么办：先删机位描述（那是镜行头的事），再删修饰词，最后拆镜。

## 六、站位声明：五要素

每段必写一行。它是**本段人物方位的唯一权威源**。

```text
【站位声明】：@沈惊歌（画面左 · 倚长桌沿 · 侧身 45° 朝右 · 站姿 · 手头事务：五指扣桌沿）、
@顾城（画面右 · 靠高背椅 · 正面朝左 · 坐姿 · 手头事务：转尾戒）；
轴线锁定：左沈右顾，全段禁越轴；位移：无
```

### 五要素

| 要素 | 写法 | 说明 |
|---|---|---|
| 位置 | 画面左 / 右 / 中 | 段首给一次 |
| 依托物 | 倚长桌沿 / 靠高背椅 | **比画面左右更可靠**，因为机位翻转时它不变 |
| 朝向 | 侧身 45° 朝右 | 相对朝向 |
| 姿态 | 站姿 / 坐姿 / 半蹲 | — |
| **手头事务** | 五指扣桌沿 / 转尾戒 | 2–6 字动词+宾语。**背景人物必填**，否则会僵尸化 |

### 单一方位权威（重要）

**站位声明定了「画面左」，镜行里就严禁再写绝对左右。**

段首写「画面左」，某镜又写「画面右后」——给模型一对矛盾指令，实测直接导致人物「东一个西一个、突然出现在身后」。

镜行只写两类方位信息：

1. **位移增量**（「向前半步」「退到窗边」）——相对段首席位的增量；
2. **依托物/空间锚**（「背靠卷帘门」）——钉空间不钉左右。

**能用依托物就不用画面左右。画面方位随镜头翻转，依托物不会。**

## 七、模型方言

不同模型的语法契约不同，**锁定后不许混写**。

> 完整规格、图像模型路由、迁移与降级见 `22-model-matrix.md`。本节只写「同一镜在不同模型上该怎么落笔」。

**方言只改「怎么说」，不改「说什么」。** 叙事层、镜头层、光影层换模型不用改，只有模型层（秒数、分辨率、引用语法、参考槽位、负面词表）必须改。

### Seedance 2.0

| 项 | 规格 |
|---|---|
| 单段上限 | 15 秒 |
| 参考图 | 9 图 + 3 视频 + 3 音频（合计 ≤12 项） |
| 首尾帧 | **不支持** |
| 运镜 | 每镜一条简单运镜，禁一镜多转折 |
| 打击感 | 无顿挫词，靠接触瞬间画面本身 |
| 蓄力 | 边打边蓄，禁静止蓄力段 |

### Seedance 2.5

| 项 | 规格 |
|---|---|
| 单段上限 | 30 秒（建议 25–30 吃满，下限 12） |
| 参考图 | 上限 **50 项**多模态，逐实体绑定 |
| 首尾帧 | 支持（与参考图组互斥） |
| 运镜 | 可写复杂连续运镜与转场 |
| 打击感 | 可有顿挫三件套（微停顿 + 火花 + 震颤声） |
| 参考模式 | 全能参考（默认）/ 首尾帧，二选一 |

**逐实体绑定公式**：「严格保持 X，只改变 Y」。

### MiniMax H3

| 项 | 规格 |
|---|---|
| 单段 | 4–15 秒 |
| 参考图 | ≤ 12 项 |
| **正文语言** | **必须英文**（只有台词与画内文字保留中文） |
| 台词标记 | `<d>[Chinese] …</d>`，必须带语言标签 |
| 模式 | T2VA 三字段 / I2VA 一图 / FL2VA 两图 / Ref2VA 多参考六段式 |

**H3 的六段式**：`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`（顺序固定）。

**H3 的三个专属铁律**：

1. **同框最多两人**，第二人禁写旁观动词（会触发图层复制，画出一个人的分身）；
2. **换画幅会崩段缝**，全片一个画幅，禁 `auto`；
3. **氛围六件套写在段首**，不占镜行字数。

## 八、段缝衔接

成片时长超过单段上限时，要拆段。段与段之间必须处理，否则必跳切。

模型每段零记忆——上一段的站位、姿态、互动在下一段全部归零。

### 四种方式

| 方式 | 做法 | 适用 | 代价 |
|---|---|---|---|
| **末帧定格承接**（默认） | 段末镜末 1 秒整秒写「全员保持姿态，画面定格」→ 截取末帧作下段首帧 | 跨组长动作、长对白跨组 | 丢 1 秒 + 需截帧 |
| **换机位硬切** | 段缝两侧直接换机位，做成两个镜头的剪辑关系 | 剧情分段 + 组内多机位 | 零成本，但要有剪辑逻辑支撑 |
| **空镜过渡** | 段缝插 1–2 秒带戏剧任务的空镜 | 情绪段、时空转场 | 单集 ≤3 处 |
| **技巧型转场** | 相似动作 / 形状匹配 / 前景遮挡 / 甩镜 / 闪白 | 有设计感的段落 | 单集 ≤3 处，同段不连用 |

### 分流口诀

```
跨组长动作 / 长对白跨组 → 末帧定格
剧情段划分（本来就要换场/换时间）→ 换机位硬切就够
```

**选硬切却写「末 1 秒定格」= 口径混用**，白丢 1 秒。

### 段末禁止写「接续说明」

不要写「下一段承接：xx 保持坐姿」这类文字。理由：

1. 它写在段尾，模型逐镜渲染时读不到；
2. 空镜结尾时它承接的不是人物，是死信息；
3. 跨段对齐的本质是**画面对齐**，交给末帧截图比交给文字可靠。

## 九、投喂稿自检

- [ ] 七段齐全，顺序正确？
- [ ] 【强制禁止项】只装负面清单，没有正向指令？
- [ ] 全稿没有「不发光」「面无笑意」这类裸否定（高关联概念已换词）？
- [ ] 没有「如钟」「成线」「似箭」这类比喻？
- [ ] 没有心理动词（意识到/感到/决定）？
- [ ] 没有「氛围感/电影感/高级感」这类空词？
- [ ] 站位声明五要素齐全，背景人物有「手头事务」？
- [ ] 镜行没有重复段首已声明的绝对左右？
- [ ] 每镜一个主角动作，正文 ≤70 词？
- [ ] 有一镜同时写了两件以上的事？（有就拆）
- [ ] 动作不在四类高风险区？（在就改写）
- [ ] 镜行头（景别机位运镜）与正文（可见事实）分区清楚？
- [ ] 时间戳递增且小于段时长？首镜无时间戳？
- [ ] 台词逐字与剧本一致？
- [ ] 方言参数正确（H3 正文英文、2.0 无首尾帧、画幅全片一致）？
- [ ] 素材形态声明写在首行？
- [ ] M1 形态附了《素材接线单》？

第 2、3、8、9 题是废片高发区。
