# 特效与粒子

特效是最容易写成一堆形容词、出来一杯水的地方。

写「顶级震撼的粒子特效」，出来是一团均匀慢速的半透明彩色雾。

这一篇讲**怎么把特效写成模型能算出来的物理事件**。

---

## 一、第一条：不要写「粒子」这两个字

**模型对「粒子」没有物理经验，对「铁屑」「火星」「碎纸」有。**

| ❌ 无效 | ✅ 有效 |
|---|---|
| 金色粒子特效 | 燃烧的铁屑洪流，密度如蜂群 |
| 蓝色粒子飘散 | 水晶碎屑逆流而上，细如糖霜 |
| 光效粒子环绕 | 火星贴着地面游走，触地即灭 |
| 神秘粒子 | 符纸碎屑在气流里打旋，边缘焦黑 |

**原理**：模型是在海量图像上训出来的。它见过「铁屑在砂轮上飞」，没见过「粒子」。写粒子，它只能给你一个通用的发光噪点贴图。

**可用的材质替代表**：

| 气质 | 材质 |
|---|---|
| 火 / 爆 | 火星、余烬、燃烧的铁屑、炭块、熔渣 |
| 冰 / 寒 | 霜晶、冰屑、水雾、白汽 |
| 雷 / 电 | 电弧、电晕、焦痕、跳动的蓝白丝 |
| 光 / 圣 | 光尘、金箔碎屑、羽毛、经文残片 |
| 暗 / 魔 | 黑烟、灰烬、墨滴、蠕动的丝 |
| 土 / 力 | 碎石、沙尘、泥点、木屑 |
| 水 | 水珠、飞沫、水线、涟漪 |

## 二、去水五律

写任何特效前，逐条过这五条。**这是分水岭。**

### 律一：禁评价词

```
❌ 顶级 / 神级 / 震撼 / 绝美 / 电影级 / 高动态范围 / 视觉冲击力强
```

模型不识别评价，这些词纯占字数，还会稀释真正的指令。

### 律二：禁裸光效

光柱、法阵、能量球、光束——**严禁只写一个名词**。

必须给**四件套**：

| # | 件 | 例 |
|---|---|---|
| ① **由什么构成** | 符文环 / 火流 / 铁屑 / 电弧 / 水线 |
| ② **边缘什么样** | 剥落 / 焦黑 / 白热光边 / 毛刺 / 半融 |
| ③ **怎么动** | 轮转 / 收束 / 分野 / 逆流 / 崩解 |
| ④ **密度层次** | 近实、中厚、远虚；核心密、边缘稀 |

```
❌ 一道金色光柱冲天而起
✅ 一道由旋转符文环构成的柱体自地面升起，外缘有剥落的金箔碎屑向外飘散，
   柱身近处实、远处虚，核心密到看不清结构，边缘稀到能看见背后的天
```

### 律三：禁写「粒子」（见第一节）

### 律四：必写方向与速度差

**全片一个速度 = 水。**

| 必须有 | 写法 |
|---|---|
| 高速项 | 带拖尾光迹，0.2 秒划出画面 |
| 中速项 | 随气流翻滚，方向不稳定 |
| 低速项 | 余烬带沉降弧线，触地即灭 |

**禁止「均匀漂浮」**——那是雾，不是特效。

**要写方向**：下落 / 逆流 / 贴地游走 / 向外炸开 / 向内坍缩 / 横向扫过。

### 律五：生长三段论

**没有压缩就没有重量感。这是水不水的分水岭。**

```
① 压缩（逆向收束）→ ② 爆发（核心破裂 + 冲击波环）→ ③ 余波（烟尘膨胀 + 余烬沉降）
```

| 段 | 必须写什么 | 常见错误 |
|---|---|---|
| **压缩** | 碎屑像磁吸铁屑向核心收拢；衣袂发丝被吸向能量场；空气开始扭曲 | 直接写"凝聚成球"——没有逆向感 |
| **爆发** | 核心出现第一道裂纹；冲击波以环状向外推；地面尘土被压成圆盘 | 只写"炸开"——没有扩散形态 |
| **余波** | 烟尘还在膨胀；余烬在沉降；人物衣角还在动 | 直接切下一镜——没有呼吸 |

## 三、配色：双色缠绕，不要单色涂抹

单一颜色的特效是"发光贴图"。**必须有主色 + 副色的高反差关系。**

| 气质 | 主色 + 副色 |
|---|---|
| 熔岩 / 烈阳 | 赤红 + 暗金 |
| 暗夜 / 魔道 | 玄黑 + 幽紫 |
| 霜雪 / 寒月 | 冰蓝 + 银白 |
| 太古道祖 / 东方修仙 | 苍青 + 鎏金 |
| 血煞 | 暗红 + 铁灰 |
| 圣光 | 暖白 + 淡金 |

### 缠绕怎么写

```
❌ 两色光柱互推
✅ 两股属性流旋拧交缠，螺旋加速，逐渐拧成一个完整的图案，
   图案边缘开始不稳定，过载到临界后整体炸散成漫天双色光屑
```

**「互推」是两条平行线，「缠绕」是螺旋。** 后者才有能量感。

## 四、特效的物理刻度

特效要像物理事件，就得给数值。

| 维度 | 写什么 | 例 |
|---|---|---|
| **尺寸** | 相对参照物 | 直径约三人高 / 覆盖半个院子 |
| **持续时间** | 秒 | 起势 0.8s，爆发 0.3s，余波 2s |
| **速度** | 相对参照 | 比箭快，能看到残影 / 缓慢如糖浆 |
| **密度** | 疏密描述 | 密到看不见背后的天 / 稀疏到能数清 |
| **衰减** | 怎么消失 | 由外向内熄灭 / 被风吹散 / 沉入地面 |

**不用写具体焦耳数。** 写"覆盖半个院子"比"直径 8 米"更好——模型对前者有经验。

## 五、大招的三段式（15 秒）

玄幻、仙侠、热血番的大招，有固定节奏。

```
0–3s    蓄力      微距 + 极速环绕拉升
3–8s    展开      全景拉远 + 空间扭曲
8–15s   爆发      巨物成型 + 冲击波定格
```

### 蓄力：边动边蓄，不许静止

**这是最常被写错的一段。**

```
❌ 他悬在空中，双手结印，能量在掌心凝聚
✅ 他悬在空中，手腕猛旋，衣袂被气流扯得向后翻卷，
   碎屑从地面向上倒流，在他掌心外侧半尺处开始打转，
   越转越密，最后拧成一个拳头大的实心点
```

**关键三件事**：身体在动（旋腕/踏步/上升中）、环境在响应（衣袂/碎屑/空气）、能量有形态（打转→拧紧→实心）。

### 展开：空间要扭曲

法阵、领域、异象——不能只是"地上出现一个圈"。

```
亿万道符文自他背后向外泼洒，铺满整片夜空，符文之间连出细线，
空间在阵法边缘开始弯折，远处的山形被拉长、错位
```

**「空间弯折」是最高级的写法**：让背景变形，而不是加一个发光层。

### 爆发：给冲击波，不给爆炸云

```
❌ 轰的一声炸开，火光冲天
✅ 核心先裂开一道缝，光从缝里漏出来；
   0.2 秒后整个核心向内塌陷了一下，然后向外推开一个环；
   环扫过地面时把尘土压成一张贴地的圆盘，圆盘边缘翻卷着追出去
```

**「向内塌陷一下再推开」** 是爆炸的真实节奏——先吸后放。

### 收尾：能量吞屏切黑

绝杀命中后，不要直接跳平静全景。

```
① 命中爆闪（吞屏白 / 属性色）—— 0.1–0.2s
② 纯黑 —— 0.3–0.5s
③ 余响渐起（碎石滚落 / 风声 / 耳鸣）
```

**给观众"重击消化时间"。** 这是节奏，不是特效。

## 六、常见特效类型速查

| 类型 | 关键写法 | 别写 |
|---|---|---|
| **能量球 / 弹** | 表面有翻滚的流体纹；飞行时拖尾逐渐变细变淡 | 一个光滑的发光球 |
| **光柱 / 光束** | 有体积、有边缘剥落、穿过介质时照亮尘埃 | 一根白线 |
| **法阵** | 分层：外环轮转 / 中环符文流动 / 内核脉动 | 一个平的发光图案 |
| **护盾** | 受击处出现蛛网裂纹，裂纹里透光，整片盾随之波动 | 一个半透明球 |
| **火焰** | 分三层：焰心白 / 中焰橙 / 外焰红黑；有向上的速度差 | 一片橙色 |
| **烟 / 雾** | 分前后层，前层快、后层慢；被光穿过时可见光锥 | 一块灰 |
| **碎裂** | 先出现裂纹路径，再按裂纹分块飞出，块有大小和转速差 | 整体炸成粉末 |
| **水** | 有表面张力（水珠成球）、有飞溅方向、落地有涟漪 | 一片透明蓝 |
| **残影 / 高速** | 主体清晰，残影是半透明的拖尾，数量 2–3 个 | 主体也糊 |
| **领域 / 结界** | 边界可见（像水面/玻璃），内部物体有轻微变形 | 一个圆 |

## 七、特效与镜头的配合

| 镜头 | 特效该怎么写 |
|---|---|
| **特写** | 只写局部：火星掠过瞳孔、碎屑划过脸颊、睫毛上的水珠 |
| **近景** | 特效是背景层，人物是主体；特效不许盖住脸 |
| **中景** | 特效可占画面 1/3，看得出形态 |
| **全景** | 特效是环境，要写它与地面的关系（压出的圆盘、烧焦的痕迹） |
| **俯拍** | 这是特效最好看的机位——能看清扩散的形状 |

**一个铁律**：**特效不许盖住人物识别点**（脸、眼睛、关键持物）。写「光从她脸侧掠过，不遮住眼睛」。

## 八、单张静图的特效

前七节全部假设有时间。**静图没有时间。**

这条不能混：静图照抄视频写法，出来是一张「雾里有个亮点」的壁纸。
静图的特效靠的是**力的痕迹**，不是速度与节奏。

### 三条腿

| 腿 | 是什么 | 怎么写 |
|---|---|---|
| **中间态** | 一个物理过程停在半路 | 墨浸爬到四指、水滴将落未落、丝断到一半、字写到一半 |
| **空间分层** | 近 / 中 / 远三层，密度与虚实不同 | 近层虚焦、中层实、远层稀 |
| **接触关系** | 特效与人物、地面、衣料的交界处必须画清 | 布被顶起、地面被压出痕、发丝被拉弯 |

三条腿缺一条，图就是贴图。

### 视频写法 → 静图改写对照

| 视频里这么写 | 静图必须换成 |
|---|---|
| 高速项 / 中速项 / 低速项 | **形态差**：被拉长绷直的丝、悬停的珠、卷成筒的片，同屏并存 |
| 三段论（压缩→爆发→余波） | **中间态**：只画正在发生的那一帧，例如核心刚裂开一道缝 |
| 持续 2 秒 | **已发生多久的痕迹**：墨爬上四指，说明已经爬了一阵 |
| 衰减方式（熄灭/吹散/沉入） | **边缘衰减带**：墨汽、干边、焦边、由湿亮到哑光的过渡 |
| 速度与方向 | 方向仍要写，但靠**形变**表达（丝被拉向哪侧、布往哪边翻），不靠速度 |

**静图里唯一能表达「正在进行」的，是把过程切开停在中间。** 画完成态就是死的。

### 三个可复用的「未完成」母题

任何题材通用，写在任何一张关键帧上都成立：

| 母题 | 例 |
|---|---|
| **将落未落** | 墨滴悬在笔尖下一寸、刀锋停在离颈一指、露水挂在叶尖 |
| **写到一半** | 字未闭合、阵未画满、裂缝只延伸了一半、符纸烧到中段 |
| **刚刚断裂** | 丝断成两截还在弹回、弦崩断、冰面裂开但未塌、石缝刚张开 |

### 景深是静图独有的分层手段

视频靠运动模糊分层，静图只能靠景深。**必须写明哪层虚、虚多少**：

```
前景一道墨丝横过画面下缘，虚焦；
人物与身前的墨珠实，焦点在右眼；
背后纸灰在焦外，糊成一片有方向的灰。
```

少这一句，四层特效会挤在同一个焦平面上，变成一张噪点图。

### 一张图只有一个视觉中心

分层是**层**，不是四个主角。必须指定哪一层是主：

```
视觉中心：右手背与指尖的墨珠（最清晰、对比最强）；
墨丝是第二层，笔画碎片是第三层，纸灰只是背景纹理。
```

不指定，模型会把四层平均分配，画面散掉。

### 静图四点测试

写完逐条问，答不上就还是贴图：

- [ ] 画面里有「力」吗？（被顶起的布 / 被拉长的丝 / 被压出的痕 / 将落未落的珠）
- [ ] 三层有没有密度差与虚实差？
- [ ] 焦点落在哪一点，写了吗？
- [ ] 特效与人物、地面、衣料的**接触处**画清了吗？

## 九、服装特效

**服装特效是最便宜的法力。** 不用做 CG 大场面，一件袍子就能说明这个人有法力，
而且它跟着人物走，不占额外镜头。

机制与写法在 `06-costume-assets.md` 第九字段，这一节讲**怎么在分镜与主图里用它**。

### 布料受力的物理清单（照这个写，不要写「衣袂飘飘」）

| 力 | 布的反应 |
|---|---|
| **向上气流** | 下摆外翻、袖口鼓起、衣角上扬、系带向上抛 |
| **向心吸力** | 布料贴向身体、下摆向内收、缝线绷紧、扣件被拉直 |
| **横向风** | 迎风一侧贴身、背风一侧鼓起、所有褶皱朝同一方向 |
| **冲击波** | 整片布向外推、扣件先崩、缝线先裂、边缘先起毛 |
| **高温** | 边缘先向内卷、颜色由外向内加深、纤维末端球化成小珠 |
| **极寒** | 布面变硬、褶皱变直、边缘结霜成针、动起来有折纸声 |
| **湿透** | 贴身、颜色深两级、下摆加重下垂、走时甩出水线 |

**「衣袂飘飘」是四个字，上表是十几种可画的物理结果。**

### 三个使用时机

| 时机 | 服装特效怎么动 |
|---|---|
| **起势** | 符纹自领口向下逐组浮离；下摆墨浸开始向上爬；袖口布条末端散丝 |
| **承力** | 布料被吸向能量核心、贴住身体、缝线绷紧；这一帧是全片布料最"紧"的一帧 |
| **余波** | 浮离的符纹逐组落回布面；散丝回落；墨浸退回下摆；布面留下新的褶皱 |

**起势与余波必须成对出现。** 只起不落，观众会觉得特效是贴纸；
一落，这件衣服就有了重量。

### 三条纪律

1. **跟着招式走，不跟着时间走。** 出招那一帧布被撕开，收招那一帧布才回落。
   按秒数平均分配布料运动，看起来像在吹风机前面站着。
2. **一集只允许升级一次。** 整集都在浮离发光，最后一击就没有重量了。
   常态贴身 → 起势浮离 → 承力绷紧 → 余波回落，这是完整的一次呼吸。
3. **不许改轮廓。** 服装特效只改变布的形态、颜色、粗糙度，
   不许长出飘带、披风、光翼——那会让三视图与锁面全部失效。

### 主图里怎么用

主图是传播物料，可以用服装特效的**最强状态**（浮离 + 浸染 + 散丝同时出现），
但必须满足两条：

- 特效不遮住识别点（脸、眼、手背的纹、关键持物）
- 至少有一处停在中间态（符纹浮离到一半、墨浸爬到四指），让图"还在动"

## 十、特效自检

- [ ] 全篇没有出现「粒子」二字？
- [ ] 没有「震撼/顶级/电影级」这类评价词？
- [ ] 每个光效都有四件套（构成+边缘+运动+密度）？
- [ ] 有高速项和低速项的速度差？
- [ ] 写了方向（下落/逆流/贴地/炸开/坍缩）？
- [ ] 走了三段论（压缩→爆发→余波），压缩段有逆向收束？
- [ ] 配色是主色 + 副色，不是单色？
- [ ] 给了尺寸参照（相对人物/建筑）？
- [ ] 写了衰减方式？
- [ ] 特效没有盖住人物识别点？
- [ ] 绝杀后有吞屏切黑或等效的节奏处理？

**静图另加四条**（详见第八节）：

- [ ] 有一处停在中间态（爬到一半 / 将落未落 / 刚断裂）？
- [ ] 写了哪层虚、虚多少、焦点在哪一点？
- [ ] 指定了唯一的视觉中心层？
- [ ] 特效与人物、地面、衣料的接触处写清了吗？

**服装特效另加三条**（详见第九节）：

- [ ] 起势与余波成对出现，不是只起不落？
- [ ] 布的反应写的是物理结果（贴住 / 绷紧 / 外翻 / 卷边），不是「飘飘」？
- [ ] 没有改变服装轮廓（无飘带、披风、光翼）？

第 1、3、6 题决定出来是不是水。

## 附：一句话对照

| 写完自检 | 如果答不上来 |
|---|---|
| 这个特效**由什么材质**构成？ | 回去换材质名词 |
| 它**从哪来、往哪去**？ | 补方向 |
| 它**快到什么程度**？ | 补速度差 |
| 它**怎么消失**？ | 补衰减 |
| 它**看起来有多重**？ | 补压缩段 |
| （静图）它**停在哪一步**？ | 补中间态 |
| （服装）它**跟着哪一招在动**？ | 补招式对应 |
