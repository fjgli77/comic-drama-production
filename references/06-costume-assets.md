# 服装资产：设定板与演进表

服装在漫剧里承担三件事：**识别、身份、状态**。

- **识别**：观众一眼认出这是谁（靠轮廓、配色、标志物）
- **身份**：阶层、职业、时代（靠材质、工艺、版型）
- **状态**：这一刻他过得怎么样（靠磨损、干净程度、合不合身）

这一篇解决：怎么把一套衣服写成能拆解、能复用、能跨集演进的资产。

---

## 一、第一原则：服装板是「拆解」不是「设计」

**参考图是唯一标准。** 服装设定板的职责是把已经存在的设计信息**整理、展开、放大、标注**，不是重新设计一套更好看的。

这条纪律几乎是反直觉的——人看到一张图，本能想"给它加点什么"。但服装板一旦开始"优化"，下游全部崩：你按 A 出图，参考图是 B，模型两边拉扯，出来是 C。

### 「无此结构」原则

**参考图没有的，就写「无」。**

```markdown
- 披风：无此结构
- 护甲：无此结构
- 刺绣：无此工艺
- 下装：仅裤子，无裙装
```

**为什么必须明写**：不写，模型会按"服装设定板"的先验自动补齐——给平民加披风、给文官加护甲、给素衣加刺绣。写上「无」，它才知道这块该空。

### 禁止清单

| 禁止 | 后果 |
|---|---|
| 改轮廓、长度、松紧、层数 | 变成另一套衣服 |
| 改领口、袖口、门襟、腰封、开衩 | 结构崩 |
| 增删披风/护甲/口袋/挂件/扣件 | 身份信息错 |
| 把布改成皮革、金属、丝绸 | 阶层信息错 |
| 改纹样题材、位置、密度 | 阵营信息错 |
| 把历史服饰改成现代时装 | 时代错 |
| "升级版""战斗版""华丽版" | 观众不认识了 |

**最后一条最容易犯**：觉得"这一集是高潮，服装该升级一下"。不行。要升级就**新建一个造型条目**，走换装流程，不是在同一套上改。

## 二、服装要写什么

### 八字段（硬性，无内容写「无」）

| # | 字段 | 写什么 | 反例 |
|---|---|---|---|
| ① | 整体类型 | 交领右衽长袍 + 内搭中衣 | 「古装」 |
| ② | 颜色体系 | 主色灰青，辅色土黄，袖口深褐镶边 | 「深色系」 |
| ③ | 面料材质 | 粗麻布，质地粗糙，多处磨损起毛 | 「布料」 |
| ④ | 纹样图案 | 素面无纹，仅领口有简单回纹镶边 | 「有花纹」 |
| ⑤ | 结构细节 | 交领右衽，宽袖口，腰间系粗麻绳腰带，衣摆及踝 | 「传统样式」 |
| ⑥ | 服装状态 | 多处补丁，肘部膝盖磨破，衣摆沾泥渍 | 「有点旧」 |
| ⑦ | 鞋袜 | 黑色粗布鞋，鞋面磨损露白，无袜 | 「穿鞋」 |
| ⑧ | 专属配饰 | 头顶破毡帽，颈间围脏灰布巾 | 「有些配饰」 |

### 为什么必须这么细

因为服装是**唯一能同时表达阶层、职业、时代、状态**的资产。

| 你想表达 | 靠什么写 |
|---|---|
| 穷 | 补丁位置、磨损集中处、染色不匀、缝线粗糙 |
| 贵 | 面料垂坠、纹样对称、滚边宽度一致、扣件工艺 |
| 武将 | 护腕磨损、肩部加厚、靴面刮痕 |
| 水上讨生活 | 衣摆盐霜、袖口潮痕、皮肤晒痕 |
| 文职 | 袖口与领缘洁净、随身文具磨出的痕迹 |
| 刚打完 | 汗湿区域、尘土附着位置、衣角撕裂 |

**不要用"高级感""质感"表达身份。** 用「滚边宽度一致」「染色稳定」这种可测的东西。

---

### 第九字段：服装特效（仅玄幻 / 仙侠 / 科幻 / 异能题材）

写实古装与现代题材写「无」。

**玄幻题材不写这一项，模型会自己补发光**——而且补出来的每次都不一样，比写错更难修。

#### 六种机制，按出图稳定性排序

| 机制 | 写法 | 稳定性 | 为什么 |
|---|---|---|---|
| **织入** | 经线密度变化形成凸浮织纹，只在斜光下浮出 | ★★★ | 不靠光源，靠法线，3D 必出 |
| **附着** | 墨 / 霜 / 灰 / 血 / 盐霜附着布面，改变粗糙度与颜色 | ★★★ | 有实体，边界自然 |
| **浸染** | 颜色沿纤维爬升，前沿呈锯齿状，布面被顶起变硬 | ★★☆ | 要写「停在半路」才有正在进行感 |
| **抽丝** | 布条 / 线头末端散成丝，被气流拉向一侧 | ★★☆ | 顺带给出风向与风力 |
| **浮离** | 纹样离开布面约一指，产生缝隙与投影 | ★★☆ | 3D 独有的证明，静图容易糊成一团 |
| **自发光** | 纹路亮起来 | ★☆☆ | 掉进页游广告，且跨镜极难一致 |

#### 铁律三条

1. **不许改变轮廓。** 特效不能变成披风、翅膀、拖尾、飘带。
   轮廓是三视图派生与 R2 锁面对齐的依据，轮廓一变，所有的跨镜一致性全部作废。
2. **必须有布做载体。** 写不出「长在布面 / 线头 / 接缝 / 磨损处」的特效，就是还没想清，
   交给模型只会得到一层贴图。
3. **资产图只写常态版本。** 爆发、流转、吞噬、燃烧这些动态形态留给分镜关键帧。
   资产是参考图，越花哨越污染后续镜头——**参考图加一次光，后面十镜都得跟着加**。

#### 必须写「可关断」

```
此为常态状态：未施法时符纹完全贴合布面，仅斜光下可见；
施法时浮离布面约一指，纹样位置不变。
```

一句话解决「参考图与成片不一致」的扯皮，也让后续镜头知道该取哪个版本。

#### 反漂移写成正向锁定

| ❌ 禁止清单 | ✅ 正向锁定 |
|---|---|
| 袍面不要发光 | 袍面亮度不因纹样改变：纹样只靠布面颜色加深一级与法线起伏表现 |
| 不要刺绣 | 纹样为织入的凸浮织纹，不用丝线缝缀，边缘与布面齐平 |
| 不要贴片 | 纹样与布面同材质、同磨损、同褶皱走向 |

**禁止清单里每多一个名词，模型就多一个可以画的词。** 详见 `11-vfx-and-particles.md` 第九节。

## 三、部件拆解

服装板要拆到这八项，**只拆参考图里有的**：

| 部件 | 拆什么 |
|---|---|
| **整体** | 叠穿顺序、轮廓、主次色关系、身份指向 |
| **上衣** | 领型、肩线、袖型、门襟、收省、拼接、衣摆、闭合方式 |
| **下装** | 腰头、褶量、裤线或裙褶、开衩、收口、活动余量 |
| **披风** | 领部固定点、肩部覆盖、长度、开口、垂坠、内外层材质 |
| **鞋** | 鞋面、鞋头、鞋帮、鞋底、鞋跟、系带或扣合 |
| **腰带** | 带身、扣具、孔位、压边、挂点、层叠顺序 |
| **护甲** | 甲片分区、重叠方向、活动关节、固定带、铆钉或系结 |
| **配件** | 扣件、挂件、护腕、手套、首饰、包袋、功能附件 |

### 下装不要自作主张

参考图是裤子，就只拆裤子，**不要顺便设计一条裙子**。
参考图是裙子，同理。

这是「无此结构」原则在部件层的应用。

## 四、图案与工艺

| 项 | 拆什么 |
|---|---|
| **纹样** | 放大单元、重复规律、方向、边界、在服装上的准确位置 |
| **刺绣** | 针脚方向、线材粗细、色线层次、起伏厚度、边缘收针 |
| **面料** | 每种主要面料独立样片：纤维类型、织法、纹理、厚薄、软硬、垂坠、粗糙度、光泽、透光 |
| **缝线** | 针距感、单双线、压线位置、包边、锁边、拼缝、加固点 |
| **工艺** | 裁片拼接、褶裥、压褶、包边、滚边、铆接、系结、扣合、染色、印花、旧化 |

**不确定的写「待确认」，不要编。** 看不清是平绣还是盘绣，就写「刺绣工艺待确认」——编一个错的，下游全跟着错。

## 五、颜色：用中文名，不用色值

```markdown
- 主色：靛青（中明度、中饱和）
- 辅色：土黄（低明度、低饱和）
- 点缀：暗银（中明度、低饱和，带金属反射）
```

**不要写 `#2F4D7A`。** 模型对十六进制没有稳定理解，对"靛青"有。

颜色必须来自参考图，不许"调成另一套更好看的配色"。

## 六、标准版式

服装板用**横向大画布、纯白背景**：

```
┌──────────────────────────────────────────────────┐
│  正面全身   侧面全身   背面全身        │ 部件拆解  │
│  （等高，脚底对齐同一基线）            │ 上衣      │
│                                        │ 下装      │
│                                        │ 腰带      │
│                                        │ 鞋        │
│────────────────────────────────────────│ 配件      │
│  局部放大：闭合结构 / 纹样 / 缝线 / 配件 │ 材质样片 ×N│
│────────────────────────────────────────│ 颜色样片  │
└──────────────────────────────────────────────────┘
```

### 三视图的硬要求

| 视图 | 要求 |
|---|---|
| **正面** | 头顶至鞋底完整，服装中心线垂直，双臂自然下垂略离躯干，手不遮腰带 |
| **侧面** | 标准侧视，**不是把正面压扁**，要呈现厚度、前后落差、肩部结构 |
| **背面** | 后领、肩背接缝、背部闭合、腰后结构、披风固定点、鞋跟、背面纹样 |

**三格等高、脚底对齐同一基线、人物尺度一致。**

### 侧面视图最容易糊弄

把正面图水平压扁 = 侧面。这条要明确禁止——那会丢掉所有厚度信息，模型下次出侧面就不知道衣服有多厚。

### 光照

均匀柔和的影棚主光 + 克制的接触阴影。**忠实呈现颜色和材质**，不要打戏剧光。

服装板是给人做参考的，不是海报。

## 七、跨集服装演进表

**这是漫剧特有的、比单张服装板更重要的东西。**

一集一套衣服的做法在多集连载里会崩：第 3 集她穿灰衬衫，第 17 集变粉的，观众会说"这剧做得糙"。

### 服装规划表

在立项时就把全季服装排出来：

```markdown
| 造型 | 适用区间 | 场合 | 变化原因 | 相对上一套改什么 |
|---|---|---|---|---|
| 沈惊歌-破产日 | EP001-SC001～EP001-SC005 | 被清算 | — | 基准 |
| 沈惊歌-复起 | EP002-SC001 起 | 董事会对峙 | 取回部分资产 | 换西装套裙；摘素圈留戒痕 |
| 沈惊歌-守夜 | EP004-SC007 起 | 父亲忌日 | 私下场合 | 换回旧衬衫；不戴手表 |
```

### 换装时锁什么、改什么

**锁死（跨造型不变）**：

```
脸型骨相 / 五官比例 / 肤色 / 发际线与发型结构 /
头身比 / 肩宽 / 腰线 / 四肢比例 / 身高
```

**可以改**：

```
服装全套 / 配饰 / 妆容 / 发型整理方式（不剪不染）
```

### 配饰变化是叙事

最有力的服装信息不在衣服上，在**配饰的有无**。

EP001 她左手无名指有一枚素圈（已褪色）。EP002 起**素圈没了，只留一圈极浅的戒痕**。

一句台词都不用写，观众知道发生了什么。

**所以配饰必须单独写一行**，而且每次换装都要交代它的去向。


## 九、常见错误

| 症状 | 病根 | 修法 |
|---|---|---|
| 服装板像"新设计" | 把它当设计任务做了 | 回到参考图，只整理不创作 |
| 给平民加了披风 | 没写「无此结构」 | 逐项写「无」，尤其是披风/护甲/刺绣 |
| 侧面是正面压扁的 | 没要求真实侧视 | 明确写「呈现厚度与前后落差，不得镜像或压扁」 |
| 颜色比参考图好看 | 擅自调色 | 颜色必须来自参考图 |
| 三格不是同一个人 | 没锁身份 | 补「同一人物、同一尺度、脚底对齐基线」 |
| 标签乱码 | 要求中文标注且字多 | 短句 + 引导线；仍乱码就降级为编号 + 对照表 |
| 跨集衣服变了 | 没有服装演进表 | 立项时排表，换装走模板 |

## 十、服装自检

- [ ] 是拆解参考图，不是重新设计？
- [ ] 参考图没有的部件都写了「无此结构」？
- [ ] 八字段都填了，没留空？
- [ ] 下装只拆了实际存在的类型，没有额外设计？
- [ ] 纹样/刺绣/面料/缝线/工艺五项都拆了，不确定的标了「待确认」？
- [ ] 颜色用中文名 + 明度饱和度，没用十六进制？
- [ ] 三视图等高、脚底对齐、侧面不是压扁的？
- [ ] 背面写了滚边腰带的连续对齐？
- [ ] 全季有服装演进表，每套标了适用区间与变化原因？
- [ ] 换装时锁了脸与比例，只改衣服配饰？
- [ ] 配饰的去向写清楚了？
- [ ] 用影棚柔光，没有打戏剧光？

第 1、2、9 题决定这套东西能不能用。
