# 场景资产：母版、九宫格与视图

场景资产要解决的不是"画得好看"，是**让第 3 镜和第 27 镜里的同一个房间是同一个房间**。

它比人物资产更容易出错——因为空间有方位，而方位会随镜头翻转。

---

## 一、先分两件事：地点与视图

**这是最容易搞混的地方。**

| | 地点 | 视图 |
|---|---|---|
| **是什么** | 空间身份：可行走地理、分区关系、出入口、不可移动的锚点、主要材料与尺度 | 可复用的观察方向 + 生产状态 |
| **例子** | 顾氏总裁办：南向落地窗在东，长桌居中，门在北墙偏左 | 「北向夜间」：从南侧朝门看，窗在画面右后 |
| **会变吗** | 不变（除非剧本说换了地方） | 会变（换时段、换天气、换光态、换观察方向） |

### 为什么必须分开

同一间值班室，白天和停电后是两个**视图**，但仍是同一个**地点**。

如果拆成两个地点，模型会以为是两间屋子，跨镜时空间错位。

反过来，如果一间大屋子的「候船厅」和「值班室」有各自独立的门和动线，那是**两个地点**，必须分建，并注明连接关系。

### 判断规则

| 分建两个地点 | 同一地点建两个视图 |
|---|---|
| 有独立地理、独立入口、独立固定锚点 | 只是换了光、时段、天气、机位朝向 |
| 例：候船厅 vs 值班室 | 例：停电前 vs 停电后 |

## 二、方位怎么写（反打不对调的关键）

**写方位用锚点的相对关系，不要写裸的"左侧"。**

| ❌ 会翻车 | ✅ 稳定 |
|---|---|
| 左侧一扇大窗 | 窗在书柜墙靠门一端 |
| 左后角有扇门 | 北门通走廊，门正对办公桌 |
| 右边一张桌子 | 柜台平行于窗，离窗约一米 |

**为什么**：摄影机一转到对面，"左侧"就变成"右侧"，模型按字面执行，空间直接镜像。

**什么时候可以用画面左右**：只有**视图**里写明了观察位置与朝向时，才能在该视图内用画面左右。

### 固定物必须写高度

人会靠、撑、坐的东西，**写出高度和落在人身上的位置**：

```
柜台约 90 厘米高，台面齐成年人腰带
```

不写高度，各镜的台面会落在人身上不同位置——这一镜齐腰，下一镜齐胸。

---

## 三、两层产出：母版 + 九宫格

每个场景要出**两张图**，各管一件事，不能互相替代。

| 顺序 | 产出 | 管什么 | 有人吗 | 画幅 |
|---|---|---|---|---|
| **①** | **母版**（空镜） | 长相与空间锚点，连续性基准件 | **无人** | 16:9 横版 |
| **②** | **九宫格**（9 视角合集） | 机位与子区域，给分镜选角度用 | **禁止任何人影** | 整板 16:9 |
| ③ | 机位调度版 / 战斗站位版 | 复杂场景的调度与轴线 | 武戏必带人物 | 16:9 |

**为什么母版在前**：母版是"这间屋子长什么样"的唯一真相。九宫格是从母版派生的 9 个观察方向，不能反过来。

---

## 四、九宫格：一张图 9 个视角

### 为什么是九宫格

**它是对抗素材数量上限的手段。** 视频模型能吃进去的参考图有限（有的只收 9 张）。把 9 个视角压进一张图，**1 张图 = 1 个素材槽 = 9 个视角**。

理解这一点，遇到复杂场景才不会退化成"多出几张图、把素材槽撑爆"。

### 两种内容分配模式

| 模式 | 内容 | 适用 |
|---|---|---|
| **A 单场景多机位** | 9 格是同一场景的 9 个不同机位 | 一个大空间要拍很多角度 |
| **B 多子区域** | 把 N 个子区域分到 9 格，每个至少出现一次 | 一个大宅子有闺房/前院/书房 |

模式 B 下，子区域不足 9 个时，同一子区域可用不同机位占多格。

### 锁定模式必须分开写

**模式 A 和模式 B 的锁定段不一样，不能共用一段。**

| 模式 | 锁定段要点 |
|---|---|
| **A** | 完全相同的建筑、结构、比例、布局、景观、光照方向…… **仅允许摄影机移动** |
| **B** | 同上，但**允许按子区域切换机位**；同时必须写「各子区域的建筑形状、尺度、陈设必须与该子区域自身一致，禁止把 A 区的建筑搬到 B 区」 |

**为什么**：模式 B 要把室内和室外分进同一张图，"同一个空间的 9 个机位"物理上不成立。共用一段锁定，模型会强行把室内画成室外。

## 五、机位矩阵：按空间类型选表

**机位名必须与空间类型匹配。** 室内空间不许写"背面全景 / 高空鸟瞰"，自然场地不许写"正面近景 / 立面细节"。

### 表 ① 室外独立建筑（府邸 / 宫殿 / 楼阁 / 民居外观）

| 格 | 机位 | 说明 |
|---|---|---|
| 一左 | 正面全景 | 人眼高度主视角，完整展示建筑形态 |
| 一中 | 正面近景 | 镜头靠近主体，展示入口、中轴线与细节 |
| 一右 | 侧面全景 | 展示侧向体量关系，表现轮廓与纵深 |
| 二左 | 侧面近景 | 补充侧向细节，展示立面设计与结构层级 |
| 二中 | 背面全景 | 反向机位，展示背面结构与布局 |
| 二右 | 背面近景 | 展示背部细节，表现隐藏空间与装饰 |
| 三左 | 俯视全景 | 高空鸟瞰，展示整体规划与空间组织 |
| 三中 | 俯视近景 | 聚焦主体建筑群，展示屋顶结构 |
| 三右 | 环境交代景 | 远景氛围或局部空镜，补充场景叙事 |

### 表 ② 室内 / 半封闭空间（房间 / 牢房 / 山洞 / 船舱 / 廊道）

| 格 | 机位 | 说明 |
|---|---|---|
| 一左 | 进门视角 | 人眼高度从门向内看，交代整体空间 |
| 一中 | 主活动区全景 | 事件最密区域，交代核心陈设关系 |
| 一右 | 窗侧光位 | 靠窗一侧，交代自然光源落点 |
| 二左 | 门框反打 | 从内部回看入口，交代出入口与纵深 |
| 二中 | 俯视平面 | 高位俯拍，交代家具布局、动线与地面关系 |
| 二右 | 对角长焦压缩 | 从一角向对角压缩，交代纵深层次 |
| 三左 | 陈设特写 | 标志性家具/器物特写（带材质与使用状态） |
| 三中 | 墙侧细节 | 墙面/挂饰/破损/痕迹，交代年代感 |
| 三右 | 窗外或顶光空镜 | 窗景或顶部结构，交代时令与封闭感 |

### 表 ③ 自然场地 / 街巷 / 山路 / 树林 / 战场

| 格 | 机位 | 说明 |
|---|---|---|
| 一左 | 入口全景 | 从进入方向看，交代场地边界与主地貌 |
| 一中 | 主场地全景 | 事件核心区，交代地面材质与标志物 |
| 一右 | 反向全场 | 从另一头回望，交代反向空间关系 |
| 二左 | 侧向全景 | 沿地形走向，交代纵深与高差 |
| 二中 | 低位贴地视角 | 贴近地面，交代地面细节与动作落点 |
| 二右 | 高位俯瞰 | 树冠/坡顶/崖上俯视，交代地形拓扑 |
| 三左 | 地貌细节 | 标志物特写（巨石/断碑/枯树/车辙，带尺度参照） |
| 三中 | 通道或窄口 | 隘口/巷口/桥面，交代唯一动线与卡点 |
| 三右 | 天际与环境空镜 | 山势/街景/天光，交代时段与氛围 |

**跨空间类型时逐格换表。** 一张九宫格里既有室内又有室外，每格按该格所属子区域的类型取机位名。

## 六、光照：同地点同状态必须一致

**这是场景一致性最容易被忽略、后果最明显的一条。**

同一地点、同一时段/天气下的**所有观察视角，必须共享同一套光学事实**：

| 项 | 要求 |
|---|---|
| **主光来源** | 同一扇窗、同一组灯具、或同一片天空 |
| **色温主次** | 冷暖主次一致（不能一块板把台灯当主光，另一块当次光） |
| **光比与暗区方向** | 亮暗落差的量级与暗区方位一致 |
| **灯具开关状态** | 同一状态下不能一块板亮吊灯、另一块熄灭 |

**换时段或停电时，该地点所有受影响视角要同步更新。** 不能只改一张。

### 平光板怎么救

资产图默认用**均匀可比较的光**（方便看清结构），这会让成片显得平。

救法不是把资产图改得很戏剧化，而是**在关键帧提示词里覆盖光向**：

```
在参考图基础上：主光改为右侧单侧硬光，左脸入暗，背景虚化到只剩色块
```

## 七、空场政策

| 级别 | 内容 | 适用 |
|---|---|---|
| **禁止有人** | 严禁剧情角色、群众、叙事动作，只留固定家具与设备 | 母版、九宫格（默认） |
| **以空场为主** | 允许无身份的中性尺度参照，不遮挡地理 | 需要尺度感时 |
| **允许背景人群** | 可有人群或工作痕迹，但不得编造主角剧情事件 | 街景、市集 |

**默认禁止有人。** 场景图里出现人，会让人物参考和场景参考混在一起，模型分不清哪个是哪个。

---

## 七·补、尺度感：怎么让观众觉得「大」

仙侠、怪兽、天穹、巨塔这类场景，最难的不是画出来，是**让观众感到它大**。画一个很大的东西不等于大——没有参照，观众无法判断。

### 第一条：不要靠数字

写「高三千丈」「直径十万米」，模型没有这个尺度经验，出来可能是个一米的东西。

**要把数字翻译成视觉等价物**：

| 不要写 | 改写成 |
|---|---|
| 高 3000 丈 | 巨物约为三十层楼高，站在山脚看不到顶 |
| 体长十万米 | 巨物长度约等于从城门到皇宫的距离 |
| 直径极大 | 三个成年人张开手臂才能抱住它的一根手指 |

### 七个尺度档（用建筑层数当尺子）

| 档 | 相当于 | 画面表现 |
|---|---|---|
| **S1 大型** | 2–5 层楼 | 人物明显小，可完整看到巨物 |
| **S2 巨大** | 10–30 层楼 | 人物非常小，巨物占满画面，开始用仰视 |
| **S3 城堡级** | 一座宫殿 | 需要远景，人物只剩一个点 |
| **S4 山岳级** | 一座山峰 | 巨物与云层相交，人物不可辨 |
| **S5 天空级** | 覆盖天穹 | 巨物成为天空本身，只能看到局部 |
| **S6 大陆级** | 一片陆地 | 只能俯视，巨物是地形 |
| **S7 不可测** | 无参照 | 只给局部，让人自己脑补 |

**S5 以上不要试图拍全。** 拍局部才有大感，拍全了反而变小。

### 三级参照物：必须至少一个

| 级别 | 参照 | 用法 |
|---|---|---|
| **一级** | **人物** | 最有效的尺子。完整人物、站立、在巨物附近但留出距离 |
| **二级** | 人类建筑 | 房屋、高塔、城墙、桥梁 |
| **三级** | 自然环境 | 树、山峰、鸟群、云层、船只 |

**一级参照优先。** 有人物在画面里，观众能瞬间完成换算；只给山和云，观众不知道谁大。

### 锁定三条（缺一即失尺度）

```
□ 有明确人物参照
□ 巨物与参照物在同一个景深平面内（不能一个清晰一个虚得离谱）
□ 写出巨物的遮挡关系（什么挡住了什么，谁在前谁在后）
```

**第二条最容易漏**：把人物放前景虚化、巨物放背景清晰，两者不在同一平面，观众读不出比例。要让人和巨物"同处一个空间"。

## 八、标注：中文会乱码，要有降级方案

九宫格的每格要标机位名/子区域名，方便人看。但**中文标注经常渲染失败**。

### 降级三级

```
第 1 级：格内标中文机位名（如「宋府·闺房」）
    ↓ 出现乱码 / 缺字 / 截断
第 2 级：格内只留阿拉伯数字 1~9，随图附《编号—子区域对照表》
    ↓ 两次重试仍失败
第 3 级：按第 2 级交付，并在说明里写明「已降级」
```

**三条纪律**：

1. **不许无标注裸格交付**；
2. 重试上限 2 次，不反复烧额度；
3. 降级版**仍须保留 9 格结构**，不许因为标注失败就改成 6 格或散图。

## 九、跨集延续：同一间屋子第二次出现

场景在后续集数再次出现时，**不许重新描述**。

```markdown
【延续拍摄声明】
- 本场景为第 3 集「顾氏总裁办」的延续拍摄
- 建筑结构、家具位置、地面材质、门窗、陈设全部与第 3 集完全一致
- 材质、色彩、光照方向、阴影方向、天气、时段、亮度全部不变
- 禁止新增、删除、移动任何元素，禁止重新设计
- 仅允许摄影机移动

【参考图锁定】
- 必须传入第 3 集该场景已生成的图作为参考图（图生图）
- 参考图强度 0.7–0.85
- 参考图中所有元素必须 100% 保留，禁止 AI 自行优化、美化、替换
```

**`场景定位` 与 `画面描写` 逐字复用首次出现集的文字**，不重写。

时段/天气若因剧情变化（白昼→黄昏），必须在场景定位显式声明，并写明变化原因。

## 十、场景资产自检

- [ ] 分清了地点与视图，停电/换时段没拆成两个地点？
- [ ] 独立地理、独立入口的空间分建了地点并注明连接？
- [ ] 方位用锚点相对关系写，没写裸的"左侧"？
- [ ] 人会靠坐的固定物写了高度？
- [ ] 先出了母版，九宫格从母版派生？
- [ ] 九宫格写了「全图共 9 格，不多不少」？
- [ ] 选了模式 A 还是 B，锁定段与之匹配？
- [ ] 机位名与空间类型吻合，没硬凑？
- [ ] 同地点同状态的所有视角，主光/色温/光比/灯具状态一致？
- [ ] 场景图里没有人物？
- [ ] 标注写了降级方案？
- [ ] 跨集延续用了「逐字复用 + 参考图锁定」？

第 3、8、9 题最容易出问题。
