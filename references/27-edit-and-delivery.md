# 剪辑与交付：从一堆片段到一条能发的东西

前面所有文档都在生产**素材**。这一篇处理最后一个环节——把素材变成一条片子。

这一段最容易被忽略，因为 AI 工具链默认"生成完就结束了"。但实际死法在这里：
**音画不同步、字幕截断、响度忽大忽小、黑帧、集尾多两秒空白。**

观众不会说"你的剪辑有问题"，他直接划走。

---

## 一、剪辑单：先有单，再动手

不要打开软件边看边剪。**先在纸上把单子写完**——剪的时候只做执行，不做决定。

```markdown
# 剪辑单 · EP001

| # | 镜号 | 入点 | 出点 | 时长 | 用哪条 | 为什么是这条 |
|---|------|------|------|------|--------|--------------|
| 1 | SHOT-001 | 00:00.0 | 00:02.4 | 2.4s | take2 | take1 手崩；take3 眼神看错方向 |
| 2 | SHOT-002 | 00:00.8 | 00:03.6 | 2.8s | take1 | 前 0.8 秒是等待，进来就有动作 |
| 3 | SHOT-003 | — | — | — | 弃用 | 动作与 002 重复，删 |
```

四列必须写：**入点、出点、为什么选这条、为什么弃那条**。

最后一列不是给自己看的，是给三天后的自己看的。没有它，你会重新审一遍所有素材。

### 入点怎么定

| 情况 | 入点 |
|---|---|
| 动作镜 | 动作**起势前 3~5 帧**，不要从第一帧就用 |
| 台词镜 | 说话前留 0.2~0.3 秒的「预备」——观众要看到他要开口 |
| 反应镜 | 上一个人**说完最后一个字之后**才切进来，否则反应像是预判 |
| 空镜 / 环境 | 前 0.5 秒让画面"安顿"下来，别一进来就是动的 |

### 出点怎么定

**出点永远比"感觉够了"早 3~5 帧。** 观众不需要看完一个动作，他需要看到动作**成立**。

- 走位镜：脚落地即出，不要等走完
- 台词镜：最后一个字收完 + 0.3 秒
- 反应镜：表情到位即出，多留就是拖

### 可用带的三个判据

同一镜生成三条，怎么选？

| 判据 | 看什么 | 一票否决 |
|---|---|---|
| **① 结构** | 手、脸、肢体有没有崩 | 手指数错、脸变形 → 直接弃 |
| **② 表演** | 眼神方向对不对、情绪是不是这一场的 | 看错方向、笑场 → 弃 |
| **③ 技术** | 有没有闪烁、跳帧、穿模 | 闪烁 → 弃（后期救不回来） |

**顺序不能换。** 结构崩的片，表演再好也没用。

三条都不合格时，**回头改提示词重生成**，不要硬选一条凑——凑出来的镜头，观众一眼能看出来"这个镜头不太对"，虽然他说不出哪里不对。

## 二、镜序：什么时候允许改剧本顺序

剪辑可以改顺序，但有边界。

| 允许 | 不允许 |
|---|---|
| 同一场内的镜头调序（为了节奏） | 跨场调序（会破坏时间与空间逻辑） |
| 删掉冗余镜（信息重复的） | 删掉钩子镜、卡点镜 |
| 把长镜拆成两段插入反应镜 | 把两个不同地点合成一场 |
| 加空镜做呼吸 | 用空镜替代本该有的表演 |

**改完顺序必须回头改文档。** 分镜.md 与成片不一致，下一集必然出错——因为下一集是照着上一集的文档写的。

---

## 三、字幕：三条硬规范

### ① 逐字取自剧本

**字幕一个字都不许自己写。** 配音念什么，字幕就是什么。

改了字幕不改配音 = 观众听到的和看到的不一样，这是最廉价也最致命的错。

### ② 单行 ≤14 字，最多两行

超过就断句，**断在语义完整处**，不要断在「的、了、是、就」后面。

```
❌ 你凭什么觉得我会原谅你这个背叛了
   我整整十年的人
✅ 你凭什么觉得我会原谅你
   这个背叛了我整整十年的人
```

### ③ 停留时长跟字数走

中文阅读速度与旁白语速接近（4~5 字/秒）。一条两行字幕（约 28 字）停留 **3~4 秒**比较合适。

**字幕先出还是配音先出？** 永远**音频先出，字幕后对**。
反过来会陷入死循环：这句话念不完 → 改字幕 → 又太快。

### 竖屏字幕的安全区

| 平台 | 底部安全区 | 说明 |
|---|---|---|
| 抖音 / 红果 | 底部 12%~15% | 进度条、文案、按钮会盖住 |
| 视频号 | 底部 15% | 更保守 |
| 横屏平台 | 底部 8% | 播放控件窄 |

**字幕位置不要写在画面正中**——竖屏观众的视线在中上三分之一。

## 四、响度：一个数定生死

**响度不对，观众第一反应是"这个片子好糙"。**

| 目标 | 数值 | 说明 |
|---|---|---|
| **整体响度（流媒体 / 短视频）** | **-14 LUFS** | 抖音、B 站、YouTube 都按这个归一化 |
| 电视播出 | -23 LUFS（EBU）/ -24 LKFS（ATSC） | 交付电视台才需要 |
| **真峰值上限** | **-1 dBTP** | 超过就会被平台压限，动态全毁 |
| 对白峰值 | -6 dBFS 左右 | 给音效和 BGM 留头 |
| 对白平均 | -18 ~ -16 LUFS | 不要顶到 -14，那不是对白的电平 |

### 三条纪律

1. **同一集内，对白平均响度波动不超过 3 LU。** 忽大忽小是最容易被听出来的瑕疵。
2. **BGM 有台词时必须让路。** 不靠"感觉"，靠数字：台词期间 BGM 压到 -24 LUFS 以下，或做侧链压缩。
3. **导出前必看真峰值。** 手机外放听不出来，平台压限之后才发现爆了，已经晚了。

### 手机外放测试（不可跳过）

漫剧 90% 的观众在手机上看，且大概率外放。

- 每一句台词都听得清吗（不是"大概知道说什么"）
- 低频音效是不是完全消失了（消失了就换中高频音效）
- 有没有刺耳齿音、爆音

---

## 五、转场：只说因果，不说花活

**每个转场必须能说出叙事意图。** 说不出来就是用硬切。

| 转场 | 什么时候用 | 观众感知 |
|---|---|---|
| **硬切** | 默认。90% 的转场都该是硬切 | 无感，最好 |
| **叠化** | 时间流逝、地点转移、情绪沉降 | 「过了一会儿」 |
| **闪白** | 冲击、打击、失神 | 「被打了一下」 |
| **黑场** | 段落结束、集尾 | 「这一段落完了」 |
| **匹配剪辑** | 两个相似形状/动作接在一起 | 最丝滑，也最难 |

**纪律**：单集技巧型转场 ≤3 处，同段不连用 2 处。**转场越多，节奏越碎。**

## 六、成片核对：交付前逐条打勾

这一步只花十分钟，能拦住 80% 的低级事故。

- [ ] **总时长**与排期一致（差超过 3 秒要说明）
- [ ] **镜数与剪辑单一致**（多一镜少一镜都要能解释）
- [ ] **无黑帧**（每两镜交界处抽一帧看）
- [ ] **音画同步**：台词最后一个字与口型/表演对得上
- [ ] **字幕**：无错字、无截断、无超出安全区、与配音逐字一致
- [ ] **响度**：整体 -14 LUFS，真峰值 ≤ -1 dBTP
- [ ] **开头 3 秒**：第一帧就有信息，不是黑场或渐入
- [ ] **集尾**：卡点落在最后一帧，不留空白尾巴
- [ ] **AI 生成标识**：按平台要求加了
- [ ] **文件名**：符合平台规范（不含特殊字符、不超长）

### 八个最常见的事故

| 事故 | 原因 | 预防 |
|---|---|---|
| 黑帧 | 片段首尾有生成残留 | 入点前移 3 帧，出点提前 3 帧 |
| 音画不同步 | 音频按整段生成，未逐句对轨 | 按句生成、逐句摆位 |
| 字幕截断 | 单行超 14 字 | 断句，别硬塞 |
| 响度忽大忽小 | 各片段分别生成，电平不同 | 统一归一化后再混 |
| 集尾多两秒空白 | 忘了裁 | 核对时看最后一帧 |
| 开头黑场 | 首帧是渐入 | 首帧必须有内容 |
| 画面抖动 | 生成时运镜与剪辑运镜叠加 | 剪辑端不做数字变焦 |
| 二次压缩糊 | 导出码率太低 | 1080p 竖屏 ≥8Mbps |

## 七、交付包：一手交清，不留尾巴

```
交付/
├── EP001_成片.mp4            成片（命名带集号与版本）
├── EP001_封面.jpg            封面（3:4 或 9:16）
├── EP001_字幕.srt            字幕
├── EP001_文案.md             标题 + 简介 + 话题标签 + 前 3 秒钩子文案
├── 剪辑单.md                 入出点与取舍理由
└── 源/
    ├── 剧本.md / 分镜.md / 视觉设定.md
    └── 片段/                 按镜号命名的原始片段
```

**三条纪律**：

1. **片段按镜号命名**（`SHOT-EP001-007_take2.mp4`）。叫"最终版2"的文件，三天后没人认得出。
2. **文案单独一份**。平台的标题、简介、话题标签不进视频文件，进 md。
3. **版本号写进文件名**（`_v3`）。覆盖式命名（"最终""最终改"）一定会出事。

## 八、剪辑自检

- [ ] 剪辑单写了入点/出点/取舍理由，还是边看边剪？
- [ ] 每镜入点是否留了起势与预备？
- [ ] 出点是不是比"感觉够了"早 3~5 帧？
- [ ] 字幕逐字取自剧本？
- [ ] 单行 ≤14 字、最多两行、断在语义完整处？
- [ ] 字幕在底部安全区之上？
- [ ] 整体响度 -14 LUFS、真峰值 ≤-1 dBTP？
- [ ] 技巧型转场 ≤3 处，每个都能说出意图？
- [ ] 手机外放听过一遍？
- [ ] 成片核对十条全过？
- [ ] 交付包含片段源与命名规范？

前三条决定片子"顺不顺"，中间三条决定"糙不糙"，最后两条决定"能不能复现"。
