# 音频与剪辑

漫剧的画面是半静态的，**观众的沉浸感主要靠声音撑住**。

有从业者实测：竖屏漫剧的完播率，极大程度上取决于配音的代入感。画面可以省，声音不能省。

---

## 一、配音：声线是资产，不是设置

### 声线锁定

每个角色一条**声线卡**，写进视觉设定，全项目复用。

```markdown
- 声音：烟熏嗓，语速偏慢，每个字都像在喉咙里撕扯，句尾下沉。
```

| 维度 | 可写什么 |
|---|---|
| 音色 | 烟熏、清亮、沙哑、磁性、奶音 |
| 语速 | 偏慢 / 中速 / 急促 |
| 音高 | 低 / 中 / 高 |
| 习惯 | 句尾下沉、爱拖长音、说话像咬着牙 |
| 情绪基线 | 冷、燥、软、飘 |

**不要写「温柔的女声」这种组合词**——它同时指向几千种音色，AI 配音会随机选一个，下一集又换一个。

### 语气位必须逐句给

剧本里每句台词后面的括号就是语气位。配音时**逐句照做**，不要整段用同一个情绪。

```
沈惊歌（声音微颤，字字清晰）：顾城，这是沈家最后的资产了。
```

这里有两层：**声音微颤**（生理状态）+ **字字清晰**（表达策略）。两个都要给。

| 只给一层 | 给两层 |
|---|---|
| 「愤怒地说」 | 「压着嗓子，一个字一个字往外挤」 |
| 「悲伤地说」 | 「声音发飘，说到一半停了一下才接上」 |

### 语速标定

先量一次，再全项目用同一个值。

方法：录一段已知字数的台词，数秒数，算字/秒。

| 档 | 字/秒 | 适用 |
|---|---|---|
| 慢 | 3.5 | 独白、临终、宣判、回忆 |
| **标准** | **4.0** | 绝大多数叙事对白 |
| 快 | 4.6 | 争吵、赶时间、兴奋 |
| 极快 | 5.0+ | 只用于群喊、报点、连珠炮台词，且必须比平时更短的句子 |

**同一个角色跨集必须用同一语速。** 语速变了，人物就变了。

> ⚠ **别用播报速度当对白速度。** 新闻播报能到 5 字/秒以上，那是「念稿」不是「说话」。
> 对白里还有呼吸、迟疑、重音，实际承载量比播报低 20%~30%。按 5.5 排的镜头，配音时必赶。

### 停顿不是空的，是表演

TTS 最假的地方不是音色，是**匀速念完**。三个参数把停顿还回去：

| 位置 | 留白 | 为什么 |
|---|---|---|
| 句号 / 问号后 | 300–500ms | 低于 200 像赶，高于 500 像卡带 |
| 段落之间 | 600–800ms | 换气的长度 |
| 情绪转折（平静→爆发） | 800–1200ms | 观众需要这一口气才跟得上 |
| 镜头切换处 | 600–900ms | 让耳朵知道画面换了 |

**做法**：不要一次生成 200 字整段（模型会把所有标点拉平），按句切分、逐句生成、时间线上拼。

### 一句只留一个重音

真人的一句话里只有一个词是「砸」下去的，其余都轻。AI 的通病是每个词用力均匀。
做法土但有效：把要强调的词单独生成，或在该词后加逗号 / 破折号，或拆成短句。

### 多音字与自造名词

中文 TTS 会在「重 / 行 / 落 / 长」这类多音字和剧中自造名词上读错。
建一张替换表，随听检滚动维护，**每发现一处错读就补一条**：

```json
{ "重新出发": "chóng 新出发", "银行门口": "银 háng 门口", "雨夜便当": "雨夜便当（店名，读 biàn dàng）" }
```

## 二、音效：三层，各有任务

| 层 | 内容 | 任务 | 音量 |
|---|---|---|---|
| **环境底** | 风、雨、鸟、人声嘈杂、空调嗡鸣、远处车流 | 建立空间与真实感 | 最低，持续存在 |
| **动作音** | 脚步、开门、衣物摩擦、器物碰撞、呼吸 | 让动作有重量 | 中 |
| **强调音** | 心跳、耳鸣、玻璃碎裂、金属锐响、突然的静默 | 标记情绪峰值 | 最高，可短暂压过人声 |

### 关键原则：静默也是音效

**在噪声之后接一段完全静默，比加任何音效都强。**

写法：`[SFX] 全部环境声骤然消失，只剩她的呼吸`。

这比「紧张的音乐响起」有效十倍，因为它制造了**听觉真空**，观众的注意力会被强制拉回画面。

### 音效卡点

漫剧的画面切换应该落在**声音事件**上，不是落在时间上。

```
❌ 每 3 秒切一次
✅ 切在「酒杯顿桌」那一声上
```

所以分镜的镜长应该由声音事件倒推（见 `13-storyboard.md`），而不是先定时长再配音效。

### 音效与画面的一致性

**画外声源的动作，不能写进画面正文。**

这是 H3 的实测事故：写「门外传来三下敲门声」，模型把「敲门」这个动词绑定给画面里唯一的人，渲染出**屋里的人背对镜头敲自己家的门**。

正确做法：

| 门外发生的事 | 写在哪 |
|---|---|
| 敲门、脚步、喊话 | **只写进音效**（`overall_soundscape` / `[SFX]`） |
| 门内的可见结果 | 写进画面正文（「钢门在门框里震了三下，铁链撞在锁扣上响了一声」） |

**画面只写可见的受迫结果，声源动作留在声音层。**

## 三、BGM：三条纪律

| 纪律 | 说明 |
|---|---|
| **不压人声** | 有台词时 BGM 降到 -18dB 左右，宁可听不见也不能盖住字 |
| **情绪不重复** | 画面已经在哭，音乐不要再哭；音乐的任务是给出画面没有的那一层 |
| **进出要有理由** | 不要淡入淡出到无，要在动作/转折点切进切出 |

### 情绪对照（选一个，别混）

| 段落功能 | 音乐性格 |
|---|---|
| 强钩开场 | 无音乐，只有环境声 + 一个锐利音效 |
| 压抑对峙 | 低频持续音，无旋律 |
| 情绪临界 | 单音反复（钢琴单键 / 弦乐长音） |
| 爆发 | 全部乐器同时进入，一层就够，不要层层叠加 |
| 余韵 | 只留一个乐器，慢速，逐渐消失 |

**「无声」是一个选项。** 全片铺满 BGM 是最业余的做法。

### 去哪找：三类来源与版权

| 来源 | 代表 | 版权 | 适合 |
|---|---|---|---|
| **付费曲库** | Epidemic Sound / Artlist / 耳聆网 / 爱给网 | 订阅期内可商用，**退订后旧片仍可留**（看条款） | 稳定出片、要免纠纷 |
| **AI 生成** | Suno / Udio / 网易天音 | 多数平台声明商用可用，但**要留生成记录** | 定制、不撞曲 |
| **平台自带** | 剪映 / CapCut / 抖音音乐库 | 平台内使用安全，**跨平台搬运有风险** | 快速起量 |
| **免费 CC 库** | Free Music Archive / Pixabay Music | CC0 可直接用；CC-BY 必须署名 | 预算为零 |
| ⛔ **不可用** | 未授权的流行歌、影视原声、游戏 OST | **版权方一投诉就下架，连带封号** | — |

**判断口诀**：能说清「谁授权、授到什么范围、有没有书面记录」，才能用。
说不清的，一律当不能用。

### 检索词怎么写

不要搜「悲伤的音乐」。搜 **情绪 + 乐器 + 速度 + 用途** 四段：

```
紧张 弦乐 渐强 100BPM 悬疑 铺垫
孤寂 钢琴 单音 慢 60BPM 独白
压迫 低频 无旋律 持续音 对峙
爆发 打击乐 铜管 120BPM 高燃
```

| 用途 | 检索关键词（可直接抄） |
|---|---|
| 强钩开场 | `低频冲击` `riser` `紧张 悬念 短` |
| 压抑对峙 | `drone` `低音持续` `无旋律 压抑` |
| 情绪临界 | `单音 钢琴` `弦乐 长音` `minimal 悲伤` |
| 爆发 | `epic 打击` `铜管 高燃` `trailer hit` |
| 余韵 | `钢琴 独奏 慢` `ambient 空` `尾奏` |
| 集尾钩子 | `悬疑 未完` `unresolved` `紧张 渐强 收` |

### 音效：三层检索词

| 层 | 检索词 | 注意 |
|---|---|---|
| **环境底** | 室内底噪 / 街道远景 / 风穿过建筑 / 雨打窗 / 人群嘈杂（无对白） | 一定要「无对白」版本，否则会串进别人的台词 |
| **动作** | 脚步（分材质：石地/木地板/泥地）、布料摩擦、门轴、金属碰撞、瓷器、纸张 | 一个动作可能要叠 2~3 层才像 |
| **情绪/冲击** | 心跳、耳鸣、低频冲击（whoosh/hit）、时间拉伸、静默前的抽气 | 用得越少越有力 |

**素材命名**：`SFX_金属碰撞_短_重.wav`。命名混乱的音效库，半年后你自己都找不到。

### 一集用几首

**3~5 首，循环用。**

每首对应一个情绪段，同一首可以在不同段落重复（改音量与切入点即可）。
一集换 10 首 BGM，听起来像歌单而不是配乐。

## 四、字幕

### 硬规范

| 项 | 规格 |
|---|---|
| 位置 | 竖屏：底边上方 15%–20% 区域（避开平台 UI） |
| 字号 | 竖屏 ≥ 52px（1080×1920） |
| 行数 | 最多 2 行，单行 ≤ 18 字 |
| 停留 | ≥ 1.2 秒，且与台词同时进出 |
| 描边 | 必须有（深底浅字或浅底深字都要保证可读） |
| 字体 | 商用授权字体（**这是侵权高发区**） |

### 视觉小说式字幕（漫剧特色）

漫剧常用「角色名 + 台词」的形式，或在画面内做气泡。用的话：

- 角色名用固定色（每个角色一个色，全片一致）；
- 气泡不遮挡面部识别点；
- 同一画面不同时出现两个气泡。

### 不该做的事

- 字幕逐字出现（卡顿感）；
- 用花体/艺术字（可读性差，且平台压缩后糊）；
- 字幕压在人物脸上；
- 中英双语同时显示（竖屏放不下，会挤成两行小字）。

## 五、剪辑：拼接与节奏

### 多段拼接的三种缝

| 缝 | 处理 |
|---|---|
| **同场连续** | 末帧定格法截帧作下段首帧；或换机位硬切 |
| **同场跳时** | 空镜 / 叠化 / 闪白 |
| **换场** | 硬切最干净；不要用花式转场掩盖 |

### 节奏原则

| 段落 | 平均镜长 | 说明 |
|---|---|---|
| 强钩 | 1.5–2.5 秒 | 快，抓人 |
| 铺垫 | 3–5 秒 | 让观众喘 |
| 对峙 | 2.5–4 秒 | 换嘴切镜为主 |
| 爆发 | 1–2 秒 | 切碎 |
| 余韵 | 4–6 秒 | 放慢，收 |

**全片同一个镜长 = 没有节奏。** 至少要有「快—慢—快」的对比。

### 转场纪律

`craft_default`：单集技巧型转场 ≤3 处，同段不连用 2 处。

**每个转场必须能说出叙事意图。** 说不出就是「为转而转」，删掉用硬切。

投喂稿里不要写转场术语（「J-cut」「匹配剪辑」）——那是剪辑端的语言，写进提示词只会污染画面。

## 六、混音

顺序固定，不要跳：

```
1. 对白（最优先，先定在 -6dB 峰值）
2. 动作音效（贴着画面卡点，比对白低 6–10dB）
3. 环境底（铺满全片，比对白低 20dB 以上）
4. BGM（最低，有台词时降到 -18dB）
5. 整体压限（防止爆音）
```

### 手机外放测试

**必须用手机外放听一遍。**

漫剧 90% 的观众在手机上看，且大概率外放或半入耳。低频在小喇叭上完全消失，高频刺耳。

测试要点：
- 台词每个字都听得清吗（不是「大概知道说什么」）；
- 低频音效是否完全听不见（听不见就换中高频音效）；
- 有没有刺耳的齿音/爆音。

## 七、音频自检

- [ ] 每个角色有声线卡，写的是具体质地不是组合词？
- [ ] 每句台词都有语气位，且给了两层（生理 + 策略）？
- [ ] 同一角色跨集语速一致？
- [ ] 有环境底层？
- [ ] 画外声源的动作没有写进画面正文？
- [ ] 有没有至少一处「静默」作为强调？
- [ ] BGM 有台词时压到位了？
- [ ] 情绪没有重复（画面已经哭，音乐不再哭）？
- [ ] 字幕避开了平台 UI 区？
- [ ] 字体有商用授权？
- [ ] 手机外放听过一遍，台词全清？

第 5、11 题是硬门。
