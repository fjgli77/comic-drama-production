# 故事引擎

漫剧的失败有 90% 发生在剧本之前——不是镜头不好，是**这个故事本来就不该被做**。

这一篇解决：这个故事能不能立住、每集有没有推力、钩子是不是真的钩。

---

## 一、最小单位：戏剧动作

**戏剧动作 = 目标 + 阻碍。**

不是「一个人想喝水」，是「沙漠里一个脱水的人找水」。

这就是判断一个场景该不该存在的唯一标准。没有目标的场景是氛围，没有阻碍的场景是过场，两者都不该占一集的时长。

### 三层汇聚

```
场景内的微型戏剧动作（目标→障碍→结果）
        ↓ 汇聚
段落级的核心戏剧动作
        ↓ 汇聚
全片的核心戏剧动作
```

**每一层都必须有「结果」**——成功、失败、或意外转向。没有结果的场景是悬空的，观众感觉「这段看完了但什么也没发生」。

### 自检三问

1. 这个场景里，谁想要什么？（目标必须具体，不能是「想变强」）
2. 谁或什么在阻止他？（阻碍必须主动，不能是「运气不好」）
3. 这场结束时，局面变了没有？（变了什么，用一句话说得出来吗）

第三问答不出来，这场删掉或合并。

## 二、Want 与 Need：弧光的发动机

| | 定义 | 观众看到的方式 |
|---|---|---|
| **Want（外在需求）** | 角色自己知道、主动追求的目标 | 台词、行动、计划 |
| **Need（内在欲望）** | 角色没意识到的灵魂缺口 | 选择时的犹豫、代价的承受方式 |

弧光 = **从 A 状态到 B 状态的不可逆变化**。

- 成长弧光：得到了 Need；
- 悲剧弧光：拒绝了 Need；
- 反弧光：得到了 Want，失去了自己。

**短内容只需要一次跳跃（A→B）。** 不要在一集里设计两次转变，那会让两次都不可信。

### 漫剧的弧光预算

连载漫剧不能每集都完成弧光，会假。正确分配：

| 层级 | 弧光任务 |
|---|---|
| 全季 | 主弧光：主角从 A 到 B（一次，跨全季） |
| 单集 | 局部状态变化：这一集他**多知道了什么 / 失去了什么 / 被迫做了什么** |
| 单场 | 不承担弧光，只承担戏剧动作的结果 |

单集的一句话弧光检查：**「这一集，[主角]被拿走了什么 / 换来了什么。」** 写不出来的集数，砍掉或合并。这条比任何结构模板都管用。

## 三、反庸俗自审：动笔前拦掉「精致的垃圾」

这一节来自实战中最痛的教训：技术上无懈可击、节奏完全合规、但**没人想看**。

### 必答三题

**问题一：这个题材的公共池套路是什么？**

列出至少 3 个你最可能滑进去的套路，划为绝对禁区。

例（都市逆袭）：
- 禁「隐藏首富扮猪吃虎」；
- 禁「被退婚后当场打脸」；
- 禁「一句话让全场下跪」。

**问题二：我们给出了什么不可推导的真实细节？**

不是「重生」，是「重生后发现上辈子的记忆有一半是假的」。
不是「总裁」，是「总裁每天要在固定时间给一个陌生号码发一条空白短信」。

**不可推导 = 观众没法从题材标签猜出来。** 这是区分「同质化」和「有辨识度」的唯一分界线，也是平台治理「角色雷同」时真正看的东西。

**问题三：观众看完这一季，手里能拿着什么？**

不只是「爽」或「虐」，而是某种余味、某个画面、某句台词、某种「我也这样想过」的确认。

三个问题答完还是空的，换选题。不要用工艺去补救选题。

## 四、钩子工程：三级钩，各有各的任务

漫剧的钩子不是「开头搞个悬念」，是三级递进的注意力管理。

### 第一级：3 秒强钩（Cold Open）

**任务**：阻止划走。

可用手段（`craft_default`，选一个就够）：

| 类型 | 例 |
|---|---|
| 反常动作 | 一个人正在把自己埋进土里，然后手机响了 |
| 结果前置 | 先给观众看尸体，再回到 24 小时前 |
| 强冲突台词 | 「你杀了我哥。」「他也杀了我爸。」 |
| 强视觉 | 满桌的红色印章，全是「清算完毕」 |
| 强音效 | 寂静中一声玻璃碎裂 |

**禁止**：黑屏渐显、慢摇风景、旁白交代世界观、「很久很久以前」。

强钩必须在**第 1–3 拍内兑现**——不是「暗示要发生」，是「已经发生」。

### 第二级：30 秒微钩

**任务**：对抗中段疲劳。

位置在单集的 40%–50% 处。手段：
- 新信息（观众以为的真相被推翻一角）；
- 细节翻转（一个不起眼的物件变成关键）；
- 角色异常反应（不该笑的人笑了）。

微钩不是第二个强钩。它的强度应该低于强钩、高于日常——它是**呼吸点**，不是第二个高潮。

### 第三级：集末钩子（Cliffhanger）

**任务**：驱动下一集。

**唯一正确切法：切在最难受的临界点。**

- 大招刚发出、还没落下；
- 真相刚吐出第一个字；
- 门刚推开、还没看到里面。

**绝对不要**：
- 高潮结束后再补一段「总结」；
- 用旁白说「欲知后事如何」；
- 切在平静处，靠下集预告硬拉。

### 钩子的机械检查

```
本集最后 3 秒：______________________
下一集第 1 个画面：____________________
两者是同一时刻 / 紧接的下一个动作 / 有明确因果？
```

答不上来，集间钩子链就断了——观众会在这一集流失，而不是下一集。

## 五、集间推力：carry 什么，不 carry 什么

连载漫剧的连续性不是「记住所有细节」，是**只 carry 三样东西**：

| 必 carry | 说明 |
|---|---|
| **未完成动作** | 上集切在临界点，这集必须接着走 |
| **未兑现承诺** | 上集说了要做的事，这集必须推进或明确推迟 |
| **未结算代价** | 上集造成的伤害/损失，这集必须有人付账 |

**不必 carry**：位置、天气、在场配角、无关道具。那些是连续性锁（`04-visual-bible.md`）的事，不是剧作的事。

### 每集开头不能做的三件事

1. 重复上集结尾（观众刚看过）；
2. 用旁白回顾（最偷懒的做法）；
3. 换一个完全无关的场景从头开始（观众会以为点错了）。

正确做法：**从上集的余波里开头**——不是重演，是「那件事之后的第一秒」。

## 六、双轨节奏

好的单集有两条节奏同时运行，它们**不需要同步**：

| 轨道 | 内容 | 峰值位置 |
|---|---|---|
| **外部情节轨** | 事件、冲突、信息揭示 | 通常在后段（60%–85%） |
| **内在情感轨** | 角色的情绪转折、关系变化 | 可以早于或晚于情节峰 |

**张力来自两轨的错位。**

- 情节到顶时情感还没到（观众替角色着急）；
- 情感到顶时情节还在铺（观众替角色心疼）。

两轨同时到顶 = 平；两轨都平 = 无聊。

### 节奏波浪（手绘即可）

```
张力
 10 │                    ╱╲
  8 │              ╱╲  ╱  ╲
  6 │        ╱╲  ╱  ╲╱    ╲
  4 │   ╱╲ ╱  ╲╱            ╲___
  2 │ ╱  ╲╱
  0 └────────────────────────────→ 时间
    0    15   30   50   75   100  120s
        ↑钩   ↑微钩      ↑峰   ↑切
```

画出来的意义：**你能一眼看出中段有没有塌。** 中段连续 20 秒在 4 以下，就是注水区。

## 七、节奏档案：把感觉变成可核对的数

如果要让审查（`17-review.md`）能客观判断节奏，在立项时把这几个数定下来，写进 `short-drama.json`：

| 字段 | 含义 | 典型值 |
|---|---|---|
| `first_hook_seconds` | 从开始到第一个危机/冲突/异常已发生的秒数 | ≤ 3 |
| `beat_interval_seconds_max` | 相邻两个情绪触点之间最长间隔 | 8–12 |
| `opposed_reversals_per_episode_min` | 每集「有人对抗」的反转次数（系统/数字/环境变化不算） | 2–3 |
| `end_on_peak` | 是否切在峰值或峰值前一刻 | true |
| `reprise_previous_last_beat` | 开头是否重演上集末拍（EP001 不适用） | false |

**这些是 `craft_default`。** 定了就要核对，但偏离不需要道歉——只要你说明为什么。

> 注意 `opposed_reversals` 的定义：必须是**有意志的人类对手**驱动或承受的反转。系统弹窗、数值变化、天气突变都不算。这条定义防的是「看起来很热闹但其实没人真的在对抗」。

### 逐场张力：把曲线画出来

节奏档案是**项目级参数**，张力是**逐场数值**。两个都要。

**写法**：场次标题后面加标记。

```markdown
## EP001-SC001 外 · 石阶 · 晨（张力 6）
## EP001-SC002 内 · 剑冢 · 晨（张力 3）
## EP001-SC003 内 · 剑冢 · 晨（张力 2）
## EP001-SC004 内 · 剑冢 · 晨（张力 9）
```

`board` 命令会自动读出来，画成一条按时间铺开的曲线（`制作看板.html` 里的「情绪曲线」区块）。

**没有标记就不画**——不强制，但标了就能一眼看出问题。

#### 打分的锚点（不要凭感觉给 7）

| 分 | 这一场是什么状态 |
|---|---|
| 0–2 | 信息铺陈、日常、赶路。观众可以走神 |
| 3–4 | 有目标但没阻力，或阻力还没逼近 |
| 5–6 | 阻力出现，角色开始付代价 |
| 7–8 | 正面冲突，双方都在赌 |
| 9 | 不可逆的损失或揭露，角色变了 |
| 10 | 全片只有一次，通常在 80%~90% 位置 |

#### 三条校验

| 校验 | 不合格的信号 |
|---|---|
| **峰值位置** | 最高点落在 60% 之前 → 后面全是下坡，观众提前关掉 |
| **中段塌陷** | 连续两场 ≤3 且中间没有反转 → 注水区，砍或并 |
| **无差曲线** | 所有场次都在 5–6 → 平的，观众记不住任何一场 |

**张力只能靠"落差"被感知，绝对值没用。** 9 分之所以是 9 分，是因为前面有 2 分。

## 八、从小说改漫剧：改什么，留什么

改编不是压缩，是**换一种因果**。

| 小说擅长 | 漫剧需要 | 转换动作 |
|---|---|---|
| 内心独白 | 可见行为 | 把「他恨她」改成「他把她的杯子摔了，然后捡起来擦干净」 |
| 长段心理推演 | 一次视觉揭示 | 把三页推理压成一个道具特写 |
| 多线并行 | 单线推进 | 砍掉副线，把副线的功能并进主线人物 |
| 时间跨度大 | 连续时空 | 用一场戏承载三年（一场饭桌上的沉默） |

### 改编三条底线

1. **主角立场不能变**：原著里帮主角的人，不能改成害主角的人（除非创作者明确接受）；
2. **新增必须登记**：原著里没有的角色/场景，必须写明它承担什么功能、为什么原著材料承担不了；
3. **名场面必须留**：读者记得的那三个画面，一定要拍出来。改了结构可以，删了名场面不行。

## 九、故事层自检清单

写完故事、进剧本之前，逐条过：

- [ ] 全片核心戏剧动作能用一句话说出「谁想要什么、谁在阻止」？
- [ ] 主角的 Want 和 Need 分别是什么？两者冲突吗？
- [ ] 每一集的一句话弧光都写得出来？
- [ ] 反庸俗三题都答得出来，且答案不是题材标签？
- [ ] 第一集 3 秒内有没有已经发生的异常？
- [ ] 每集 40%–50% 处有没有微钩？
- [ ] 每集最后 3 秒与下集第一个画面能接上？
- [ ] 中段有没有连续 20 秒以上的张力塌陷？
- [ ] 反派有主动意志吗（不是「命运」「系统」「家族安排」）？
- [ ] 改编的话，名场面留了几个？新增的登记了吗？

第 2、4、9 题答不好，不要进剧本阶段。那三题是根。
