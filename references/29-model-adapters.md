# 模型适配：按范式写，不按型号写

**"支持 90% 的模型"不是给每个模型写一套方言。** 那件事做不完——型号半年换一代，
写完就过期。真正可做的是：**认出它属于哪种提示词范式，按范式写。**

---

## 一、为什么是范式而不是型号

市场上的视频/图像模型有几十个，但**提示词的写法人只有五种**。

| 范式 | 名字 | 核心特征 | 覆盖的模型（本 skill 登记 29 个） |
|---|---|---|---|
| **A** | 结构化分段 | 分段 + 时间轴 + 分字段 | Seedance 2.5/2.0、MiniMax H3、可灵 3.0、万相 3.0、Vidu Q2、即梦 |
| **B** | 自然语言散文 | 一段连续描述，像给摄影师讲戏 | Veo 3.1、Sora 2、Runway Gen-4、Luma Ray3、Pika、PixVerse、LTX、混元、Seedream 4、Qwen-Image、Firefly、Grok、Kolors |
| **C** | 标签堆叠 | 逗号分隔关键词 + 权重 | Midjourney V8、Flux 1.1、SD 3.5、Ideogram 3、Recraft |
| **D** | 指令式编辑 | 保持什么 + 只改什么 | GPT Image 2、Nano Banana Pro、Flux Kontext |
| **E** | 对话式迭代 | 先出一版，再逐轮追加 | Gemini Omni、新一代对话式生成 |

**这张表就是"90%"的真实含义**：不是罗列全部型号，而是**任何一个新模型都能落进五类之一**。
你今天遇到一个没登记的模型，先问一句"它是分段式、散文式、标签式、指令式还是对话式"，
答案出来，写法就定了。

> 五个范式 → 29 个登记型号 → 市场上未登记的新模型只要归类，就能套用。
> **范式比型号稳定，型号会死，范式不死。**

查你手上的模型属于哪一类：

```bash
python scripts/cd.py model                 # 列出全部 29 个，标范式
python scripts/cd.py model minimax-h3      # 看单个详情
```

## 二、三条不变层（跨任何模型都不许改）

换模型只改**表达方式**，不改**内容**。

| 层 | 内容 | 换模型时 |
|---|---|---|
| **叙事层** | 谁、在哪、做什么、想要什么 | ❌ 一个字不改 |
| **镜头层** | 景别、角度、机位运动、轴线 | ❌ 不改（但术语要换方言） |
| **光影层** | 光源方位、色温、光比、气氛 | ❌ 不改 |
| **模型层** | 秒数、分辨率、帧率、引用语法、参考槽位、负面词表 | ✅ **必须改** |

**这条是跨模型一致性的地基。** 很多人换模型就重写整段，结果人设、光位、景别全变了，
还以为是模型不行——其实是自己把不变层也改了。

## 三、视频三范式

### 范式 A · 结构化分段

**特征**：模型支持时间轴、分段、多字段。你不写时间轴，它自己平均分配，节奏就废了。

**骨架（七段式）**：

```text
【画幅风格】9:16 竖屏，国漫二次元，赛璐璐上色（两段平涂、边界硬边）
【场景资产】老楼走廊，绿色墙裙，声控灯昏黄，墙面有霉斑
【核心人物】苏衔，玄青窄袖道袍，右手背覆墨纹，低髻横插一支旧竹笔
【站位声明】她在门内左侧，面朝门，门在画面右三分之一，两者相距一臂
【时间轴分镜】
  0.0–1.2s  右手抬到门把上方，停住
  1.2–3.0s  门被向内拉开，雨夜的冷光从门缝涌入
  3.0–4.0s  她眯了一下眼，手背的墨纹被光照亮
【音效】门轴干涩的一声；雨声由远及近
【禁止项】（只装负面清单，用英文）no text, no watermark, no logo
```

**四条纪律**：

1. **时间轴要覆盖全片**，首尾相接不留空档。
2. **每段只写一个可见动作**，不写"她犹豫了一下"（那是心理）。
3. **站位写清相对位置**，不写"站在合适的位置"。
4. **禁止项只放负面清单**，正面的"要保持""必须"混进去会互相抵消。

**A 类模型的关键差异**（同范式内也会有微调）：

| 模型 | 要不要写禁止项 | 参考图上限 | 备注 |
|---|---|---|---|
| Seedance 2.5 | 要，放最后一段 | 50 | 多模态参考最强 |
| MiniMax H3 | 要，且**词根极敏感** | 12 | 否定词会被画出来，能不用否定就不用 |
| 可灵 3.0 | 要 | 5 | 运镜词要具体（"缓推"不够，写"0.5 米/秒前移"） |
| 万相 3.0 | 要 | 15 | 支持更长段，30s 内可一次成 |

---

### 范式 B · 自然语言散文

**特征**：模型不吃字段名，看到"【时间轴】"这种标记会当成画面文字。要写成一段人话。

**骨架**：

```text
一个年轻女子站在老楼走廊里，伸手推开一扇木门。走廊只有昏黄的声控灯，
门内更暗。门被拉开的一瞬间，外面的雨夜冷光涌进来，照亮她的侧脸，
也照亮她右手背上那片墨色纹路。她眯了一下眼睛。
镜头在她身后略偏左，缓缓向门推近。9:16 竖屏，国漫二次元，赛璐璐上色，4 秒。
```

**四条纪律**：

1. **按时间顺序写**：先什么，然后什么，最后什么。不要倒叙。
2. **一段话一个镜头**，别在一段里塞三个机位。
3. **参数放句尾**（画幅、时长、风格），前半段留给画面。
4. **不要写括号、不要写方头括号**——它们会变成画面里的符号。

**A → B 的改法**：

| A 里的东西 | 改成 |
|---|---|
| 【时间轴】0–1.2s / 1.2–3.0s | 「先……然后……最后……」（不用写秒数，模型自己分） |
| 【站位声明】左三分线、相距一臂 | 「她站在门内左侧，门就在她手边」 |
| 【禁止项】no text | 删掉。B 类大多不吃负面清单，写了反而干扰 |
| 【画幅风格】 | 挪到句尾：「9:16 竖屏，国漫二次元，赛璐璐上色」 |

---

### 范式 E · 对话式迭代

**特征**：一次生成不是终点，是起点。第一版只定构图与人物，后面逐轮改。

**用法**：

```
第一轮：先出这一镜的静态帧，人物站在门内，手搭在门把上，走廊昏黄。
第二轮：把门推开一半，让雨夜的冷光从门缝打到她脸上。
第三轮：她的眼睛眯一下，幅度小一点。
第四轮：把她右手背的墨纹照亮，要能看清纹路走向。
```

**三条纪律**：

1. **第一轮就要把人物与构图定死**，后面只改动作与光。
2. **每轮只改一件事**，同时改两件你不知道是哪个起作用。
3. **说"只改"而不是"重做"**，否则它会重掷所有随机项。

## 四、图像三范式

### 范式 B · 自然语言（Seedream / Qwen-Image / Firefly）

```
一位约 22 岁的东亚女性站在老楼走廊里，手搭在一扇旧木门上。
玄青窄袖道袍，低髻横插一支旧竹笔，右手背有墨色纹路。
走廊只有一盏昏黄声控灯，光从上方斜下，墙面是绿色墙裙。
9:16 竖构图，半身，国漫二次元素描上色，赛璐璐质感。
```

**纪律**：一段话讲完，人物 → 服装 → 环境 → 光 → 画幅风格，顺序别乱。

### 范式 C · 标签堆叠（MJ / Flux / SD / Ideogram）

```
1girl, young asian woman, low bun with bamboo hairpin, dark blue robe,
ink tattoo on right hand, hand on wooden door, dim green-walled hallway,
warm overhead lamp, anime style, cel shading, clean lineart,
medium shot, --ar 9:16 --style raw
```

**纪律**：

1. **按权重排序**：主体 → 动作 → 环境 → 光 → 风格 → 构图。越前越重。
2. **每个标签 1~3 个词**，不写完整句子。
3. **不要写否定**（"no text" 在部分模型里会生成 text）。要干净就靠 `--no text`（MJ）或负面提示词框（SD）。
4. **权重语法各家不同**：MJ 用 `::2`，SD 用 `(word:1.3)`，Flux 不支持权重。写之前查一下。

### 范式 D · 指令式编辑（GPT Image 2 / Nano Banana Pro / Flux Kontext）

**这是最容易做错的一类**：模型不是"生成"，是"改"。它需要知道**什么不许动**。

```
保持这张图的人物、服装、走廊结构、光位与构图不变，
只把门从关闭改为推开一半，门外的雨夜冷光从门缝涌入，
照亮她的侧脸与右手背。其余一律不动。
```

**三条纪律**：

1. **先列"不许动"**，再写"只改什么"。顺序反了它会重画。
2. **一次只改一处**。同时改光和动作，往往两处都漂。
3. **这是修图的第一手段**。出了图脸不像、衣服不对，别重新生成——用 D 类模型改。

## 五、同一镜头的五种写法（对照）

**意图**：她在门内推开门，门外是雨夜，光涌进来。

**A · 结构化**

```text
【画幅风格】9:16，国漫二次元，赛璐璐
【站位声明】她在门内左侧，面朝门，门在画面右三分之一
【时间轴】0–1.2s 手搭门把；1.2–3.0s 门拉开、冷光涌入；3.0–4.0s 她眯眼
【禁止项】no text, no watermark
```

**B · 散文**

```text
一个年轻女子在昏黄走廊里推开木门，门外的雨夜冷光涌进来照亮她的侧脸，
她眯了一下眼。镜头在她身后略偏左缓缓推近。9:16，赛璐璐，4 秒。
```

**C · 标签**

```text
1girl, dark blue robe, hand on wooden door, door opening, rainy night outside,
cold light spilling in, dim green hallway, cel shading, medium shot, --ar 9:16
```

**D · 指令编辑**

```text
保持人物、服装、走廊与光位不变，只把门改为推开一半，门外冷光涌入照亮侧脸。
```

**E · 对话**

```text
第一轮：静态帧，她站在门内，手搭门把。
第二轮：门推开一半，雨夜冷光打到她脸上。
```

**五段说的是同一件事。** 变的只有表达方式——这就是"换模型"该做的事。

## 六、迁移规则

### 换到同范式模型

改参数就行：秒数、分辨率、参考图张数、模型名。**内容一个字不用动。**

### A → B（结构化转散文）

1. 删掉所有【】标记；
2. 时间轴改成「先…然后…最后…」；
3. 站位改成相对位置的白话；
4. 参数挪到句尾；
5. 禁止项删掉。

### B → A（散文转结构化）

1. 把长句按"动作"切成 3~4 段；
2. 每段配一个时间区间，区间总和 = 目标时长；
3. 补【站位声明】与【禁止项】；
4. 把形容词换成可测参数（"昏黄"→"色温 2800K"）。

### B → C（散文转标签）

1. 抽名词与形容词，丢掉动词从句；
2. 按 主体 → 动作 → 环境 → 光 → 风格 → 构图 排序；
3. 每项压到 1~3 词；
4. 补画幅与风格后缀。

### C → D（标签转指令）

**标签表达不了"改哪里"。** 要换成"保持 + 只改"，并把参考图挂上。
这是最难互相转换的一对——不如直接重写。

### 跨范式迁移的三条降级

| 情况 | 怎么办 |
|---|---|
| **目标模型时长更短** | 拆段，用末帧作下一段首帧接续。不要压缩内容。 |
| **参考图上限更少** | 优先保"人物正面 + 场景主视角"两张，其余靠文字锁与锁面短语。 |
| **模型无原生音频** | 视频静音生成，音频后期做。**不要为了凑声音去写"有对白"，会出畸形口型。** |

## 七、模型换代怎么办

型号会死。Sora 2 已经停服，`cd.py check` 会直接报 FAIL 提醒迁移。

**换代的正确顺序**：

1. `cd.py model <新模型>` 查它的范式与上限；
2. 同范式 → 只改参数，一分钟搞定；
3. 跨范式 → 按第六节改写法，内容不动；
4. 改完 `cd.py check` 看 M 组是否还过；
5. 拿一镜做对比测试，确认画风没漂。

**不要做的事**：换模型就重写整段提示词。这样你永远不知道是模型的差距还是自己改坏的。

### 新增模型（本 skill 未登记的）

改 `scripts/cd.py` 的 `MODEL_PROFILE`，加一条：

```python
"新模型名": dict(kind="video", vendor="厂商", dur=10, refs=4, alive=True,
                 paradigm="B", audio=False, aspect="16:9,9:16",
                 aliases=["别名1", "别名2"], note="一句话特点"),
```

`paradigm` 填 A~E 之一。填完 M 组就能认它，`cd.py model` 也能列出来。

## 八、适配自检

- [ ] 我知道手上这个模型属于哪个范式（A/B/C/D/E）？
- [ ] 我改的是表达方式，不是叙事/镜头/光影？（三条不变层）
- [ ] 时间轴/散文顺序覆盖了全片，没有空档？
- [ ] 每段只有一个可见动作？
- [ ] 参数（秒数/画幅/分辨率）对得上模型的实际上限？
- [ ] 参考图张数没超？
- [ ] 无原生音频的模型，我没写"有对白"？
- [ ] 换成 D 类编辑模型时，先写了"不许动"再写"只改"？
- [ ] 跨范式迁移后，做过一镜对比测试？

前两题决定"换模型会不会崩"，后七题决定"换完能不能看"。
