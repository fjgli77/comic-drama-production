# 关键帧提示词

关键帧是每镜的**冻结瞬间**——镜头开始时的那一格。它决定视频生成的起点，也决定观众第一眼看到什么。

这一篇的核心是一条反直觉的判据：**参考图能覆盖的一个字别写，覆盖不了的写到死。**

---

## 一、三层分工

这是整套提示词工艺里最重要的一张表。

| 层 | 包含什么 | 写多少 | 为什么 |
|---|---|---|---|
| **外形层** | 脸、发、服装、体型 | **一句「按图」** | 参考图全覆盖；写细了与图打架，脸被拽跑 |
| **空间层** | 家具、陈设、尺度、门窗 | **只写站位与朝向** | 场景图覆盖；物件列多了尺度膨胀 |
| **氛围层** | 光位、光质、色温、空气介质、景深前景、材质高光 | **写到死** | 任何参考图都给不了；不写就是没有 |

**第三层是最容易被整体漏掉的。**

资产图是平光正对图——它锁得住「长什么样」，锁不住「被什么光照着、空气里有什么」。只写前两层，出来就是「有物件、有动作、没有空气」的塑料片。

### 常见误判

新手看到「提示词越详细越好」，就把人物外貌写三百字，结果：

- 脸被文字描述和参考图双向拉扯，出片四不像；
- 真正该写的氛围一个字没有，出片是均匀三点光的证件照。

**正确做法**：人物只写「按参考图」，把字数全花在光、介质、前景上。

## 二、氛围六件套

写在提示词开头（不是塞进镜头描述里，那会挤掉动作）。

| # | 件 | 写法 | 反例 |
|---|---|---|---|
| 1 | **光源与方向** | `一盏黄铜台灯在桌面右侧，暖黄光斜切过她的左脸` | `暖光` |
| 2 | **光质** | `硬光，边缘清晰，切过桌沿形成一条明暗分界` | `柔和的光` |
| 3 | **空气介质** | `细尘在光柱里浮动，可见光锥` | `空气中有氛围` |
| 4 | **色板三色** | `暖棕、琥珀、深木色，暗部压到近黑` | `暖色调` |
| 5 | **前景遮挡 + 景深** | `右下前景一只虚焦的青铜烛台，最近处轻微柔化` | `有景深` |
| 6 | **材质高光** | `桌面漆面有一处窄长高光，铜件边缘锐利反光` | `质感很好` |

**最少写第 1、3、5 三件。** 只有光位、没有介质和前景，仍然是「有打光的平片」。

### 空词必删

下面这些词不产生任何画面，只会回落到训练集平均值（均匀三点光）：

```
氛围感 / moody / cinematic / 电影感 / 大片质感 / beautiful / atmospheric / volumetric lighting
```

替换原则：**用具体名词替代抽象形容词。**

| 空词 | 换成 |
|---|---|
| 电影感光影 | 单侧硬光，光比 1:5，暗部保留细节 |
| 氛围感 | 薄烟横过光柱，光锥可辨 |
| 高级质感 | 哑光漆面 + 铜件锐边高光 + 织物绒毛可见 |
| 赛博感 | 青色霓虹在湿沥青上的反射，暖橙招牌作为唯一暖源 |

## 三、提示词结构

一条关键帧提示词按这个顺序组织（顺序影响模型权重）：

```
① 画风基底（一句，全集统一）
② 景别 + 画幅 + 角度
③ 空间与站位（谁在哪、朝哪、依托什么）
④ 氛围六件套（这里花最多字）
⑤ 主体与唯一动作的冻结瞬间（只写起点，不写终点）
⑥ 视觉重点（观众该看哪里）
⑦ 可读性约束（什么不能被遮住）
⑧ 排除项（不出现动作过程、不新增道具、不加可读文字）
```

### 示例

```text
国风条漫，墨线粗细分明，分层设色。

竖屏 9:16 大特写。机位在轴线东侧，平视，长焦压缩。

画面只装一双手和桌面边缘。右手五指扣在深色实木桌沿，指节泛白。

一盏黄铜台灯在桌面右侧，暖黄硬光从右下斜切，在手指上留下清晰边缘；细尘在光柱里浮动，
光锥可辨；右下前景是虚焦的清算书纸角，最近处轻微柔化；色板为暖棕、琥珀、深木色，
暗部压到近黑；桌面漆面有一处窄长高光。

指甲陷进掌心，一道细血线正从指缝渗出，停在掌纹的分叉处。

视觉重点在指缝那一道血线。

可读性约束：血线不被阴影吃掉；手指轮廓与背景桌面分开；四指与拇指关系清楚。

排除：不出现手臂以远的部分；不出现动作过程；不新增道具；不出现任何可读文字。
```

**注意第 ⑤ 段**：只写「血线正渗出、停在掌纹里」——这是**冻结瞬间**。如果写成「指甲陷进去，血渗出来，然后她松手」，那是动作过程，关键帧不该有。

## 四、画风基底：一集一句

整集所有关键帧用**同一句画风**。

不要在动作镜写「动态张力」，在对话镜写「柔和唯美」——那会让整集画风割裂。

### 漫剧画风词表（选一个，冻结）

| 画风 | 关键词根 |
|---|---|
| 赛璐璐动画帧 | 清晰轮廓线、平整色块、层数克制的硬边阴影 |
| 厚涂漫画 | 可见笔触、以明暗塑体积、软硬边随材质变化 |
| 平涂漫画 | 形体概括、有限色阶、弱化表面纹理 |
| 国风条漫 | 墨线粗细变化、分层设色、留白参与空间组织 |
| 日系二次元漫剧 | 简化面部体块、干净线稿、赛璐璐式表面分区 |
| 复古港漫 | 密集轮廓与排线、高反差色块、印刷颗粒 |
| 水彩叙事 | 纸面纹理、透明色层、轮廓局部晕开 |
| 极简叙事漫画 | 克制线条、大面积留白、低数量色层 |

**同集不许混。** 「国风条漫 + 厚涂」会让模型在两种渲染路径间跳，出片一半水墨一半油画。

### 光与色温也要统一

同一场景的所有镜头，用**同一句光与色温描述**。跨场景才换。

```markdown
- 顾氏总裁办·夜：台灯暖黄主光（3200K 感），窗外城市冷蓝作为补光，光比约 1:5
- 顾氏总裁办·日：落地窗自然光逆光，人物半剪影，色温偏冷
```

## 五、救平光片的三种方法

片子出来「没有氛围」「像塑料」，按顺序试：

### 方法一：换具体名词

把「电影感」「高级」全部替换成可数的物理事实。

```
❌ 电影级打光，氛围感强
✅ 一盏台灯在右，光锥可见，薄烟横过，前景虚焦烛台
```

### 方法二：给参考图也补氛围

如果用的是平光正对图，**加一条景深与光向描述**去覆盖它：

```
在参考图基础上：光源改为右侧单侧硬光，左脸入暗，背景虚化到只剩色块
```

注意：这会让「像不像参考图」变差一点，但「有没有氛围」变好很多。**取舍**：身份一致性靠锚点 + 图，氛围靠描述，两者不在一个维度上打架。

### 方法三：先出一张定调图

先出一张场景中远景（只有空间、光、气氛，没人），作为后续所有镜头的**最后一张参考图**，只取色调、光线与质感，不取构图。

这是成本最低的一致性手段。

## 六、参考图的作用边界

每张参考图能控制的东西是有限的，**写清「控制什么 / 不得控制什么」**：

| 用途 | 能控制 | 不能控制 |
|---|---|---|
| 身份 | 脸型、五官比例、体态 | 表情、动作、构图 |
| 造型状态 | 服装形制、材质、配色 | 姿态、光线 |
| 地理 | 空间布局、出入口、家具位置 | 人物、氛围 |
| 构图 | 占画比例、留白、机位 | 人物身份、动作 |
| 起始帧 | 起始构图、站位、姿态 | 尚未发生的动作、终态 |
| 风格 | 画风、笔触、色板 | 具体内容 |

**不给「不得控制」，模型会过度继承。** 用一张全身定妆照当身份参考，它会连站姿和构图一起抄过来。

## 七、抽卡与修复

关键帧一次过的概率不高，要有修复策略。

| 症状 | 病根 | 修法 |
|---|---|---|
| 脸不像 | 锚点写了但没挂图，或锚点与图冲突 | 挂身份图；锚点只写图里有的特征 |
| 一张脸变两次 | 同一镜里出现两个人 | 单镜单主体（见 `18-failure-atlas.md`） |
| 平光、塑料感 | 氛围层缺失 | 六件套补齐 |
| 手崩 | 手部在画面里占比过小或姿势复杂 | 手部单独出镜；或让手出画 |
| 场景尺度膨胀 | 空间层写多了 | 只写站位与朝向，物件靠场景图 |
| 画风跳 | 同集画风句不一致 | 统一画风句 |
| 多了奇怪的东西 | 抽象词被具象化 | 删掉所有比喻（见 `15-video-prompts.md` 词根清洗） |

### 修复优先级

```
先改提示词 → 再换参考图 → 最后才重画
```

大部分「画不好」是提示词问题，不是模型能力问题。

## 八、关键帧自检

- [ ] 有画风基底句，且全集统一？
- [ ] 外形层只有一句「按图」，没有长篇外貌？
- [ ] 空间层只写站位朝向，没有列家具？
- [ ] 氛围六件套至少写了光位、介质、前景三件？
- [ ] 没有任何「电影感/氛围感/高级质感」类空词？
- [ ] 冻结瞬间只写起点，没有写动作过程？
- [ ] 写了视觉重点（观众该看哪里）？
- [ ] 写了可读性约束（什么不能被遮）？
- [ ] 写了排除项？
- [ ] 参考图标了「控制什么/不得控制什么」？
- [ ] 连续性锁的锁面原样出现在正文里？

第 4、5、11 题决定成败。
