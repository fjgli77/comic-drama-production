# 包装、交付与复盘

前面十六篇讲的是"怎么把片子做出来"。这一篇讲**怎么让它被看到**。

残酷的事实：**封面决定点击，点击决定一切。** 一集画面精美但封面平淡的漫剧，播放量可能是同质量作品的十分之一。

这一篇分三段：包装（让人点）→ 交付（能发出去）→ 复盘（下一集更好）。

---

## 一、封面：第一道门

### 封面决定什么

```
曝光 → 封面 → 点击 → 前 3 秒 → 完播 → 追更
         ↑ 这一步淘汰掉 90% 的作品
```

平台给你曝光，但**是否点开由封面决定**。封面不行，后面的工艺全部归零。

### 三种有效封面类型

| 类型 | 构图 | 适用 | 为什么有效 |
|---|---|---|---|
| **人物特写** | 一张脸占画面 50–70%，眼神直视镜头，情绪极端 | 情感、复仇、虐恋 | 人眼对人脸有先天优先注意 |
| **冲突对峙** | 两人一左一右，中间留压迫感，动作在临界点 | 对抗、打脸、逆袭 | 观众想知道"谁赢了" |
| **结果前置** | 先给结果的冲击画面（满地血、跪着的人、燃烧的房） | 悬疑、复仇、灾难 | 制造"怎么会这样"的信息缺口 |

### 封面三要素（缺一即弱）

| 要素 | 说明 |
|---|---|
| **一张清晰的脸** | 观众要能认出主角是谁。脸部占画面至少 1/4 |
| **一个可见的冲突** | 不是"气氛"，是具体动作：掐住脖子、摔碎杯子、举刀 |
| **一个信息缺口** | 观众看不懂但想知道：为什么她在笑？他手里是什么？ |

### 硬规格

| 项 | 竖屏（9:16） | 说明 |
|---|---|---|
| 尺寸 | 1080 × 1920 | 与正片一致，避免二次裁切 |
| 安全区 | 上下各留 12% | 平台 UI 会盖住顶部和底部 |
| 主体位置 | 面部中心在画面上 1/3 处 | 缩略图裁切时能保住脸 |
| 文字 | 最多 6 字，压在画面下 1/4 | 缩略图里小字根本看不见 |

**封面文字越少越好。** 平台上封面缩略图只有约 120×213 像素，超过 6 个字就是一团糊。

### 五条常见错误

| 错误 | 后果 | 修法 |
|---|---|---|
| 人物全身入画 | 缩略图里脸只有指甲盖大 | 改成特写，脸占 1/4 以上 |
| 画面塞满元素 | 缩略图变噪点 | 删到只剩一个主体 + 一个背景层 |
| 文字占 1/3 版面 | 像微商海报 | 文字压到 6 字以内，或完全不用字 |
| 用氛围图（空镜、背影） | 没有信息，观众不知道点开看什么 | 换成有脸或有动作的图 |
| 封面与正片画风不一致 | 点进来觉得被骗，立刻划走 | 用正片的同一张关键帧改 |

**最省力的做法**：从成片里挑一帧最好的，裁成封面，加 4–6 字。不要另做一张。

## 二、标题

### 公式

```
身份 + 处境 + 悬念
```

| 例 | 拆解 |
|---|---|
| 「破产千金被逼下跪，管家掏出一张黑卡」 | 身份 + 处境 + 悬念物 |
| 「我死后第七天，丈夫娶了我妹妹」 | 状态 + 时间 + 反转 |
| 「扫地僧出手那刻，全宗跪了」 | 身份反差 + 结果 |

### 三条纪律

1. **≤ 20 字**。平台列表页会截断，超过 20 字后半句白写；
2. **前 8 字要有关键信息**。观众扫视只看前半；
3. **具体，不抽象**。「命运的转折」是废话，「管家掏出一张黑卡」是画面。

### 平台会限流的词

不同平台规则不同，但下面这些普遍高风险：

```
最、第一、顶级、绝对、永久、100%、根治、秒杀、震惊、速看、点击领取
```

还有：诱导性表述（「不看后悔」「99% 的人不知道」）、虚假承诺、医疗/金融承诺。

**标题里出现这些词，可能直接不进推荐池。** 宁可不刺激，也不要被限流。

## 三、前 3 秒：第二张封面

封面让人点进来，前 3 秒让人留下来。

### 三种有效开局（选一种，不要混）

| 类型 | 做法 | 适用 |
|---|---|---|
| **动作已在发生** | 第一帧就是冲突的高点，没有铺垫 | 大多数题材 |
| **反常画面** | 一个说不通的画面，观众要答案 | 悬疑、脑洞 |
| **台词轰炸** | 一句狠话直接砸出来 | 复仇、打脸 |

### 三条禁忌

- **禁止黑屏渐显**（0.5 秒就能损失 20% 观众）；
- **禁止空镜开场**（风景、天空、建筑）；
- **禁止旁白交代世界观**（"在这个世界上，有三大宗门……"）。

### 检验方法

把前 3 秒单独截出来，静音播放，给一个没看过的人看。

**他能不能说出"这里出事了"？** 说不出，重做。

### 十种可直接抄的开局写法

上面三种是策略，下面是能把策略写成提示词的具体句式。**前 2 秒是真正的分界线**——人的注意力在 0.5–2 秒之间就完成判断了，3 秒已经是宽容值。

| 技法 | 提示词句式骨架 | 用在 |
|---|---|---|
| **极特写切大远景** | 开场为〔水滴／尘埃／布料纤维〕的极限微距，0.5 秒处硬切〔场景〕大远景，对比度 100:1 | 悬疑、史诗 |
| **黑场接光爆** | 纯黑起。0.8 秒处〔左上角〕爆出一束强光，0.3 秒内金色铺满画面，镜头耀斑展开 | 逆袭、觉醒 |
| **逆向运动** | 前 2 秒动作倒放：〔物件〕逆向滑过画面，水滴向上飘，烟雾逆时针盘旋 | 脑洞、奇幻 |
| **熟悉物的陌生尺度** | 把〔布料纹理／混凝土气孔／叶脉〕当宏大风景拍，浅景深，观众 2 秒内认不出尺度 | 高级感开场 |
| **静默接巨响** | 前 1.2 秒完全静默（无对白、无音乐、最低环境音），1.3 秒突然〔枪响／玻璃碎／重音落下〕，画面同步硬切 | 悬疑、暴力 |
| **极端色移** | 画面以冷蓝灰起，0.6 秒处整体转为暖琥珀或霓虹饱和，0.4 秒完成 50% 色移 | 时空跳转 |
| **高速入画** | 〔人物／车〕从画面边缘（不是中心）高速入画，带引导线，视线被迫跟随 | 追车、冲撞 |
| **变焦转移** | 前后景起初都实，1 秒处焦点快速转到前景（背景全虚）或反向，等效 f/1.4 | 揭示、反转 |
| **眼睛睁开／锁定镜头** | 低照度下眼睛特写，0.8 秒处眼睛猛睁开或锁定镜头，可加瞳孔收缩 | 最原始的关注抓取 |
| **镜头翻滚** | 0–1.5 秒镜头快速翻滚 45°–180°，地平线倾斜，2 秒处回正 | "出事了"信号 |

### 叠加使用

强的开场不是选一个，是**叠两到三个**：

```
黑场静默（听觉）+ 光爆（视觉）+ 极特写转大远景（构图）= 三层同时抓
逆向运动（认知）+ 眼睛睁开（本能）+ 几何对比（构图）= 叠三层
```

**但不要叠超过三个**——超过三个，观众来不及处理，反而什么都不记得。

### 与分镜的接法

这十种技法**要写进第一个镜头的提示词里**，不是写进剪辑稿。

在 `13-storyboard.md` 里，第 1 镜的「职责」字段写「钩子」，然后在 `15-video-prompts.md` 的段首声明里落实技法句式。**不要指望后期剪出来**——模型生成的运动不对，剪辑救不回来。

## 四、简介与标签

### 简介结构（三行）

```
第 1 行：一句话说清这是什么故事（≤30 字）
第 2 行：主角的处境与目标（≤40 字）
第 3 行：更新信息（每周几更、共几集）
```

例：

```
破产千金被未婚夫当众退婚，家族一夜清零。
她手里只剩一张没人认识的黑卡，和三个不肯走的旧人。
每周三、六更新，共 24 集。
```

### 标签

| 选什么 | 数量 |
|---|---|
| 题材标签（复仇、逆袭、甜宠、悬疑） | 2–3 个 |
| 形式标签（漫剧、动态漫、AI 动画） | 1–2 个 |
| 情绪标签（爽、虐、燃、治愈） | 1–2 个 |

**不要堆满。** 标签超过 6 个，平台会认为你在蹭流量，反而降权。

## 五、成片规格

### 视频

| 项 | 竖屏 9:16 | 横屏 16:9 |
|---|---|---|
| 分辨率 | 1080 × 1920 | 1920 × 1080 |
| 帧率 | 24 或 30 fps（**全片统一**） | 同 |
| 码率 | 8–12 Mbps | 10–15 Mbps |
| 编码 | H.264（兼容性最好） | 同 |
| 容器 | MP4 | 同 |
| 色彩 | Rec.709 / sRGB | 同 |

**帧率必须全片统一。** 混用 24 和 30 会在某些设备上出现卡顿。

### 音频

| 项 | 规格 |
|---|---|
| 采样率 | 48 kHz |
| 位深 | 16 bit |
| 声道 | 立体声（单声道也可） |
| 响度 | -14 LUFS 左右（平台会做响度归一，太高会被压扁） |
| 峰值 | ≤ -1 dBTP（防削波） |

### 竖屏安全区

```
┌─────────────────┐
│  ← 顶部 12% 平台 UI（标题、头像）
│
│   核心画面区
│
│  ← 底部 20% 字幕 + 平台 UI（进度条、按钮）
└─────────────────┘
```

**人物眼睛不要放在上 12% 内**，会被顶部信息条盖住。

### 文件命名

```
剧名_EP001_竖屏_v3_20261115.mp4
```

带版本号和日期。改到第五版时你会感谢自己。

## 六、多平台适配

### 一版多发的原则

**做一个最严格的版本，其他平台直接复用。** 不要每个平台重出一版——成本翻几倍，一致性必崩。

最严格 = **竖屏 + 高码率 + 字幕留足安全区**。

### 平台差异

| 平台 | 画幅偏好 | 时长 | 注意 |
|---|---|---|---|
| 抖音 | 9:16 | 60–120s | 前 3 秒权重极高 |
| 红果 | 9:16 | 90–150s | 付费卡点在第 10–15 集 |
| 快手 | 9:16 | 60–120s | 下沉题材接受度高 |
| 番茄 | 9:16 | 90–180s | 网文改编，注意原著截取比例 |
| B 站 | 16:9 或 9:16 | 3–10 分钟 | 可承载复杂叙事 |
| 视频号 | 9:16 | 60–120s | 中老年受众 |

横屏项目发竖屏平台时，**不要简单裁切**——重新构一版竖屏封面即可，正片可以带黑边或做画中画。

### 水印位置

平台会自动加自己的水印（通常在右下或左上）。**你的 logo 不要放在同一位置**，会被盖住。

推荐：右上角，透明度 40%，尺寸不超过画面宽度的 12%。

## 七、AI 标识：位置与形式

**这是硬性合规项，不是可选项。**

| 项 | 要求 |
|---|---|
| **位置** | 每一集的**明显位置**（不是片尾小字） |
| **形式** | 文字标注「AI 生成」或平台提供的标识贴纸 |
| **时长** | 全程可见，或至少在片头 3 秒 + 片尾 3 秒 |
| **可读性** | 字号足够，对比度足够，不被其他元素遮挡 |

**推荐做法**：右上角一个半透明圆角标签，全程显示。既不干扰观看，又满足"明显位置"。

不要试图隐藏或用极小字号蒙混——平台有自动检测，被判定隐瞒的后果比不做标识严重得多。

## 九、数据复盘

### 看四个数，不看播放量

播放量是结果，不是原因。要看的是这四个：

| 指标 | 含义 | 低于基准说明什么 | 怎么改 |
|---|---|---|---|
| **封面点击率** | 看到封面后点开的比例 | 封面不吸引 / 标题没信息 | 换封面，改标题 |
| **3 秒完播率** | 看了 3 秒以上的比例 | 开局没抓住 / 前 3 秒是铺垫 | 重做开局 |
| **整集完播率** | 看完的比例 | 中段塌 / 节奏拖 | 砍中段注水，加微钩 |
| **追更率** | 看完后看下一集的比例 | 集末钩子不狠 | 重切集末 |

### 基准参考

不同题材差异大，但可以先看这几个量级（`craft_default`，非硬指标）：

| 指标 | 及格 | 好 |
|---|---|---|
| 封面点击率 | 5% | 10%+ |
| 3 秒完播 | 60% | 75%+ |
| 整集完播（120s） | 25% | 40%+ |
| 追更率 | 30% | 50%+ |

### 诊断顺序

```
点击率低 → 先改封面标题（其他都白搭）
3 秒低   → 改开局
整集低   → 改中段节奏
追更低   → 改集末钩子
```

**必须按顺序。** 点击率不行的时候优化中段，是浪费。

### 单变量原则

**一次只改一个东西。**

同时改封面和开局，你不知道是哪个起的作用。改了封面点击率上去了，下一集继续用这个封面策略；如果同时改了开局，你就无法归因。

### 连载的迭代周期

| 阶段 | 做什么 |
|---|---|
| 前 3 集 | 试封面与标题，找点击率最高的组合 |
| 4–10 集 | 固定封面策略，优化中段节奏 |
| 10 集后 | 固定节奏，优化集末钩子与追更 |
| 全季结束 | 复盘哪类钩子/封面/题材反应最好，用于下一部 |

**前 3 集不要急着优化工艺细节。** 那时候最该优化的是"有没有人点进来"。

- [ ] 封面是特写或冲突，不是氛围图？
- [ ] 封面文字 ≤6 字？
- [ ] 标题前 8 字有关键信息，且无限流词？

- [ ] 简介三行，带更新信息？
- [ ] 标签 4–6 个？
- [ ] 帧率全片统一？
- [ ] 响度与峰值符合规格？
- [ ] 人物眼睛避开了顶部安全区？
- [ ] AI 标识明显且全程可见？
- [ ] 文件名带版本与日期？
- [ ] 知道这一轮要优化哪个指标（单变量）？
