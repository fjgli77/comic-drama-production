# 小说转剧本

从一本小说到一集漫剧剧本，中间隔的不是"压缩"，是**换一套因果**。

小说用文字制造体验，漫剧用画面和声音制造体验。两者的区别不在篇幅，在**观众获得信息的方式**。

这一篇解决：这本书能不能改、怎么拆、拆完怎么切集、怎么保住原著的魂。

---

## 一、先判断值不值得拆

不要拿到书就开始拆。先做**改编价值快评**，十五分钟能出结论。

### 四问

| 问 | 合格的答 | 不合格的答 |
|---|---|---|
| **爽点密度** | 每 3–5 章有一次明确的情绪回报（爽/虐/甜/惊） | 大段铺垫，回报在三十章后 |
| **可视性** | 主要冲突能落在动作、对白、物证上 | 主要靠心理描写和内心独白推进 |
| **人物立场** | 核心 3–5 人有清晰的 Want 与对抗关系 | 人物众多但都在同一个立场 |
| **单集承载** | 任意一章能撑起 60–150 秒的完整冲突 | 一章的内容摊开只有气氛没有事件 |

**四问有两问答不好，先不要改。** 那不是工艺能救的，是材料本身不适合这个媒介。

### 抽样法

不必读完。抽三处：

1. **第 1–3 章**：看开局有没有能直接拍的事件；
2. **全书中段**：看中段有没有塌（很多网文中段是水）；
3. **口碑最高的那一章**：看读者真正买单的是什么（那才是要保住的东西）。

## 二、拆书：提取戏剧功能，不是缩写

拆书的目的是**知道每一段在故事里干什么活**，不是写一份剧情简介。

### 情节点四段式

每章提取若干情节点，每个一行：

```
P1 类型 | 白描 | 涉及：称谓、物件、地点 | 功能：这一步改变了什么
```

| 段 | 写什么 | 反例 |
|---|---|---|
| **类型** | 行动 / 对话 / 信息 / 转折 / 铺垫 / 兑现 / 状态 | — |
| **白描** | **原文已有的可观察事实**：谁做了什么、说了什么、什么被看见 | 「林风展现了自己的实力」 |
| **涉及** | 人物称谓、关键物件、地点 | — |
| **功能** | 改变了权力 / 信息 / 关系 / 暴露 / 资源 / 时间 / 代价中的哪一项 | 「为后文埋下伏笔」 |

### 白描必须去心理化

拆书时最容易滑进去的坑：把心理断言当成情节。

| ❌ 不是白描 | ✅ 是白描 |
|---|---|
| 通过对话，郑松得知张子豪在韩国训练 | 吴志斌告诉郑松，张子豪在韩国训练 |
| 邵阳感到心碎和愤怒 | 邵阳撞见宋丽与旁人相拥，脚步顿住，攥紧的拳头慢慢松开，转身离开 |
| 这一章为后文埋下伏笔 | 管家把一枚旧钥匙放进抽屉最里层，没有说明用途 |
| 林风这三年的隐忍终于有了回报 | 林风把辞职信放在桌上，转身走出办公室，没有回头 |

**原文是内心独白时**，照录那句话本身（「他在心里说这次真的完了」），不要替它总结心理状态（「他感到绝望」）。

### 载体记录：这一段靠什么传达

每章至少记一条，因为**它决定下游怎么改**：

| 通道 | 原文怎么写的 | 改编去向 |
|---|---|---|
| **可见行动** | 人物当场动手、亮物证 | 直接拍 |
| **对白** | 人物开口交锋 | 直接拍 |
| **心理叙述** | 内心盘算、回忆 | 改成可见动作 / 物证 / 短 VO |
| **叙述者旁白** | 作者总结背景 | 同上，或砍掉 |
| **信息密度** | 表面是日常，实则密集交代规则与死线 | **别当水章砍掉**（见下） |

**「信息密度」这一类最容易被误杀。** 例：兄妹俩刚赶走抢房的二叔，隔壁奶奶端来鸡肉炖蛋，妹妹吃两口推给哥哥，哥哥吃完取下墙上父亲留下的柴刀和猎矛，准备趁大雪封山前上山。

表面是日常吃饭，实则立住了三件事：邻里的善意、封山前必须进山换粮的死线、父亲留下的遗物。这种章砍了，后面全崩。

## 三、爽点表：决定切集顺序

**集数跟着爽点走，不跟着章节走。**

### 先列爽点

把全书让读者拍大腿的地方列出来，按强度排序：

| 爽点类型 | 例 | 观众回报 |
|---|---|---|
| 身份反转 | 扫地僧是隐世高手 | 震撼 |
| 打脸 | 被羞辱者当场碾压对方 | 爽 |
| 真相揭开 | 观众和主角同时知道真相 | 惊 |
| 情感兑现 | 暗恋多年的告白被回应 | 甜 |
| 绝境反杀 | 已被逼到墙角的人翻盘 | 燃 |
| 失去 | 明知要失去却无法阻止 | 虐 |

### 三条切集规则

| 规则 | 说明 |
|---|---|
| **一集至少一个爽点** | 没有爽点的章，并入相邻集或删掉 |
| **一集可含两个爽点** | 一章双爽点时拆成两集，比硬塞强 |
| **后文高光可提前** | 第 30 章的爆点可以提到第 3 集——前提是补齐前因（见第六节） |

### 第 1 集的特殊处理

第 1 集不能按顺序从第一章开始。

三种入口，选一种：

| 入口 | 做法 | 适用 |
|---|---|---|
| **时序入口** | 按原著顺序，但从最紧张的一刻切入 | 原著开头本身够硬 |
| **收益入口** | 把后文最强的一个爽点提到开头 | 原著前几章偏慢 |
| **冷开** | 先给一个结果画面（尸体/婚礼/爆炸），切回「三小时前」 | 悬疑、复仇、强反差题材 |

冷开切回正叙时，必须给时间定位：字幕卡「48 小时前」、同一物件的新旧状态对照、或一句台词点明。

## 四、改编契约：先划三条线

动笔前写下这张表，后面所有删改都要对得上。

| 类别 | 内容 | 处理 |
|---|---|---|
| **不可改承诺** | 核心人物的立场与性情、核心关系、主线、关键选择、结局含义 | 保持事实与功能 |
| **可换载体** | 叙述顺序、场景、配角、信息出现方式 | 可压缩/合并，但要记录替代关系 |
| **可删冗余** | 重复说明、只连接路程的段落、无新状态的复述 | 删，并说明没损失什么 |
| **未决歧义** | 原著自相矛盾、授权不清 | 保留问题，不替作者定案 |

**「不可改承诺」的第一条最容易出事**：把原著里帮主角的人改成害主角的人，观众会立刻弃剧。哪怕这样"更有戏剧性"。

要改，必须创作者明确接受，并写进契约。

## 五、压缩：先删线，再合并人

顺序反了会白干——合并完的人跟着被删的支线一起作废。

### 第一步：删支线

五条判据，逐条过：

| 判据 | 问什么 |
|---|---|
| **兑现依赖** | 它承载了后文的伏笔，还是正在兑现前文的承诺？ |
| **手段来源** | 主角是否靠它获得唯一的证据/盟友/权限/技能？ |
| **世界规模 vs 主线** | 只负责垫大世界广度、不推进主线的，优先删 |
| **信息落差** | 它是否承担「观众知而主角不知」的悬念？ |
| **孤儿铺垫** | 删线时，前文为它埋的铺垫有没有同步清理？ |

**最后一条最常被忘。** 删了 A 线，但第一章还在写"A 线专用道具"，观众会一直等一个不来的东西。

### 第二步：合并人物

只在**功能真的能合并**时才合。六项核对：

1. 两人是否**知情不同**？（合并会提前泄密）
2. 是否分属**施压方与支持方**？（合并会让对抗消失）
3. 是否承担不同的**伦理位置**？
4. 同一时点能否完成**两项行动**？
5. 合并后**背叛或牺牲**是否还成立？
6. 合并后**关系张力**还在吗？

### 硬合并 vs 保住因果的合并

**硬合并（断桥）**：
> 「配角太多，把门店会计和房东合并成一个人。」

问题：原著后文反转是「会计背着房东用假发票吃回扣，房东也被蒙在鼓里」。合并后变成「房东自己瞒自己」，逻辑崩了。

**保住因果的合并（先查秘密，再转交线索）**：
> 让舅舅房东兼管账目、承担当面施压；把「只有会计知道的假发票回扣」改由供货商发来的催款对账单揭开。

省掉一个配角，证据链还在。

## 六、信息视觉化：五级阶梯

**这是小说改编最核心的手艺。** 小说里「他知道」「她想起」「他明白」，在漫剧里必须换成能被看见或听见的东西。

按优先级从上到下选：

| 级 | 手段 | 例 |
|---|---|---|
| **1** | **行动后果** | 不报门牌，直接用旧钥匙开门 |
| **2** | **可争夺证据** | 缺页、录音、伤痕、持物、屏幕内容 |
| **3** | **空间与关系行为** | 谁挡出口、避开座位、退后半步错开触碰、改了称呼 |
| **4** | **对话策略** | 试探、误导、讨价、圆场、拒绝——而不是中性说明 |
| **5** | **声音/主观** | `[VO]` / `[OS]` / 主观画面 |

### 三个必改的例子

**例子一：前史综述 → 当场交锋**

小说：
> 父母过世后，二叔一家霸占了老宅和田产，逼兄妹俩签字画押，兄妹俩忍了三年……

漫剧：
> 直接从二叔踹开院门、把抵债婚书拍在石桌上切入。哥哥把妹妹护在身后，一手亮出父亲留下的老房契，一手拔出插在门框上的猎矛。

观众第一秒就看到：谁在欺负谁、主角手里有什么依仗。

**例子二：心理转折 → 改变处境的行动**

小说：
> 她看着冷掉的饭菜，想起三年来每个纪念日都是空等，终于彻底死心。

漫剧（按题材分两种改法）：

- **强冲突戏**：她把墙上圈着纪念日的台历撕下一页扔进垃圾桶，当着推门进来的丈夫面把失约短信摁灭。
- **克制生活戏**：她对着满桌冷菜静坐片刻，等丈夫进门时平静收起碗筷，把备用钥匙留在玄关柜上，进屋反锁房门。

**注意**：不要机械地改成「倒水、看窗外、摸旧物、攥拳头」——那些是假忙活，不改变处境。

**例子三：言行反差 → 保留短 VO**

有一类情况**不该**强行删成哑剧：当人物表面动作与真实盘算相反时。

例：假千金哭得梨花带雨替姐姐求情，真千金递纸巾，画外一句「她这滴眼药水比我进门时的茶水还烫」。

**保留一两句短 VO 与画面动作同框对撞**，比删光更有力。

## 七、保住因果桥

压缩时间后，按这条链核对：

```
原因事实 → 人物理解 → 选择 → 对手反制 → 可见后果 → 新压力
```

**任何一环断了，观众就出戏。**

被删的段落如果承担了「人物为何相信」「对手如何得知」「道具如何到手」，必须在新版本建立**等价的可见桥**。

| 原著里的桥 | 改编后可用的桥 |
|---|---|
| 用两页写她为什么信任他 | 一场戏：他把最后一块饼给了她，自己喝水 |
| 用旁白解释反派怎么知道计划 | 一个镜头：管家在门外听见了 |
| 用回忆交代信物来历 | 一次交接：母亲把镯子褪下来戴到她腕上 |

## 八、重排要登记

把后文提前、把顺序调换，都是合法操作。**但必须登记，否则后面接不上。**

`disposition` 九种取值：

| 值 | 含义 |
|---|---|
| `preserve` | 保留 |
| `merge` | 合并 |
| `change_carrier` | 换载体（同一功能，换一种呈现） |
| `compress` | 压缩 |
| `omit` | 删去 |
| `move_earlier` | 后文提前 |
| `cold_open` | 提作冷开，再切回原时序 |
| `add` | 新增（原著没有的） |
| `unresolved` | 待决 |

**标 `move_earlier` 或 `cold_open` 时，必须补齐三件事：**

1. **必要前因跟着提前**：被提上来的那一拍依赖哪条事实，在更早场次用可见动作埋下；
2. **时间定位与顺序衔接**：冷开切回正叙时用字幕卡/物件新旧对照/台词定位；
3. **处理被掏空的原位置**：原位置不能原样再演一遍——删掉、改成摊牌后的余波、或换另一个爽点顶上。

**第三条最常被忘，后果最常见**：把第 20 章的爆点提到第 3 集，结果第 20 集还在演同一件事，观众会觉得"怎么又来一遍"。

## 九、单集落地：从爽点到场次

一集确定后，落成场次：

```markdown
## EP001-SC001 内 · 顾氏总裁办 · 夜
```

每场必须有：

| 要素 | 问 |
|---|---|
| **目标** | 这场里谁想要什么（具体，不是「想变强」） |
| **阻碍** | 谁或什么在阻止（主动的，不是「运气不好」） |
| **结果** | 这场结束时局面变了什么（一句话说得出来） |
| **进集理由** | 删掉这场，这一集少了什么 |

第四问答不出来，这场不该存在。

**一场戏的字数参考**：60 秒集 250–300 字，120 秒集 500–600 字。超了说明有注水。

## 十、改编自检

- [ ] 四问快评过了，不是靠工艺硬救？
- [ ] 每章都提取了情节点，白描去心理化？
- [ ] 载体记录写了「靠什么传达」，心理叙述的段标了 `needs_carrier`？
- [ ] 爽点表列出来了，集数跟着爽点走？
- [ ] 第 1 集用了哪个入口（时序/收益/冷开）？冷开有时间定位？
- [ ] 改编契约四类都写了，不可改承诺没动？
- [ ] 先删线后合并人，五项/六项核对过了？
- [ ] 删线时孤儿铺垫清理了？
- [ ] 心理描写都走了五级阶梯，没有改成假忙活？
- [ ] 因果桥每环都接上了？
- [ ] 重排的都登记了，原位置处理了？
- [ ] 每场都有目标/阻碍/结果/进集理由？

第 6、9、11 题决定改编成败。
