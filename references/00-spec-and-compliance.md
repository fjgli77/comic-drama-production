# 规格、平台与合规

这一篇解决三个问题：**做多长、发哪里、能不能发。**

规格不是审美问题，是容器问题——容器选错，后面所有工艺都在为错误的目标服务。

---

## 一、单集规格：三条互相冲突的曲线

行业里流传的「单集 1–3 分钟」是一句被简化过的话。真实的约束是三条曲线的交点：

| 曲线 | 压力方向 | 后果 |
|---|---|---|
| **平台分发** | 越短越容易被算法推、越短完播率越高 | 太短讲不完一个完整冲突 |
| **付费转化** | 越长单集信息量越大、卡点越有分量 | 太长掉完播，前 3 秒白费 |
| **制作成本** | 越长镜数越多、返修面越大 | 长集是成本放大器，不是收益放大器 |

三者的交点大致落在 **90–150 秒**。这是 `craft_default`，不是硬门：

| 档 | 时长 | 适用 | 代价 |
|---|---|---|---|
| 快消档 | 60–90 秒 | 免费流量、平台激励、试水 | 只能承载一个冲突 + 一个反转 |
| **标准档** | **90–150 秒** | 绝大多数连载漫剧 | 平衡点，推荐默认 |
| 厚集档 | 3–5 分钟 | 付费卡点集、季播精品 | 镜数翻倍，一致性风险同步翻倍 |

**关键判断**：单集长度应该由「这一集要完成的戏剧任务」倒推，不是先定时长再往里塞内容。写不出来就合并集数，不要注水。

### 秒级结构（以 120 秒为例）

```
[00:00–00:05]  3 秒强钩      直切高潮 / 反常动作 / 强音效。禁黑屏渐显、禁慢摇风景
[00:05–00:15]  集头承接      回应上集悬念或本集开场状态，迅速建立当场危机
[00:15–00:50]  冲突一阶      事件展开、正面交锋，引出核心台词与关键视觉特写
[00:50–01:00]  30 秒微钩     新信息 / 细节翻转 / 怪异表情，对抗疲劳点
[01:00–01:45]  冲突二阶      矛盾到顶，底牌揭开或局势塌方
[01:45–02:00]  集末钩子      切在最难受的临界点：大招刚发、真相刚吐第一个字
```

这套结构是 `craft_default`。它的价值不在精确到秒，而在**三个强制位置**：开头必须有钩、中段必须有微钩、结尾必须切在临界点。中间怎么分配是创作自由。

## 二、分镜密度：格数、镜长、特写率

这三项决定「看起来是漫剧还是幻灯片」。

| 指标 | 60 秒 | 120 秒 | 级别 |
|---|---|---|---|
| 分镜格数 | 8–12 格 | 16–22 格 | `craft_default` |
| 平均镜长 | 5–7 秒 | 5–7 秒 | `craft_default` |
| 特写率（特写+近景占比） | ≥ 40% | ≥ 40% | `craft_default` |
| 单句台词字数 | ≤ 15 字（16:9 → 20） | ≤ 15 字（16:9 → 20） | `reviewed_invariant` |
| 单集总字数 | 250–300 字 | 500–600 字 | `craft_default` |
| 纯台词字数 | 120–150 字 | 240–300 字 | `craft_default` |

**为什么特写率是 40% 而不是更高**：漫剧的画面是半静态的，靠特写制造「这里很重要」的注意力锚点。但全片特写会让空间感消失、观众疲劳。40% 是「每 2.5 格有一个情绪落点」的经验值。

**为什么单句字数有硬上限**：这不像其他指标可以商量。原因不是审美，是**口型与配音的物理限制**——超过上限的句子在 2–3 秒的镜头里念不完，必然要么压镜长（破坏节奏），要么加速配音（破坏质感），要么砍句（破坏台词完整性）。三条路都通向返工。所以这条设为 `reviewed_invariant`。

**上限随画幅变**：9:16 竖屏 15 字，16:9 横屏 20 字。横屏的镜头通常更长、有更多呼吸空间，多出来的 5 字落在这段余量里。但**不要因此写长句**——20 字是上限不是目标。

> 注意区分：这是**单句**上限。一场戏里可以连续多句短台词，那不是长台词，是对白节奏。

## 三、监管：2026 年已经落地的四道闸

这一节不是免责声明，是**立项决策依据**。合规做晚了不是「补材料」，是「整部作废」。

### 3.1 时间线（已生效）

| 日期 | 事项 |
|---|---|
| 2026-04-01 | AI 微短剧实行「**先备案、后上线**」，未备案全网下架 |
| 2026-07-01 | 《管理提示（AI 微短剧分类分层标准）》按投资额分三级 |
| 2026-09-01 | 《微短剧发展管理办法》施行，首部专项部门规章 |

### 3.2 三级备案（按投资额）

| 档 | 投资额 | 审核主体 | 备案路径 |
|---|---|---|---|
| 重点微短剧 | ≥ 80 万元 | 广电总局 | 发许可证 |
| 普通微短剧 | 30–80 万元 | 省级广电 | 省级备案 |
| 其他微短剧 | < 30 万元 | 平台自审 | 报省级备案 |

**备案在立项阶段就要定档。** 因为投资额决定审核主体，审核主体决定周期，周期决定排期，排期决定要不要接这个活。

### 3.3 AI 标识（硬性）

- **每一集**的**明显位置**必须有 AI 生成提示标识；
- 不是片尾一行小字，是观众能看见的位置；
- 这条没有商量空间，且平台有自动检测。

### 3.4 内容红线（《办法》11 条 + 平台细则）

必须避开的：

- 渲染暴力、血腥、断肢的特写呈现；
- 宣扬拜金、奢靡、攀比；
- 丑化、亵渎英烈与公职人员；
- 未成年人不当呈现；
- 涉政、涉宗教敏感；
- 封建迷信作为现实指导（玄学题材需明确架空）；
- 侵权：未经授权的 IP、肖像、音乐、字体、素材。

**实操转译法**（不降低戏剧强度，只换呈现方式）：

| 原写法 | 转译后 |
|---|---|
| 刀刺入胸口，血喷涌 | 刀锋落下瞬间切到对方瞳孔骤缩，血溅在屏风上 |
| 断肢飞起 | 气浪震散，衣袍撕裂，人撞塌木架 |
| 尸体特写 | 一只手垂在画面外，血滴落在青砖上 |
| 割腕 | 手腕垂在浴缸边，水面泛红 |

原则：**保留因果与情绪，删掉器官级细节。** 观众知道发生了什么就够了，不需要看清组织。

## 四、真实的商业面（必须先看这个再做决定）

这一节会让人不舒服，但省掉它等于骗人。

### 4.1 数据

| 指标 | 数值（2026 上半年） |
|---|---|
| 全网新上线 AI 短剧 | 22.19 万部 |
| 播放破亿 | 1055 部（**0.47%**） |
| AI 漫剧爆款率 | **不足 0.1%** |
| 播放量低于 100 万 | 99% 以上 |
| 90% 以上漫剧公司 | 不赚钱 |

### 4.2 分账系数在收紧

| 平台动作 | 变化 |
|---|---|
| 抖音 AI 仿真人剧分成系数 | 60 → 40 |
| 动画漫剧分成系数 | 50 → 40 |
| 红果 AI 仿真人 | 取消保底，转纯分成（约 20%） |
| 真人 + AI 融合内容 | 最高可到 95% 分账 |

**平台在明确表态**：纯流水线堆量的内容收益被压到底，人机融合、有真人质感的进高档位。

### 4.3 平台正在打击的三件事

1. **高频 AI 脸**——同一张脸在多个作品反复出现，或角色之间高度雷同；
2. **同质化**——题材、结构、桥段批量复制；
3. **素材侵权**——参考图、BGM、字体来源不明。

这三条直接决定了本 Skill 的两个设计取向：**锚点必须个性化**（不是通用美人脸），**素材必须可溯源**。

### 4.4 由此推出的策略结论

| 如果你想… | 现实路径 |
|---|---|
| 试水、验证能力 | 免费流量号 + 平台激励，60–90 秒快消档，不投流 |
| 做连载、拿分账 | 必须有公司主体与制作资质，走备案，90–150 秒标准档 |
| 做出海 | 内容驱动替代成本驱动，角色与文化背景整体转换，不是换字幕 |
| 拿保底/流量倾斜 | 国风非遗、现实民生、正向题材的系数明显更好 |

**最重要的一句**：**工具替你做的是「手」，不是「脑」。** 这个赛道最值钱的能力是判断力——知道哪个画面能留人、哪句台词会勾起情绪。本 Skill 能保证工艺不出错，不能保证选题会爆。

## 五、平台适配速查

| 平台 | 单集偏好 | 特点 |
|---|---|---|
| 抖音 | 60–120 秒 | 前 3 秒定生死，完播率权重最高 |
| 红果 | 90–150 秒 | 付费卡点在第 10–15 集，过稿率严 |
| 快手 | 60–120 秒 | 下沉题材接受度高 |
| 番茄 | 90–180 秒 | 网文改编为主，要求原著截取比例合规 |
| B 站 | 3–10 分钟 | 可承载更复杂叙事，弹幕互动强 |
| 视频号 | 60–120 秒 | 中老年受众，题材偏家庭伦理 |

**多平台分发时，画幅与字幕安全区要按最严的那个做。** 不要为每个平台重出一版。

## 五·补、画幅决定阈值：同一条规则不能两档通吃

定了画幅之后，下面这几个数不是全局常量，是**随画幅变的**。

| 项 | 9:16 竖屏 | 16:9 / 21:9 横屏 | 为什么 |
|---|---|---|---|
| **单句台词上限** | ≤15 字 | ≤20 字 | 竖屏手机端阅读窗口窄、节奏快；横屏半精品有呼吸空间 |
| **单镜时长的下限** | 1.2 秒 | 2.0 秒 | 竖屏快切是常态，1.5 秒一镜不奇怪；横屏切太碎显得毛躁 |
| **空镜 / 留白** | **不鼓励**，要用必须标「刻意空镜」且 ≤1 秒 | 允许，是表现手段 | 竖屏拖节奏就是划走；横屏需要意境 |
| **多人背景的反应** | 要有，但保持一个动作 | 要有层次（不同人不同反应） | 竖屏画面小，看得到「有没有动」就够了 |
| **折算语速** | 4.2 字/秒 | 3.7 字/秒 | 竖屏是短句快切，横屏精品剧留气口；均按可发声字计 |

**这不是审美偏好，是媒介约束。**

9:16 的观众在手机上是「划」的动作，任何让他慢下来的东西都是成本；16:9 的观众多数在投屏或横屏端，愿意为氛围多等两秒。

所以机检里这几条带条件门（`X1` `S8` `Q1`），换画幅会自动改判。**同一个剧本换成另一个画幅，过检结论可能不同**——这是设计如此。

> 其他画幅的取值见 `scripts/cd.py` 的 `FORMAT_TUNING`：4:3 → 18 字 / 2.0 秒 / 3.8 字每秒；1:1 与 3:4 → 16 字 / 1.5 秒 / 4.0 字每秒。没登记的画幅回落到 15 字 / 2.0 秒 / 4.0 字每秒。
>
> 语速在 `estimate` 里按画幅自动取，也可 `--cps` 手动覆盖。

### 语速这个数是怎么来的

**不是拍的，是量的。** 几家独立实测的口径：

| 来源 | 中文语速 |
|---|---|
| AI 短剧产线实践 | 舒适区 4–5 字/秒，「太快像报菜名」 |
| TTS 工程实践 | 自然语速 4–5 字/秒，叙事段 speed 调到 0.9–1.05 |
| AI 配音调优 | 旁白 4.5–5，独白 3.5，争吵 6–7 |
| 系列化项目调研 | 对白：缓慢 3 / 日常 3.5 / 激烈 4；**4.5 只作极端上限** |
| 解说词换算 | 旁白 3.5–4 字/秒（每分钟约 210 汉字） |

取交集：**日常对白 4.0 字/秒是安全值，4.5 以上只在争吵与赶时间时用。**

> ⚠ **旧版本这个数写的是 5.5 / 5.8**，折算出来的时长会偏短三成左右。
> 按旧值排好的集，配音时必然赶词、字幕会截断、卡点会错位。
> 如果有按旧口径排过的项目，用 `estimate --cps 5.8` 复算对比，差异就是隐藏的赤字。

**口径提醒**：这里算的是**可发声字**——标点不计，语气助词按半字计。按「含标点的字符数」除以秒数，会得到偏高的假语速。

## 六、立项卡（P0 要填的东西）

```markdown
# 立项卡

- 片名：
- 题材 / 赛道：
- 档位：单集试水 / 多集连载 / IP 改编 / 归档复刻
- 集数：
- 单集目标时长：____ 秒（依据：____）
- 画幅：9:16 / 16:9
- 制作形态：二维动态漫 / 国漫二次元 / 风格化三维 / 水墨 / Q 版 / 条漫
- 目标视频模型：____（单段上限 ____ 秒 · 参考上限 ____ 项 · 原生音频 有/无）
- 素材形态：M0 / M1 / M2
- 投放平台：
- 备案档位：重点 / 普通 / 其他（依据投资额 ____ 万元）
- 商业目标：平台激励 / 分账 / 承制 / 品宣
- 一句话故事：
- 本片给观众的独特体验（不是"爽"，是具体的那种余味）：
```

最后两项是**反庸俗自审**。写不出来就先别开工——见 `01-story-engine.md`。
