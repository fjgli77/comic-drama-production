# 分镜：站位、轴线与镜头边界

分镜是整条管线的中枢。它决定三件事：**观众看到什么、生成端能执行什么、返修时改哪一镜。**

直接拿剧本喂模型 = 抽卡地狱。剧本是给故事用的，分镜是给生产系统用的。

---

## 一、场次站位：一场戏只写一次

一场戏拍成多镜时，**先写一次站位，再逐镜写相对变化。**

```markdown
## 场景站位 · EP001-SC001 · 顾氏总裁办
- 固定锚点：南墙北墙之间是深色长桌（桌面正中偏右）；门在北墙偏左；落地窗在南侧（画面背后）。
- 人物：沈惊歌站在长桌外侧，面对顾城，背对门口；顾城坐在桌后高背椅上，面向沈惊歌。
- 轴线：沈惊歌 ↔ 顾城；摄影机工作侧：长桌东侧（沈惊歌左手边）。
- 变化：EP001-SC003 老管家从北门入画，站到沈惊歌右后方。
```

### 四要素

| 要素 | 作用 | 常见错误 |
|---|---|---|
| **固定锚点** | 空间里的不动件与出入口 | 写「奢华的办公室」——那是形容词不是空间 |
| **人物** | 每人的位置 + 依托物 + 朝向 | 只写「A 和 B 对峙」，不写谁在哪 |
| **轴线** | 两人（或两组）的连线 + 摄影机常驻哪一侧 | 不写轴线，后面必然越轴 |
| **变化** | 哪一镜改变了站位 | 中途换位不写，下一镜就漂了 |

### 轴线：唯一必须守的空间纪律

**摄影机工作侧一旦定下，全段不许换。**

越轴为什么致命：观众会瞬间失去方位感——「她刚才在左边，怎么现在在右边了？」在 2 秒一镜的漫剧里，观众没有时间重建空间，只会觉得「乱了」。

需要越轴时（比如从对峙切到另一方主观），必须**用一个中性镜头过渡**（空镜、道具特写、全景），重新建立方位。不要硬越。

## 二、逐镜写法

```markdown
## SHOT-EP001-003 · 掐进掌心
- 来源：EP001-SC001
- 时长：3s
- 职责：让观众看见她在忍，且忍得很辛苦。
- 景别：大特写
- 角度：正侧（轴线东侧）
- 机位高度：平视
- 焦段意图：长（压缩，隔离主体）
- 运镜：固定；这一下她自己要被看见，机位不抢。
- 起点：右手五指扣在桌面边缘，指节正常肤色。
- 唯一动作：五指收拢，指甲陷入掌心，指节泛白，一道血线渗出。
- 终点：五指仍扣着，血线停在指缝。
- 声音：无对白；[SFX] 指甲压进皮肉的黏腻声，放大
- 视觉依据：《视觉设定.md》·人物「沈惊歌」（控制：身份、手部）；道具「清算书」（控制：纸张质感）
- 图片提示词项：IMG-SHEN-HAND《沈惊歌手部特写》（控制：手型、指甲、肤色）
- 输入参考图：PLAN-SHOT-START（顺序：1）· SHOT-EP001-003《本镜冻结关键帧》（用途：起始帧；控制：起始构图、手部姿态；不得控制：尚未发生的血痕）
```

### 起点 → 唯一动作 → 终点

这三行是整个分镜的骨架。**没有它们，模型不知道该从哪开始、到哪结束。**

| 行 | 写什么 | 常见错误 |
|---|---|---|
| 起点 | 镜头开始时**已经在发生的状态** | 写「她准备掐手心」——那是意图不是状态 |
| 唯一动作 | 一条可见的状态转换，含触发、方向、接触、落点 | 写「她心里很痛」——不可见；写「她掐手、咬牙、流泪、转身」——四件事，超载 |
| 终点 | 动作完成后的可见状态，逐项接住位置/双手/持物 | 写「她离开了」——那要一整个镜头 |

**「唯一动作」的「唯一」是硬约束。** 一个 2 秒镜头装不下两个动作。要装两个，就拆成两镜。

### 拆镜的正确切点

复杂动作要按**力学阶段**拆：

| 动作 | 错误拆法 | 正确拆法 |
|---|---|---|
| 推搡 | 拆成「推」和「倒」 | 拆成「到接触为止」和「从接触后状态起」 |
| 掌掴 | 拆成「抬手」和「扇下」 | **一镜写全**（短促动作拆开会失真） |
| 开门进入 | 拆成「推门」和「走进」 | 拆成「门推开一道缝」和「门内视角，人已站定」 |

**判断标准**：切点必须绑定一个**精确的可见状态**。切在「动作进行到一半」，两镜都生成不好。

## 三、景别：工作景别与离场

### 工作景别

一场戏有一个**工作景别**（通常是中景或中近景），大多数切镜在它上下一格来回。

```
开场：比工作景别宽一档（交代空间）
第二镜：落到工作景别
中段：在工作景别上下浮动
宽景/特写：标记事件，用过即回
场尾：略微放开，收住
```

**为什么不能一路收紧**：从全景一路切到特写，情绪会提前用光，到真正的峰值时没有余量了。

### 竖屏的高度代价

9:16 的纵向画幅很长，**俯仰会迅速压缩人物的可用高度**。同样 15° 的仰角，在竖屏里比横屏强烈得多。

所以竖屏表达权力差时，优先用：

1. **水平角度**（正面 vs 背面，谁挡谁）
2. **距离**（谁占画面更大比例）
3. **高度**——最后才用，且幅度要小

不要一上来就「俯拍压迫感」，竖屏里那一压，人就只剩个头了。

### 三轴分立，不许混写

| 维度 | 词表 | 回答什么 |
|---|---|---|
| **水平角度** | 正面 / 斜侧（四分之三）/ 正侧 / 后斜侧 / 背面 | 观众能读到多少表情，站在谁的一侧 |
| **机位高度** | 地平 / 低（仰）/ 平视 / 高（俯）/ 顶视 | 谁在这一刻大于谁 |
| **焦段意图** | 广（空间关系优先）/ 标准（接近肉眼）/ 长（压缩纵深） | 人与人的距离感 |

**混写的典型错误**：把「从她背后越过肩膀」写成「俯拍」——机位高度被误标，权力关系直接反转。

## 四、切镜必须带来变化

每一次切镜，必须至少带来一项：

- **信息**（观众知道了新东西）
- **权力**（谁占上风变了）
- **情绪**（情绪温度变了）
- **空间**（方位/距离变了）
- **节奏**（速度变了）

**一项都没有的切镜，删掉。** 同义重复的镜头是最常见的注水方式：A 说一句切到 B 的反应，B 说一句切到 A 的反应，来回六次——观众看到的是「两个人在聊天」，不是戏。

### 运镜：逐镜选，固定也要写理由

**「每镜必标运镜」不等于「每镜都要动」。**

对话段的主力是**固定机位 + 换嘴切镜**。15 秒的段落里最多 1–2 次微推，多了必然空间穿帮。

| 该动的时候 | 该固定的时候 |
|---|---|
| 揭示空间（推/拉/摇） | 表演本身承担信息（收手、抬眼、松手） |
| 跟随位移（跟） | 情绪需要观众自己看（不抢） |
| 情绪升温（缓推） | 对峙、静默、宣判 |

**运镜要带物理刻度**：不是「缓慢推近」，是「2 秒内推进 10 厘米」。模型需要具体数值才能执行。

## 五、镜长从哪来

**不要按剧本字数折算镜长。** 镜长由**这一镜里要发生的声音事件**倒推。

### 推导顺序

```
1. 这一镜有没有台词？有 → 台词时长 = 字数 ÷ 语速 + 0.45s 留白 + 0.6s 收口余量
2. 有没有音效事件？有 → 音效本身的时长
3. 有没有动作？有 → 按动作幅度给 1.8 / 2.2 / 3.0 秒
4. 三者取最大值，再加 0.3s 呼吸
5. 夹在 [2, 8] 秒之间（超出即拆镜或合并）
```

### 台词镜必须有余量

**镜长 = 台词时长 + 0.6 秒**，不是等于。

那 0.6 秒是开口前的吸气与收口后的落点。没有它，配音会顶到镜头边缘，剪辑时必须补帧，一补就露馅。

### 目标模型的原生时长

视频模型有单段时长限制（Seedance 2.0 约 15 秒，2.5 约 30 秒，H3 是 4–15 秒）。**单镜时长必须落在原生区间内。**

短于下限的镜头，向创作者提议把同场相邻镜头装进**多镜容器**（一次生成多个切点），不要硬拉长。

## 六、对白覆盖：怎么切一场对话

对话场不要「一句一切」。正确的节奏是：

```
双人全景（建立关系，3s）
  → A 过肩拍 B（A 说话，B 的反应在焦点外）
  → B 特写（B 的表情回应）
  → B 过肩拍 A
  → A 特写
  → 双人全景（情绪转折，收）
```

**过肩镜头是对话场的主力**，因为它同时装下「说话的人」和「听的人的反应」。

### 长对白的两个人不能丢

单段超过 15 秒、含两人对白交锋时，**严禁连续用孤立单人特写来回切**。

原因：视频模型的潜空间没有多轨剪辑记忆。单人特写持续几秒后，原角色的特征被冲刷，切回来就变脸或凭空消失。

解法：用**过肩机位或中景双人构图**，说话方清晰、听话方在前景虚焦但持续在场。

## 七、打戏：一时段一出手

打戏不是「把动作写细」，是**按回合拆**。

| 原则 | 写法 |
|---|---|
| **一时段一出手者** | `0–1.5s 他抡棍朝对方头顶劈下；1.5–3s 对方上身朝自己右侧一偏，棍擦着左肩落空` |
| **写路线与反应，不写接触形变** | 写「右拳朝他下巴方向挥过，他的头猛地朝左甩开，踉跄后退两步」，不写「拳头打在脸上、脸被打变形」 |
| **左右按人物自身写** | 「他的右拳」而不是「画面左边的拳」——机位一换就翻 |
| **接触瞬间单独成镜** | 特写只写承受者，拳脚从画外闯入，头顺来力甩开 |
| **贴身控制写两态** | 谁的哪只手臂箍住谁的哪里 → 松开或放倒，中间不写多步换手 |

### 打戏的合规转译

动作强度分三档，选档决定写法：

| 档 | 写法 | 适用 |
|---|---|---|
| R1 写实克制 | 接触瞬间切走，只留声音与反应 | 现实题材、平台审核严 |
| R2 商业高燃（默认） | 气浪、碎屑、衣袍撕裂、撞击定格 | 大多数漫剧 |
| R3 玄幻大招 | 光效、能量、天地异象 | 仙侠玄幻，需架空设定支撑 |

**不要写器官级细节。** 见 `00-spec-and-compliance.md` 的转译表。

## 七·补、群像镜：不许齐动，也不许齐不动

背景里的人是最容易被忘掉的部分。忘了会出两种完全相反的病：

| 病 | 症状 | 观众感受 |
|---|---|---|
| **齐动** | 「众人同时转头」「所有人一起后退」 | 像部队，不像人群 |
| **齐不动** | 背景人物站着，不做事、不反应、像个立牌 | 像贴图，假 |

**关键认知：禁止齐动 ≠ 允许齐不动。** 这两条不对称，只防一头会把病从这边搬到那边。

### 判据：每人在做一件不同的事

多人同框的镜，必须满足下面任一条：

```
① 每人写一件具体的事（可以很短）
② 显式声明这批人不动（「墙边两人双手交叉待命」已算给了事）
③ 显式声明无人（「除 @沈惊歌 外无其他人物」）
```

三条都不满足 → 群像缺失，机检 Q2 会报。

### 写法对照

| ❌ | ✅ |
|---|---|
| 众人站在两侧 | 墙边两名保镖双手交叉待命；门边一名助理低头看本子 |
| 大家都在看 | 前排三人看向屏幕，后排两人在低声说话 |
| 路人在旁边 | 换掉：把路人删掉，或给一个人「在收伞」 |

**注意第二条的边界**：「手头事务」不等于「有动作」。站着不动但手上有事（扶着门、端着托盘、捏着文件）就够了。真正要防的是「什么都没写」。

### 聚合词是危险信号

看到自己写下这类词，就停下来：

```
众人 / 大家 / 围观 / 在旁 / 周围人群 / 路人 / 一群人 / 学生们 / 员工们
```

**聚合词本身不是错，但它是个提醒**：写完聚合词要立刻回答「他们各自在做什么」。答不出来，就换成两三个具体的人。

### 什么时候可以不写

四种情况整条跳过，不用给事务：

- 打戏段（动作本身已占据画面）
- 纯特写（画不进那么多人）
- 密闭双人戏（没有第三个人）
- 已声明「四下无人」

**这也是 Q2 的关门条件**——不适用的场景不该被这条规则打扰。

## 七·补二、关键帧提示词的小节名是硬要求

机检（`X6`）按**节名**判断这一镜有没有关键帧提示词——只认名字里含「关键帧」或「提示词」的 `###` 小节。

写成 `### 备注`、`### 说明`、`### Prompt` 都算缺，哪怕里面有内容。

**为什么按节名而不按内容**：一镜下面可能有多个小节（站位说明、参考图备注、返修记录）。如果只看「第一个有内容的小节」，那把小节改个名就能绕过检查，而这一镜实际没有可用提示词。

约定只有一条：**`### 冻结关键帧提示词`**，全片统一。

## 八、分镜自检

- [ ] 每场都写了站位（锚点 + 人物 + 轴线 + 变化）？
- [ ] 每镜都有「起点 → 唯一动作 → 终点」三行？
- [ ] 「唯一动作」真的只有一个？拆成两条就分镜？
- [ ] 每次切镜都带来信息/权力/情绪/空间/节奏的变化？
- [ ] 一场戏有工作景别，没有一路收紧？
- [ ] 水平角度/机位高度/焦段分开写，没混？
- [ ] 竖屏戏没有滥用俯仰？
- [ ] 运镜带物理刻度？固定镜写了理由？
- [ ] 镜长由声音事件倒推，且落在模型原生区间？
- [ ] 台词镜有余量（≥0.6s）？
- [ ] 每镜有 `### 冻结关键帧提示词` 这一节（**节名要含「关键帧」或「提示词」**，机检按节名找）？
- [ ] 群像镜每人有「一件事」，或显式声明无人/不动？
- [ ] 竖屏戏没有用空镜做过渡（要用就标「刻意空镜」且 ≤1s）？
- [ ] 长对白用了过肩，没有连续孤立特写？
- [ ] 打戏一时段一出手，左右按人物自身写？
- [ ] 每个 `来源` 指向的场次真实存在？
- [ ] 剧本里每场都有镜头承载（没拍的场次写明了理由）？

第 2、3、9 题是 `structural_invariant`，机检会拦。其余是 `craft_default`。
