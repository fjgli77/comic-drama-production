# 武器资产：形制、握持与战斗可执行性

武器有两重身份，这是它比普通道具难的地方：

- **作为道具**：形制、材质、磨损必须跨镜一致
- **作为战斗载体**：长度、重量、握法、攻击轨迹必须能被动作执行

只做前者，打起来会飘；只做后者，形制会漂。

---

## 一、武器板比道具板多三样

普通道具四格板（正面 / 45°侧 / 顶视 / 细节）不够。武器必须额外有三样：

| 附加项 | 为什么 |
|---|---|
| **人体比例参照** | 不标长度，每次出图都不同——这一镜是匕首，下一镜变成长剑 |
| **握持区标注** | 手握在哪一段，决定发力方式与攻击半径 |
| **佩挂方式** | 挂在腰左还是背后，决定拔出的动作 |

### 完整七格

```
① 全长正视图（整体轮廓）
② 45° 侧视图（厚度与刃部截面）
③ 刃部/头部细节（开刃方式、血槽、纹样）
④ 护手与柄部细节（缠绕、铆接、配重球）
⑤ 握持区标注图（手放在哪一段，画出手的轮廓）
⑥ 鞘/收纳状态（如有）
⑦ 人体比例参照图（与成年人身高/手臂的对比）
```

**⑤ 和 ⑦ 是最容易被漏、也最影响下游的两格。**

---

## 二、长度必须给三重参照

只写「长约 110 厘米」不够。要给三种参照，模型才能稳定：

| 参照 | 写法 |
|---|---|
| **绝对长度** | 全长约 110 厘米 |
| **人体比例** | 立起时刃尖到成年人胸口，柄底齐腰 |
| **握持后的攻击半径** | 单手持握时，刃尖离身体约 70 厘米 |

**为什么三重**：模型对"厘米"的理解不稳定，对"到胸口"有身体经验。两个一起给，误差会收窄。

### 短兵与长兵的写法差异

| 类型 | 长度参照 | 攻击半径 | 镜头影响 |
|---|---|---|---|
| 匕首 / 短刀 | 刃长约等于手掌宽 ×2 | 贴身，肘部弯曲 | 适合特写，全镜可装下 |
| 单刀 / 剑 | 立起齐胸 | 单臂伸展 + 半步 | 中景可装下全身与刃尖 |
| 长枪 / 长棍 | 立起超头顶一头 | 双臂 + 跨步 | 中景装不下，必须留出画外空间 |
| 长柄斧 / 大刀 | 立起过头，刃部宽于肩 | 双臂 + 转身 | 全景才装得下 |

**长兵必须规划"出画"**：写「枪尖出画」比强行塞进画幅好。观众知道它长。

## 三、握持区：武器怎么被拿

| 部位 | 写什么 |
|---|---|
| **主握区** | 手掌覆盖的那一段（长度、是否有缠绕、是否缠绳） |
| **副握区** | 双手持时另一只手放哪（长兵必须有） |
| **护手** | 与手的关系（贴手背 / 离手两指 / 无护手） |
| **配重** | 重心在前端还是护手处（决定手感与动作幅度） |

### 重心决定动作

| 重心位置 | 动作特征 | 适用 |
|---|---|---|
| 护手处（配重球） | 灵活，可快速变向 | 剑、短刀 |
| 前端（重头） | 势大，收不住，靠惯性 | 战斧、锤 |
| 中段 | 平衡，可刺可劈 | 长枪 |

**写清重心，动作设计才有依据。** 不写，模型会让重斧像剑一样轻巧地转。

---

## 四、佩挂与出鞘

**佩挂位置决定拔刀动作，拔刀动作决定第一击。**

| 佩挂 | 拔出方式 | 适用 |
|---|---|---|
| 腰左，刃朝后 | 右手反手抽出，向上撩 | 刀、剑（右手使用者） |
| 背后交叉 | 越肩拔出，动作大 | 大剑、双刀 |
| 腰后横挂 | 侧身抽出 | 短兵、暗器 |
| 手持（不出鞘） | 无拔出动作 | 对峙、威慑 |

**写清佩挂，否则每一镜的刀都从不同地方冒出来。**

### 状态轨迹

武器像道具一样有状态：

```markdown
- 状态：入鞘（EP001-SC001）→ 出鞘（EP002-SC004）→ 刃口缺口（EP003-SC009）→ 断（EP005-SC002）
```

**不写状态轨迹，武器会永远保持初始样子。** 打了一整集，刃口一点缺口都没有，观众会觉得"没打实"。

## 五、五类武器的写法差异

### ① 刀剑类

| 要点 | 写法 |
|---|---|
| 刃口方向 | 单刃（刀）与双刃（剑）必须写清，刃筋朝哪 |
| 接触方式 | 压刃 / 滑刃 / 挑刃 / 偏转——见 `12-action-and-fight.md` |
| 反光 | **只写材质，不写光效**（「刃面呈哑光钢灰」不写「寒光一闪」） |
| 血槽 | 有就写位置与深度，没有写「无血槽」 |

### ② 长兵类（枪 / 棍 / 戟）

| 要点 | 写法 |
|---|---|
| 分段 | 头 / 杆 / 尾，各段材质可能不同 |
| 弹性 | 木杆有弯，铁杆没有——写清 |
| 出画 | 长兵必须允许出画，不强行塞满 |
| 双握 | 前后手位置，间距多少 |

### ③ 钝器类（锤 / 锏 / 骨朵）

| 要点 | 写法 |
|---|---|
| 质量感 | 写「下沉」「惯性大」「收招慢」 |
| 冲击 | 写「闷响」「震手」不写「血肉模糊」 |
| 形变 | 钝器**不写形变**（那是特效的事） |

### ④ 远程类（弓 / 弩 / 暗器）

| 要点 | 写法 |
|---|---|
| 发射动作 | 拉弦 / 上弦 / 甩腕，写清 |
| 弹道 | 直线还是弧线，飞行时有没有拖尾 |
| 命中 | 写「钉入」「擦过」，不写伤口特写 |

### ⑤ 法器 / 能量类

| 要点 | 写法 |
|---|---|
| 触发器 | 手势 / 法印 / 咒文 / 眼睛 / 装置——必须固定一个 |
| 能量光 | 颜色形状与武器一致，在触发/成形/飞行/命中各阶段都出现 |
| 规则 | 有代价、有冷却、有限制，不能想放就放 |

**法器的"光"要走 `11-vfx-and-particles.md` 的去水五律**——不写「粒子」写材质。

## 六、武器与角色的绑定

### 绑定表（每个持械角色一行）

```markdown
| 角色 | 武器 | 持用手 | 佩挂 | 握持习惯 | 备注 |
|---|---|---|---|---|---|
| 沈惊歌 | 无 | — | — | — | 非战斗角色 |
| 顾城 | 无 | — | — | — | 非战斗角色 |
| 黑衣人甲 | 短棍 | 右手 | 腰后横挂 | 单手，棍尾贴小臂 | 群演级 |
```

**战斗角色才建武器条目。** 非战斗角色不建——建了也没用，还会占图槽。

### "哪只手"必须固定

同一把刀，镜 1 右手、镜 5 左手、镜 9 又右手——观众会以为有两个人。

**一旦定了持用手，全片不改。** 要换手，必须有一个"换手"的动作镜头。

## 七、武器板的提示词

```text
请生成〔武器名〕的设定板，纯道具展示，画面中不得出现任何人物、手、肢体或人物剪影。

【形制】
全长约〔110〕厘米；立起时刃尖到成年人胸口，柄底齐腰。
〔单刃/双刃〕，刃筋朝〔…〕；〔有/无〕血槽。
护手为〔…〕；柄部〔缠绕麻绳/木柄/金属环〕，长〔约 20〕厘米，可容〔单/双〕手握持。
重心在〔护手前两指〕处。

【材质】
刃部：〔哑光钢灰，锻造纹理可见，边缘有细密研磨痕〕
柄部：〔深褐木，表面有长期握持形成的浅色包浆〕
护手：〔黄铜，边缘有细微磕碰〕

【状态】
〔出鞘/入鞘〕；刃口〔有一处米粒大缺口〕；〔无〕血迹。

【版式】
全图共 7 格，横向排列：
① 全长正视图　② 45°侧视图　③ 刃部细节　④ 护手与柄部细节
⑤ 握持区标注（画出成年人手的轮廓，标出主握区）　⑥ 鞘（如有）　⑦ 人体比例参照

纯白背景，柔和均匀影棚主光，克制的接触阴影。
禁止：人物、手（⑤格除外）、场景、拼图之外的额外视图、文字水印。
```

### 七格与 1+6 怎么选

七格是**按武器结构切**（全长、侧视、刃部、护手、握持、鞘、人体比例），适合单一形制的刀剑枪棍。

如果武器是**复合结构**——折叠弓、带机关的弩、多段拼接的长兵、带附件的枪械——七格装不下，改用 `09-prop-assets.md` 的「1+6 骨架」，按那张表改三处变量（主图加刃口方向、尺度格换三重参照、第 6 格换握持区与重心）。

**两种版式都遵守同一套工程纪律**（这套纪律是从设定板排版类 skill 借来的，比「出四格图」这种口头要求可靠得多）：

| 纪律 | 具体 | 为什么 |
|---|---|---|
| 模块化网格 | 明确写「严格网格布局、严格对齐」 | 不写，模型会给你错落的拼贴 |
| 极窄分隔线 | 5–8px 纯白，明确禁止圆角卡片与阴影 | 写了「卡片」就出 UI 感 |
| 标题条 | 深色半透明矩形 + 白色无衬线中文 | 让图自带说明，美术不用回来问 |
| 身份一致性句 | 「必须与主图保持完全一致的尺寸、颜色、材质、纹理、磨损、光线」 | 这句是六格不飘的唯一保障 |
| 满版无留白 | 「几乎没有外围留白」 | 留白多了单格信息量下降 |

### 反光禁止

**武器是最容易"发光"的资产。**

```
❌ 寒光一闪 / 刃面反射火光 / 杀气逼人的冷光
✅ 刃面呈哑光钢灰，边缘有细密研磨痕，不发光
```

任何与光产生描写关联的从句都会点火——见 `09-prop-assets.md` 的反光道具纪律。

## 八、常见错误

| 症状 | 病根 | 修法 |
|---|---|---|
| 刀忽长忽短 | 没给长度参照 | 补三重参照（绝对/人体/攻击半径） |
| 刀突然换手 | 没定持用手 | 绑定表固定，换手要有动作镜头 |
| 长兵塞不进画幅 | 强行塞 | 允许出画，写「枪尖出画」 |
| 重斧轻飘飘 | 没写重心 | 写「重心在前端，收招慢，靠惯性」 |
| 打了一整集刃口完好 | 没有状态轨迹 | 补「缺口/卷刃/沾血」的轨迹 |
| 武器自己发光 | 写了光效 | 只写材质，删掉所有光效从句 |
| 每镜刀从不同地方出来 | 没写佩挂 | 补佩挂位置与拔出方式 |

## 九、自检

- [ ] 只给战斗角色建武器条目？
- [ ] 给了三重长度参照（绝对/人体/攻击半径）？
- [ ] 标了握持区与重心位置？
- [ ] 写了佩挂位置与拔出方式？
- [ ] 有状态轨迹（入鞘→出鞘→破损）？
- [ ] 持用手固定，全片不改？
- [ ] 刃口方向与单双刃写清了？
- [ ] 反光只写材质，没有任何光效从句？
- [ ] 长兵允许出画？
- [ ] 法器有固定触发器与能量规则？

第 2、3、5、8 题决定武器能不能用。
