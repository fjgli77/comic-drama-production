# 镜头选型决策：这场戏该用什么镜头

> 这一篇补的是全流程里最容易漏的一层。
>
> `13-storyboard.md` 管「一镜怎么拆」（起点→动作→终点），`12-action-and-fight.md` 管「打戏怎么拍」。但两者之间缺一步：**这场戏为什么要这样拍？**

---

## 零、缺了这一层会发生什么

没有选型依据时，分镜设计靠临场发挥。后果是可预测的：

| 症状 | 病根 |
|---|---|
| 同一场戏两集拍法不同 | 每次重新想，没有依据 |
| 情绪曲线平 | 没有段落级的情绪规划 |
| 全片镜头「一个味道」 | 只会用自己顺手的几种机位 |
| 改稿时说不清为什么改 | 原本就没有理由 |

**有依据和没依据的差别**：前者改稿时能说「这里该用 E09 突破内心，你用了 E08 内向退缩，情绪方向反了」；后者只能说「我觉得不太对」。

---

## 一、情境映射：15 个情境

先判断这场戏属于哪个情境，再定镜头。

| ID | 情境 | 核心组合（锁死必用） | 典型场景 |
|---|---|---|---|
| **E01** | 主角觉醒 | 中景 + 低角度仰拍 + 缓推 | 废柴逆袭、顿悟、首次展现实力 |
| **E02** | 反派登场 | 全景 + 低角度 + 逆光剪影 + 静态 | 大反派亮相、权力者入场 |
| **E03** | 紧张追逐 | 手持呼吸感 + 长焦 + 快切 | 逃跑、追捕、时限紧迫 |
| **E04** | 审讯对峙 | 正面居中 + 长焦 + 静态 | 审问、法庭、谈判僵持 |
| **E05** | 孤独沉思 | 长焦 + 大光圈 + 空旷留白 | 独处、回忆、深夜自省 |
| **E06** | 暴怒爆发 | 全景 + 大光圈 + 手持快摇 | 摔东西、情绪失控、冲突爆发 |
| **E07** | 暧昧试探 | 长焦 + 大光圈 + 过肩静态 | 暗生情愫、欲言又止 |
| **E08** | 内向退缩 | 过肩 + 长焦 + 手持微动 | 自卑、回避、被压制 |
| **E09** | 突破内心 | 长焦 + 仰拍 + 缓推 | 鼓起勇气、下定决心、冲破心防 |
| **E10** | 仪式威严 | 对称居中 + 长焦 + 静态 | 婚礼 / 葬礼 / 加冕 / 审判 / 宣誓 |
| **E11** | 干脆决断 | 微距标点 + 静切动 | 掐烟、拍桌、落笔——道具特写接动作切换 |
| **E12** | 释放释怀 | 中景 + 俯拍 + 拉远 + 大景深 | 放下执念、和解、结尾舒缓 |
| **E13** | 异化失控 | 强对称居中 + 全景 + 缓推 | 精神失序、非人化、制度性压迫。**全片慎用** |
| **E14** | 被困压抑 | 头顶贴边 + 全景 + 静态 | 牢笼感、阶级压迫、被监视 |
| **E15** | 神性显现 | 背景过亮 + 逆光剪影 + 缓升 | 神迹、死亡瞬间、超验体验 |

### 最容易搞混的三对

| 对 | 差别 | 判据 |
|---|---|---|
| E01 觉醒 vs E09 突破内心 | 前者是**能力的**转变，后者是**心理的** | 有没有「他做到了」这个动作？有 → E01 |
| E02 反派登场 vs E10 仪式威严 | 前者**压人**，后者**中立** | 需不需要观众感到威胁？需要 → E02 |
| E06 暴怒 vs E12 释怀 | 都是大景别，方向相反 | 情绪在涨 → E06 手持快摇；在落 → E12 俯拍拉远 |

**选错情境的代价**：不只是画面不对，是**情绪方向反了**。E08 的内向退缩和 E09 的突破内心都是「长焦 + 仰拍」，但一个手持微动（不稳），一个缓推（推上去）——观众感到的是一退一进。

## 二、80/15/5：把自由发挥压到 20%

选定情境后，镜头设计按三层权重分配。这是本篇最重要的机制。

```
┌─ 核心组合（80%）—— 锁死，全部必须用 ─────────────┐
│ 情境表里「核心组合」那一列                              │
│ ❌ 不许替换、不许删、不许自由发挥                        │
└────────────────────────────────────────────────┘
┌─ 辅助锚点（15%）—— 选 1~2 个 ─────────────────┐
│ 从该情境的辅助锚点里挑，不能自己发明                      │
└────────────────────────────────────────────────┘
┌─ 增强项（5%）—— 一段最多 1 个镜头用 ────────────┐
│ 只给情绪峰值那一镜                                      │
└────────────────────────────────────────────────┘
```

**设计意图：把「能自由发挥」的空间从 100% 压到 20%。**

核心组合锁死保证跨集稳定性，辅助和增强保留创作弹性。

### 为什么这条有用

没有权重机制时，AI 或新手会把每个镜头都当成「自由创作」，结果：
- 该稳的地方不稳（核心机位每次都不一样）
- 该有变化的地方没变化（永远同一套）

有了 80/15/5，**同一场戏交给两个人做，出来的骨架是一样的**，只在气质上有差异。这才是可复用的流程。

### 一条纪律：核心组合不许优化

看到「E04 审讯对峙 = 正面居中 + 长焦 + 静态」，第一反应往往是「正面居中太死板，改成斜侧吧」。

**不许改。** 正面居中在审讯里是有意义的——它制造「面对面被逼问」的压迫感，同时是双人对峙的对称结构。改成 30° 斜侧，压迫感就散了。

如果确实需要改，走雷区解锁流程（见下一节），并且写明解锁理由。

## 三、构图雷区：A 类可解锁，B 类永不解锁

这是整套里最实用的一张表。**雷区不是绝对禁令，是「默认禁止 + 特定情境解锁」的双态系统。**

### 判定口诀

> **这个「错误」有没有艺术上的理由？有 = A 类；没有 = B 类。**

### A 类 · 艺术性雷区（7 条，可解锁）

| # | 雷区 | 默认理由 | 什么时候可以解锁 |
|---|---|---|---|
| **A1** | 正面居中 | 舞台感、破第四面墙、视觉平庸 | 异化时刻（E13）/ 仪式（E10）/ 对峙凝固（E04）/ 直视镜头击穿第四墙 / 强对称作者风格 / 权力凝固（E02） |
| **A2** | 头顶贴边 | 视觉压迫不适 | 天花板压住（E14）/ 阶级压迫 / 监视感 |
| **A3** | 主体永远压中线 | 构图平庸、缺张力 | 强对称风格 / 仪式 / 权力结构表达 |
| **A4** | 眼神无空间 | 视线指向画外但该侧没留白，看着憋 | 表现「无路可走」/ 封闭心理 |
| **A5** | 框边切在关节处 | 断手断脚感 | 暴力美学 / 强调身体受创 |
| **A6** | 背景比主体亮 | 主体被吃掉 | 神性显现（E15）/ 逆光剪影风格 |
| **A7** | 多人正面平铺 | 像合影 | 仪式宣誓（E10）/ 集体表态 |

**解锁后的强制约束**（缺一不可）：

1. 配套结构：如 A1 解锁后必须配「对称布景 + 静态运镜 + 长焦压缩」
2. 通用后缀补词：如「强对称构图 / 仪式感 / 风格化」
3. **写明解锁理由**：哪一条白名单、对应哪个情境 ID

**只解锁不写理由，等于没解锁。** 下一集的人看到「正面居中」会以为你忘了规则。

### B 类 · 工程性雷区（7 条，永不解锁）

这些是 AI 生成的**技术错误**，艺术上没有任何保留理由。

| 雷区 | 症状 | 强制规避（写进限制字段） |
|---|---|---|
| **物体穿身** | 树枝 / 灯柱从头顶长出 | 背景物体不与角色身体重叠 |
| **服装突变** | 上一镜白衣下一镜灰衣 | 服装发型与上一镜完全一致 |
| **前景刺眼物** | 虚化里出现光斑、反光板边缘 | 前景虚化中无刺眼光斑异物 |
| **比例失调** | 手比头大、多手指、透视错乱 | 身体各部位比例符合解剖学 |
| **重复元素无重点** | 背景多个相同物，画面没主次 | 背景元素有主次层次 |
| **空鸡蛋构图** | 主体周围全空，无视觉支撑 | 加前景物件或框架式构图 |
| **道具状态突变** | 杯里水量、烟头长度跳变 | 道具状态与上一镜延续 |

**B 类出现 = 必修 bug，任何情境都不保留。**

### 多人构图（A1 / A7 的衍生）

| 雷区 | 默认规避 | 可解锁 |
|---|---|---|
| 眼睛同高 | 用站 / 坐 / 俯仰角制造高低差 | 仪式、法庭（A7） |
| 一字排开 | 三角形构图 / 前后景纵深 | 仪式宣誓（A7） |
| 视线散乱 | 至少两人共同看向焦点 | 表现集体困惑可保留 |

### 微距 / 特写（无解锁，是必填项）

| 雷区 | 规避 |
|---|---|
| 主体不明 | **必须写明「X 占满画面」** |
| 失焦 | 写明焦点在哪：「焦点在烟头红色火星」 |
| 杂物入画 | 「画面中只有〔指定物〕，无其他物件」 |

微距没有「要不要」的问题——不写清主体和焦点，出来就是一团虚。

## 四、情绪锚点表

一段戏开机前，先填这张表。它比分镜早一步，决定节奏。

| 列 | 填什么 |
|---|---|
| 段落号 | SC001 / SC002 |
| 情绪起点 | 这场戏开头观众该在什么状态 |
| 情绪落点 | 结尾推到哪 |
| 拐点位置 | 在第几拍转向 |
| 情境 ID | E01~E15，可多段用不同 ID |
| 峰值镜 | 哪一镜是峰值（也是 5% 增强项唯一允许的地方） |

**为什么值得单独填**：分镜是按镜写的，容易「一镜一镜都还行，连起来没有起伏」。锚点表是按段落填的，逼你先看曲线。

## 五、接进分镜流程

```
剧本（这场戏说什么）
    ↓
情境判断（E01~E15，这场戏属于哪种）
    ↓
情绪锚点表（起→拐→落）
    ↓
80/15/5 分配（核心锁死 / 辅助选 1-2 / 增强给峰值）
    ↓
雷区检查（A 类要理由，B 类写进限制）
    ↓
13-storyboard.md（拆成一镜的起点→动作→终点）
```

**在 `分镜.md` 里怎么落**：

每场戏开头加一行元信息：

```
> 情境：E04 审讯对峙 · 情绪：压 → 崩 → 冷 · 峰值：SHOT-012 · 解锁：A1（理由：对峙凝固）
```

这一行不超过 40 字，但它让后面所有镜头都有了理由。

- [ ] 情绪锚点表填了起 / 拐 / 落？
- [ ] 相邻两场没有用同一个情境 ID（会平）？
