# 剧本：分镜式双轨格式

漫剧剧本要同时被三种人使用：**生图/画师看画面，CV 看台词，后期看声效。** 传统电影剧本的大段散文描述会让三方全部对接失败。

解法是**双轨物理分离**：画面归画面，声音归声音，谁也不许混进对方的字段。

---

## 一、格式

```markdown
# EP001 清算日

## EP001-SC001 内 · 顾氏集团总裁办 · 夜

### 画面轨
- 一只颤抖的手按在铺着白色桌布的餐桌上，指节泛白。
- 一叠破产清算书上印着猩红的「清算完毕」钢印，纸边卷起。
- 沈惊歌脸色苍白，嘴角挂着一抹挑衅的冷笑。

### 听觉轨
- 沈惊歌（声音微颤，字字清晰）：顾城，这是沈家最后的资产了。
- [SFX] 红酒杯被重重顿在桌面上，酒液溅出
- [BGM] 大提琴独奏，此处渐弱

## EP001-SC002 内 · 同前 · 连续

### 画面轨
- 顾城靠在真皮椅背上，缓慢转动小指上的黑曜石尾戒。
- 他居高临下俯视，眼里是玩弄。身后两名保镖双手交叉，面无表情。

### 听觉轨
- 顾城（讥讽，漫不经心）：沈大小姐，现在跪下求我，还来得及。
- [SFX] 皮椅受压的轻微吱声
```

### 语法约定

| 元素 | 写法 | 机检 |
|---|---|---|
| 集标题 | `# EP001 集名` | 必须有集号 |
| 场次标题 | `## EP001-SC001 内/外 · 地点 · 时间` | ID 必须唯一，空间性质必须是「内/外/内外」 |
| 画面轨 | `### 画面轨` 下用 `- ` 列表 | 每场必须非空 |
| 听觉轨 | `### 听觉轨` 下用 `- ` 列表 | 可为空（纯视觉场） |
| 对白 | `角色名（语气提示）：台词` | 冒号必须是全角「：」 |
| 画外音 | `[VO] 角色名（语气）：台词` | 内心独白/旁白 |
| 画外对白 | `[OS] 角色名（语气）：台词` | 人在画外但世界内发声 |
| 音效 | `[SFX] 描述` | — |
| 音乐 | `[BGM] 描述` | — |
| 画面文字 | `[画面文字] 内容` | 手机屏、招牌、文件上的可读字 |
| 转场 | `[转场] 切 / 闪白 / 叠化` | — |
| 连续性 | `[连续性] 描述` | 跨场必须保持的物理事实 |

**为什么对白不用 `【台词】` 前缀**：因为一行里「角色名（语气）：台词」自身已经唯一可识别，加前缀是冗余。机检认的是「行首是已知角色名 + 全角冒号」。

## 一·补、台词长度随画幅变

单句台词上限不是固定的 15 字：

| 画幅 | 上限 | 理由 |
|---|---:|---|
| 9:16 竖屏 | 15 字 | 手机端阅读窗口窄，长句要扫两遍 |
| 16:9 / 21:9 | 20 字 | 投屏端视野宽，容得下一句完整的话 |

**同一句话在两个画幅下可能一句过检一句不过。** 这不是规则不一致，是媒介不一致。详见 `00-spec-and-compliance.md` 第五·补节。

## 二、五条写作红线

这五条不是风格建议，是**漫剧媒介属性决定的物理约束**。

### 红线 1：禁心理描写

漫剧的画面是半静态的，没有表演去承载「心里涌起一阵绝望」。写心理 = 画不出来 = 制作端只能瞎猜。

| ❌ | ✅ |
|---|---|
| 林默看着合同，心里涌起绝望，他意识到自己被骗了。 | 林默捏着合同，指节因用力发白。纸张被捏得发皱。 |
| 她终于明白父亲的苦心。 | 她站了一会儿，把外套脱下来，盖在父亲身上。 |

**检验法**：这句话能不能被摄影机拍到？拍不到就删。

### 红线 2：禁括号暗示

括号里解释潜台词 = 把戏说破了 = 观众失去发现的权利。

| ❌ | ✅ |
|---|---|
| 苏晴：好吧，我答应你。（其实她是为了拿到优盘） | 苏晴顺从地低下头。她的视线死死盯住顾城西装口袋露出的优盘边缘。 |

### 红线 3：禁死空间

写了画不出来、也发不出声的东西，就是死空间。

| ❌ | ✅ |
|---|---|
| 现场弥漫着十年商战沉淀下来的杀气。 | [SFX] 死寂。一滴汗落在实木会议桌上，被放大。 画面轨：对面五个高管集体低头，双手紧扣。 |

### 红线 4：禁 AI 腔

| ❌ | ✅ |
|---|---|
| 「我当年作为林家大少，就是因为被你设计陷害，才不得不隐姓埋名去了国外十年，如今我回来了，就要让你付出代价！」 | 「十年了。顾总还认识这张脸吗？」 |
| 「哈哈，呵呵，啊，哦」等无意义语气词 | 直接删。用动作代替停顿。 |

**AI 腔的三个特征**：信息密度过高（一句话交代全部前史）、对称排比（三句一顿）、书面语（「此刻」「然而」「不禁」）。

### 红线 5：禁解释性台词

角色不该说出双方都已经知道的事。那是写给观众看的说明书，不是对话。

| ❌ | ✅ |
|---|---|
| 「你是我的秘书，你跟了我三年，你知道我所有的秘密。」 | 「三年了。」她把咖啡放在他手边，没有立刻走开。 |

## 三、台词纪律

### 3.0 七维：先分诊，再改

台词写不好，通常不是"不够精彩"，是**某一维塌了**。七维分开看，才知道改哪。

| # | 维度 | 问什么 | 怎么判 |
|---|---|---|---|
| ① | **长度与可念性** | 一口气念得完吗 | 机器可判（字数） |
| ② | **语气位** | 配音知道怎么念吗 | 机器可判（有无括号） |
| ③ | **信息量** | 这句给了新东西吗 | 半自动（见 3.5） |
| ④ | **推进力** | 说完之后局势变了吗 | 人工（见 3.6） |
| ⑤ | **潜台词** | 说的是不是想说的 | 人工（见 3.3） |
| ⑥ | **人物辨识** | 换个人说会不会一样 | 半自动（见 3.4） |
| ⑦ | **可演性** | 配得上一个动作吗 | 人工（见 3.7） |

```bash
python scripts/cd.py lines ./my-drama --episode EP001
```

它会逐句判①②，并对③⑥给出可疑标记；④⑤⑦只能人判，命令会输出一张空表让你填。

**判定顺序**：先①②（不合格的直接改，别的维度白谈）→ 再③④（信息与推进是骨架）
→ 最后⑤⑥⑦（这三维决定好不好看）。

**七维全满分的台词不存在。** 一集里有 2~3 句接近满分就够了，其余只要不塌。

---

### 3.1 长度与可念性（`reviewed_invariant`）

这不是审美，是物理限制。2–3 秒的镜头装不下超限的句子，硬塞的后果是三条路都烂：

- 压镜长 → 破坏节奏；
- 加速配音 → 破坏质感；
- 砍句 → 破坏台词完整性。

**长内容怎么处理**：拆成多句短台词，中间插一个动作或一个反应。但插的动作必须**改变战术**，不能是「看了一眼」这种填充。

```
❌ 一句 28 字：「我知道你恨我，但是当年那件事不是我做的，是有人在背后操纵，你信不信我？」
✅ 三句 + 一个动作：
  「我知道你恨我。」（她没抬头。）
  「当年那件事，不是我做的。」
  「有人在背后操纵。」（她终于抬头，看着他。）
```

### 3.2 语气位：怎么念

对白的括号里必须写清怎么说。没有语气位的台词，配音演员只能猜，猜错的概率极高。

| 语气位的维度 | 例 |
|---|---|
| 音量 | 低声、嘶吼、气声 |
| 速度 | 一字一顿、急促、慢悠悠 |
| 质地 | 沙哑、清亮、发颤、冷硬 |
| 态度 | 讥讽、居高临下、恳求、试探 |

**关键规则**：语气位必须与画面动作一致。宣判式的冷硬台词，配「把玩玉佩」这种闲适动作，必出戏。

### 3.3 潜台词：对话是冰山

角色说出来的只是水面上的十分之一。

| 直白（on-the-nose） | 潜台词 |
|---|---|
| 「我很害怕失去你。」 | 「你走的时候把那件外套带上。……外面冷。」 |
| 「我原谅你了。」 | 「碗我洗了。你的那份在锅里。」 |
| 「我们是敌人。」 | 「下次见面，我不会留手。」（然后替他挡了一刀） |

**检验法**：把所有台词删掉，只看画面轨，故事还成立吗？成立说明画面承担了叙事。不成立说明台词在替画面干活——那就要改画面。

### 3.4 人物辨识：换个人说会不会一样

不同角色说话方式必须不同，否则读者要靠「XX说」才知道谁在讲。

三个可调的旋钮：
- **句长**：有人只说短句，有人爱绕；
- **用词**：有人满口术语，有人全是脏话，有人文绉绉；
- **回避方式**：被问住时，有人反问，有人沉默，有人转移话题。

给每个主要角色定一条「说话指纹」，写进视觉设定（配音也要用）。

**可数化**：每个人的**平均句长**要拉开 2 字以上，且至少有一个**专属用词习惯**
（口头禅、称呼方式、骂人方式）。两句都拉不开，观众只能靠"XX 说"分辨。

---

### 3.5 信息量：这句给了新东西吗

**每句台词至少要给一样新东西**：一个人、一件事、一个物件、一个时间、一层关系。

| 类型 | 例 | 给了什么 |
|---|---|---|
| 事实 | 「他昨天就退房了。」 | 时间 + 状态 |
| 关系 | 「我是他师姐。」 | 关系 |
| 物件 | 「钥匙在他那儿。」 | 物件 + 持有者 |
| 规则 | 「这里不许提那个名字。」 | 世界观约束 |
| 情绪转折 | 「你终于肯叫我了。」 | 关系变化 |

**什么都没给的句子叫"回声"**——它只是把上一句换个说法重复一遍。

```
❌ 甲：你走吧。  乙：我真的要走了吗？  甲：是的，你走吧。
✅ 甲：你走吧。  乙：那我把钥匙留下。  甲：（没接）
```

**密度参考**：一集里"回声句"不超过 15%。超过就是水词。

### 3.6 推进力：说完之后局势变了吗

**一句有推进力的台词，会让下一句的可能性变少。**

判据很简单——**删掉这句，后面的戏还成立吗？**

- 成立 → 这句是描述，不是推进；
- 不成立 → 它在推动。

```
❌ 「我们家以前很穷。」（删掉，后面的戏一样成立）
✅ 「房产证上写的是你哥的名字。」（删掉，后面整场争产戏不成立）
```

**短剧的容错比长片低**：长片可以有整场"生活流"，短剧每 15 秒就要有一次局势变化。
一集 60 秒，至少 4 个推进点。

### 3.7 可演性：配得上一个动作吗

台词不是念出来的，是**做**出来的。一句配不上任何动作的台词，演员只能站着念。

**测试法**：给这句台词配一个身体动作，配不上就要改。

| 台词 | 能配的动作 |
|---|---|
| 「你手抖了。」 | 伸手按住对方的手 |
| 「我记得你怕黑。」 | 把灯打开 |
| 「钱我不要了。」 | 把信封推回去 |
| 「我一直在这儿。」（配不上动作） | ← 改 |

**最后一句的问题不是不感人，是它没有落点。** 改成「这三年，我每天都来」——可以配"推开门"。

**一条实用规则**：情绪最重的台词，必须配**最轻的动作**（放杯子、关门、系扣子）。
情绪与动作同向（大哭 + 摔东西），观众会觉得在演。

## 四、时长折算：从字数到秒

写剧本时就要知道这一集多长。不要等分镜才发现超了。

### 折算公式

```
单句时长 = 台词字数 ÷ 语速 + 句末留白
```

| 参数 | 值 | 说明 |
|---|---|---|
| 中文语速 | 4.0 字/秒 | 日常对白安全值（快 4.6 / 慢 3.5；4.5 以上只用于争吵赶时间） |
| 句末留白 | 0.45 秒 | 换气 + 情绪落点 |

**动作行的折算**（`craft_default`）：

| 动作类型 | 关键词 | 秒数 |
|---|---|---|
| 位移 | 走、跑、冲、起身、转身、推门 | 3.0 |
| 小幅动作 | 抬手、转头、点头、摇头、伸手、落座 | 2.2 |
| 微动 / 静帧 | 其他 | 1.8 |

动作秒数是「这一拍在成片里占多久」，不是「演员做这个动作需要多久」。一场静默对峙可能有 5 秒，但动作描述只有一句「他一动不动」——那要靠镜长承载，不能靠文字量。

### 用脚本算，别心算

```bash
python scripts/cd.py estimate ./my-drama/剧集/EP001/剧本.md
```

输出每场、每集的折算时长与目标值偏差。偏差超过 ±15% 时：
- **偏短**：这场戏不够承载这一集的任务，补冲突或合并集数；
- **偏长**：有注水，按「一句话弧光」砍掉不推进的场。

**不要按数字均匀砍台词。** 那会把节奏砍死。

## 五、剧本 vs 分镜：什么时候可以合并

标准流程是剧本（场次）→ 分镜（镜头）。但有两种情况可以合并：

| 情况 | 做法 |
|---|---|
| 单集试水、快速验证 | 剧本直接写镜号，一个画面轨条目 ≈ 一个镜头 |
| 静态漫剧（图 + 配音，无动态） | 画面轨条目就是「格」，格即镜头 |

**不要合并的情况**：多集连载、需要严格控时长、多人协作。这三种情况下，剧本和分镜分开能省下大量返工。

## 六、去 AI 味：观众闻到的那股味儿

**AI 写的台词不是"不像人"，是"太像人写的"——工整得可疑。**

观众说不出哪里不对，但会划走。常见的六种痕迹，剧本阶段就能改：

| 痕迹 | 表现 | 为什么假 |
|---|---|---|
| **句句完整** | 没有打断、没有半句、没有答非所问 | 真人对话一半是不完整的 |
| **人均文学家** | 每个角色都能说出金句 | 一部戏里只有 1~2 个人该会说话 |
| **情绪直给** | 「她很愤怒」「他感到绝望」 | 情绪要落在动作上，观众自己判断 |
| **一句一人称** | 你说一句我答一句，严丝合缝 | 真人经常不听、抢话、说别的 |
| **句长均匀** | 每句都 12~15 字 | 真人说话是一串短的，突然来一个长的 |
| **零冗余** | 每句话都在推动剧情 | 真人说话有 20% 是废话 |

### 六条修法

**① 让台词被打断**

```
❌ 甲：你昨天去哪了？
   乙：我去公司加班了。
✅ 甲：你昨天去哪——
   乙：公司。
```

**② 一场戏只给一个人一句好台词**

其余人说的话要平。**人人金句 = 没有金句。**

**③ 情绪换成身体**

```
❌ 她愤怒地看着他。
✅ 她把杯子放回桌上，放得很轻。
```

「放得很轻」比「愤怒地摔」更狠——克制才有压力。

**④ 加答非所问**

问 A 答 B，是真人最常见的状态，也是最能出人物的一句。

```
甲：你还回得来吗？
乙：灶上还热着汤。
```

**⑤ 打乱句长**

同一段里放一个 3 字句和一个 18 字句。**节奏是靠长短差出来的，不是靠内容。**

**⑥ 留废话**

一场戏留 15%~20% 不推进剧情的对话（寒暄、抱怨、重复）。删掉不影响剧情，
但它决定了这场戏是"人演的"还是"大纲念的"。

> **注意配比**：竖屏短剧的容错比长片低得多。上面六条用来改**关键场次**（对峙、告别、翻脸），
> 不要全片都用——每分钟都"生活流"，观众三秒就走了。
> 判断标准：**这场戏是不是观众会截图/二刷的那场？** 是，就按上面改；不是，保持效率。

## 七、剧本自检

交付前逐条过：

- [ ] 每场都有明确的戏剧动作（目标 + 阻碍 + 结果）？
- [ ] 全篇没有心理描写、括号暗示、死空间？
- [ ] 每句台词 ≤ 15 字？
- [ ] 每句台词都有语气位？
- [ ] 语气位与画面动作一致？
- [ ] 主要角色的说话方式能区分开？
- [ ] 删掉所有台词，画面轨还能讲清故事？
- [ ] 折算时长与目标偏差 ≤ 15%？
- [ ] 第一场 3 秒内有没有已发生的异常？
- [ ] 最后一场是不是切在临界点？
- [ ] 关键场次有没有去过 AI 味（打断 / 答非所问 / 句长差 / 留废话）？
- [ ] 七维过了一遍：①②全绿、③④没有塌、⑤⑥⑦关键句达标？（`cd.py lines` 出表）

第 2、3、7 题是硬门。其余是 `craft_default`——偏离要能说出理由。
