# 表情与动作：设定板与强度梯度

表情和动作是最容易被做成"废板"的两类资产——做了一套图，生成时一次都没用上。

原因是：**它们是镜头瞬态，不是资产。** 但有两种情况必须做，做对了能救命。

---

## 一、什么时候做，什么时候不做

| 情况 | 做 | 理由 |
|---|---|---|
| 角色有大量情绪特写（虐恋、复仇、崩溃） | ✅ 做表情板 | 表情会飘，需要一把"标尺" |
| 角色有标志性动作（武打、施法、职业动作） | ✅ 做动作板 | 姿势会走形，需要参考 |
| 只有通用情绪（说话、点头、走路） | ❌ 不做 | 分镜和关键帧直接写，做了也白做 |
| 静态漫剧、图集模式 | ❌ 不做 | 逐格出图，不需要设定板 |

**判断标准**：这个角色有没有 5 个以上镜头需要**同一种极端状态**？有 → 做板；没有 → 不做。

---

## 二、表情板：十二宫格

### 硬纪律

| 项 | 要求 |
|---|---|
| **格数** | 正好 12 格，不多不少 |
| **裁切** | 统一头肩像或胸像，不得有人全身 |
| **视角** | 默认正面；参考图只支持四分之三时，**十二格统一用同一角度** |
| **尺度** | 十二格头部大小、眼线高度、肩线位置、留白比例完全一致 |
| **光线** | 同一光源方向、光比、色温、曝光、阴影软硬、眼神光位置 |
| **背景** | 纯白或中性灰，禁止剧情场景与道具 |
| **不许做的** | 不许用手势、手部、全身姿势表达情绪；不许靠换妆发/换衣服表达情绪 |

**最后一条最关键**：情绪只能靠**眼神、眉毛、眼睑、鼻翼、嘴型、下颌、面部肌肉**这七项。

靠"换个发型显得忧郁"是作弊，出来不是同一个人。

### 十二表情与强度梯度

**顺序不能乱，强度必须拉开。** 这是整套板的核心价值。

| # | 表情 | 关键差异 | 强度 |
|---|---|---|---|
| ① | **平静** | 视线自然聚焦，眼睑正常开合，双眉舒展，嘴角不抬不坠 | 0 |
| ② | **微笑** | 目光柔和，眼睑轻微收窄，两侧嘴角小幅上扬，双唇闭合 | 2 |
| ③ | **开心** | 眼神明亮，眼睑明显收窄，面颊上抬，嘴角充分上扬，可轻微露齿 | 4 |
| ④ | **大笑** | 眼睑挤成弯，面颊大幅上抬，张口，可见上齿与舌 | 6 |
| ⑤ | **惊讶** | 眉毛抬高，上眼睑提起露出上方眼白，唇微张成小圆形 | 5 |
| ⑥ | **恐惧** | 眉内侧上扬并靠拢，眼睁大，下眼睑绷紧，唇向两侧拉开 | 7 |
| ⑦ | **愤怒** | 眉内侧下压靠拢，鼻翼张开，下颌前送，唇紧抿或咬牙 | 7 |
| ⑧ | **悲伤** | 眉内侧上扬，上眼睑下垂，嘴角向下，下颌微颤 | 6 |
| ⑨ | **厌恶** | 鼻梁皱起，上唇抬起一侧，眼睛眯起，头微后仰 | 5 |
| ⑩ | **轻蔑** | 单侧嘴角上扬，一侧鼻翼提起，眼睑半垂，下颌微抬 | 4 |
| ⑪ | **压抑** | 面部肌肉绷紧但表情克制：唇紧闭、咬肌隆起、眉头微蹙 | 3（但张力高） |
| ⑫ | **失神** | 目光失焦，眼睑松弛，唇微启，面部肌肉全部松开 | 0（但是"空"） |

### 强度梯度表（必写进提示词）

```
微笑（强度 2）< 开心（强度 4）< 大笑（强度 6）
```

**不写梯度，模型会把三个笑画成同一个。**

具体写法：

```
② 微笑：嘴角小幅上扬，双唇闭合，面颊只有轻微抬升。表演强度必须低于"开心"。
③ 开心：嘴角充分上扬，上下唇之间留一条细缝露出齿尖，鼻唇沟比"微笑"更清晰，眼睑平展。
④ 大笑：张口，可见上齿与舌，眼睑挤成弯，面颊大幅上抬。
```

### 最容易错的三个

1. **微笑画成大笑** — 没有强度梯度，模型默认取中间值
2. **恐惧画成惊讶** — 少了"眉内侧靠拢"和"下眼睑绷紧"
3. **悲伤画成哭泣** — 没有眼泪的情况下，靠眉内侧上扬 + 嘴角下压，不靠眼泪

## 三、动作板：十五格

### 硬纪律

| 项 | 要求 |
|---|---|
| **格数** | 正好 15 格 |
| **构图** | 完整全身，头顶到鞋底全部可见 |
| **视角** | 统一正面或轻微四分之三；相机高度、焦段感、透视一致 |
| **基线** | 地面基线一致，人物缩放比例一致 |
| **剪影** | 每个动作要有清晰剪影，四肢不与躯干无意义重叠 |
| **背景** | 纯白，柔和均匀影棚主光，轻微接触阴影，脚底落点清晰 |
| **面部** | 表情克制，服务于动作；不因动作强度换脸 |

### 十五个动作（通用版）

| # | 动作 | 关键点 |
|---|---|---|
| 1 | 自然站立 | 重心均匀，双臂自然下垂 |
| 2 | 行走中 | 单脚着地，重心前移，手臂反向摆动 |
| 3 | 奔跑中 | 双脚离地瞬间，躯干前倾 |
| 4 | 转身回望 | 腰部先转，头部后转，重心在支撑脚 |
| 5 | 坐下 | 重心后移，膝盖弯曲，手扶支撑 |
| 6 | 起身 | 重心前移，腿部发力，躯干先起 |
| 7 | 伸手取物 | 肩先动，肘随，指尖最后到位 |
| 8 | 递物 | 双手或单手前送，身体微前倾 |
| 9 | 受惊后退 | 重心骤然后移，肩先缩，脚下不稳 |
| 10 | 蹲下 | 膝盖先屈，臀部后坐，重心降低 |
| 11 | 抬手遮挡 | 前臂上抬，肘部内收，头侧偏 |
| 12 | 挥击 | 腰部发力，肩带动臂，末端加速 |
| 13 | 防御格挡 | 双臂交叉或单臂横挡，重心下沉 |
| 14 | 施法 | 手势定型，能量从掌心或指尖起 |
| 15 | 力竭 | 支撑面扩大，脊柱弯曲，头低垂 |

### 动作的六条物理规律

这是动作板与"摆姿势"的分界线：

| 规律 | 怎么写 |
|---|---|
| **重心** | 每个动作标出重心落在哪只脚、哪个位置 |
| **支撑面** | 双脚之间的距离与朝向决定稳定度 |
| **关节活动范围** | 肘不能反折，膝不能侧弯，脊椎有极限 |
| **惯性** | 动作结束时身体有前冲或后仰的余势 |
| **反作用力** | 挥击时另一侧身体要反向配重 |
| **服装滞后** | 衣摆、袖口、发丝的运动比身体慢半拍 |

**最后一条最容易被忽略，也最出效果。** 写「转身时衣摆向反方向甩出半拍」比写「衣袂飘飘」有用一百倍。

### 武器与能力

| 情况 | 处理 |
|---|---|
| 参考图已定义武器 | 拔剑/攻击/防御必须用同一件，外形尺寸材质佩挂位置一致 |
| 参考图没有武器 | **先问用户**，不得擅自新增标志性武器 |
| "攻击"格 | 只表现动作关键帧，**不表现命中、伤口、血液、受击对象** |
| "防御"格 | 表现稳定支撑与防护方向，**不出现对手** |
| "施法"格 | 用与世界观匹配的能量/符纹/粒子/气流，不借用现实品牌或版权角色效果 |

## 四、提示词写法

### 表情板开头

```text
请根据所附角色参考图生成十二宫格表情设定板。参考图是该角色的唯一视觉标准，
只允许改变面部表演与必要的轻微头部动态，不得重新设计人物。

【身份锁定（不可变）】
头骨宽窄、颧骨位置、下颌转折、下巴长度；双眼间距、眼裂走向、上下眼睑厚度、虹膜颜色；
眉峰位置与左右天然差异；鼻梁高度、鼻翼宽度、鼻尖形态；人中长度、唇峰、上下唇厚度；
肤色、皮肤纹理、痣、雀斑、疤痕；发际线、刘海分区、发束走向、发长、发色、发饰。

【固定拍摄】
统一头肩像裁切，正面视角，同一焦段感与透视，十二格头部大小与眼线高度一致。
纯白背景，同一光源方向、光比、色温、曝光与眼神光位置。
禁止用手势、手部、全身姿势表达情绪；禁止靠更换妆容、发型、服装表达情绪。

【十二格严格按序，强度必须拉开】
① 平静：……
② 微笑：……（强度必须低于"开心"）
③ 开心：……（强度高于"微笑"、低于"大笑"）
……
```

### 动作板开头

```text
请根据所附角色参考图生成十五格动作设定板。参考图是唯一视觉标准，
只允许改变姿势、重心与必要的服装动态。

【人物与服装锁定】
头身比、肩宽、腰线、四肢比例、手脚尺度；服装领口、袖型、腰封、衣摆、裤裙结构；
面料厚薄软硬光泽、纹样、磨损位置、叠穿顺序；鞋履、首饰、护具、腰带、挂件、武器。

【固定拍摄】
完整全身，头顶到鞋底全部可见；统一正面或轻微四分之三视角；
统一相机高度、焦段感、透视、人物缩放、地面基线、留白与光照方向；
纯白背景，柔和均匀影棚主光，轻微接触阴影，脚底落点清晰。

【物理规律】
每个动作标出重心落点、支撑面、关节活动范围、动作结束时的惯性余势、
反向配重，以及衣摆/袖口/发丝比身体慢半拍的滞后。
```

## 五、用完怎么接

**设定板不是交付物，是参考资产。** 出完板之后：

1. 把它登记为 `IMG-...` 条目（图片提示词项）；
2. 在关键帧提示词里挂成「用途：造型状态」的参考图；
3. 在 `控制：` 里写清它管什么（表情范围 / 姿态范围）；
4. 在 `不得控制：` 里写清它不管什么（构图、光线、场景）。

**不要**在每个镜头里都挂它——那会占满参考图槽位。只在**该状态确实要复现**的镜头挂。

## 六、自检

### 表情板

- [ ] 正好 12 格？
- [ ] 十二格是同一个人的同一时刻？
- [ ] 强度梯度写清楚了（微笑<开心<大笑）？
- [ ] 恐惧有「眉内侧靠拢 + 下眼睑绷紧」，不是只有"睁大眼"？
- [ ] 悲伤没有靠眼泪表达？
- [ ] 没有用手势/换装/换妆表达情绪？
- [ ] 十二格光线完全一致？

### 动作板

- [ ] 正好 15 格？
- [ ] 每格头顶到鞋底完整？
- [ ] 基线一致、缩放一致？
- [ ] 每个动作标了重心与支撑面？
- [ ] 有惯性余势与反向配重？
- [ ] 写了服装滞后？
- [ ] "攻击"格没有命中与伤口？
- [ ] "防御"格没有对手？
- [ ] 武器是参考图已有的那件？

第 3 题（表情）和第 4–6 题（动作）是这两类板真正的价值所在。
