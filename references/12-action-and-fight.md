# 打戏与动作链

打戏不是"把动作写细"，是**让观众看懂谁在占上风**。

很多打戏提示词写了一堆动词，出来还是一团乱——因为模型不知道力从哪来、往哪去。

这一篇解决：怎么把一场打拆成可执行的动作链，以及怎么用轨迹图把它钉死。

---

## 一、两条前置：强度档与战斗逻辑

### 强度档（只有两档）

| 档 | 特征 | 默认用于 |
|---|---|---|
| **均衡** | 快、清晰、有重量与惯性，击退有限，地形可通行，破坏适度 | **真人写实** |
| **夸张** | 加速度更大、位移更远、有攻击线、残影、透视拉伸、击退与环境反应更强 | **3D 卡通 / 3D 写实动漫 / 2D 动漫** |

**不要设第三档。** "写实克制"不是第三档，是均衡档里收紧距离与伤害，不是让表演变慢变僵。

**渲染风格与强度档是两个维度。** 武侠/科幻/玄幻是题材标签，影响服装武器环境与动作语汇，**不替代渲染分类**。

### 每个战士的战斗逻辑

同一个导演不要给所有角色同一套动作。每个能打的人先定六项：

| 项 | 问 |
|---|---|
| **偏好距离** | 贴脸 / 一臂 / 一兵器长 / 远程 |
| **接近与脱离方式** | 突进 / 绕侧 / 翻滚 / 后跳 |
| **主攻方向** | 上段劈 / 中段刺 / 下段扫 |
| **防御与反击模式** | 格挡反击 / 闪避后手 / 以攻代守 |
| **被击退后怎么刹车再入** | 撑地 / 侧滚 / 撞墙借力 |
| **稳定的能力规则** | 有代价、有冷却、有限制 |

**动作必须由当前距离、身体朝向、武器位置、上一招结果、对手反应、可用地形推导出来。**

## 二、五类战斗载体

打戏不是只有拳脚。五类载体的写法完全不同。

### ① 近战

**力的来源**：武器或身体接触；**传递**：步法、姿态、旋转、护架、闪避、地形。

按真实攻击范围与人体结构设计。写「脚蹬地→腰转→肩送→接触」这条链。

### ② 远程

三件事必须有：**发射动作、飞行轨迹、命中或躲开的结果**。

```
❌ 他射了一箭，对方倒下
✅ 他拉满弦，弦离指的一瞬箭已出；箭身在空中走一条微微下坠的直线，
   钉进对方左肩的甲片缝；对方上身向后一顿，箭尾还在震
```

**禁止把远程戏拍成站着对射。** 移动要围绕距离、掩体、接近与后撤。

### ③ 法术

**先定义真实触发器**，再写三阶段。

| 触发器 | 手势 / 法印 / 符咒 / 法杖 / 武器 / 眼睛 / 声音 / 装置 |
|---|---|
| 阶段一 | 成形（从哪开始聚、聚成什么） |
| 阶段二 | 飞行或扩散（方向、速度、路径） |
| 阶段三 | 命中或消散（结果、余波） |

**颜色、形状、触发器、能量光必须全片一致。**

首次使用用特写把触发器交代清楚；大招要重复触发器细节 → 中近景看施法者 → 再展示规模、方向、目标、释放、结果。

能量光怎么写不水，见 `11-vfx-and-particles.md` 的去水五律。

### ④ 召唤

**先决定它是哪一种：**

| 类型 | 特征 | 写法 |
|---|---|---|
| **无碰撞的光影投影** | 光、虚影、不接触实体 | 写「光从…透出，人形轮廓在半空成形，穿过它身体不产生阻挡」 |
| **有独立身体的实体** | 会被打、会撞、会挡 | 写「落地时地面被压出裂纹，它的重量是真的」 |

然后写：触发器细节、从哪来、怎么与施法者互动（骑乘 / 并肩 / 承载 / 同步攻击）。

**固定形态（元神、武魂、式神）值得建一个参考资产**；一次性召唤可以纯文字定义。

### ⑤ 变身

**当成状态变化，不是攻击类别。**

写法顺序固定：

```
真实起点（眼睛/皮肤/手臂/骨/毛/能量纹，具体到部位）
  → 沿扩散方向（向上/向外）
  → 逐渐扩大到中景
  → 最后才展示完成的全身
```

**变完之后，新的解剖结构、武器、能力限制要保留。** 不能下一镜又变回去。

## 三、动作最小单位：11 环动力链

**一个动作不是"他打了一拳"，是一条完整的力学传递。**

| # | 环 | 写什么 |
|---|---|---|
| 1 | 意图 | 想达成什么（打脸/逼退/缴械） |
| 2 | 起手 | 哪个部位先动 |
| 3 | 重心 | 往哪移 |
| 4 | 脚步 | 哪只脚蹬地、哪只上步 |
| 5 | 腰胯 | 怎么转 |
| 6 | 传导 | 肩→肘→腕，或髋→膝→踝 |
| 7 | 轨迹 | 走什么路线 |
| 8 | 接触点 | 打在对方哪里 |
| 9 | 反馈 | 对方身体怎么反应 |
| 10 | 惯性 | 收招时的余势 |
| 11 | 继承 | 给下一招留下什么状态 |

**不必每招写全 11 环。** 关键三招（开局、转折、终结）必须写全。

```
❌ 他一拳打在对方脸上，对方倒下

✅ 他后脚蹬地，重心前移，腰胯向左拧，右肩随之前送，
   右拳从胸前出发走一条微微向上的弧线，拳峰砸在对方左颧骨下方；
   对方头部顺着力气向右甩开，上半身跟着转过去，左脚绊到桌腿，
   整个人向后跌坐在地上，右手还撑着地面没起来
```

差别在：**力从脚来，经过腰，到拳，对方顺着力走。**

### 但投喂时不要写全 11 环

这是实践里最容易被忽略的一条：**11 环是给人拆招用的，不是给模型看的。**

一篇打戏投喂稿有字数上限，11 环全写进去会挤掉别的必要信息；而且模型读不了那么细，过度的力学描述会被它忽略或扭曲成奇怪的动作。

**投喂时压成四要件：**

| 要件 | 对应环 | 写法 |
|---|---|---|
| ① 发力来源 | 4+5+6 | 「左足蹬地拧腰，脊椎如大弓崩弹」 |
| ② 攻击轨迹 | 7 | 「右拳沿中线直线穿刺」 |
| ③ 毫米级接触点 | 8 | 「拳峰击中下颌骨」 |
| ④ 受力形变 | 9 | 「受击方头部剧烈侧偏，下颌线绷紧，躯干向后弓起」 |

**四要件齐全，打击感就够；11 环齐全，模型反而会漏。**

完整 11 环留在自己的拆招稿里（写给自己看），投喂稿只放四要件。连接招、过渡招还要更省——只写起点、受力点与状态继承。

### 蓄力不许有静止段

写「他站定，蓄力三秒，然后出拳」是错的。

模型拿到「静止」会给你一个真的不动的镜头，然后接一个突然的拳——中间没有力的积累，打出来是飘的。

**蓄力必须发生在位移里**：

```
❌ 他站定蓄力，随后出拳
✅ 他后撤半步沉身，筋膜绷紧，重心压到后腿，
   就在这一步落地未稳之际，前手已送出去
```

只有一种情况可以写压缩式蓄力：目标模型支持（Seedance 2.5 这类可写「压缩收束」的）。2.0 档的模型必须边打边蓄。

### 发力机制六型：选招时对号入座

不同招式用不同的力学机制。写错类型，动作会失真：

| 类型 | 力学特征 | 典型招式 |
|---|---|---|
| **直线整劲** | 力从地起，沿骨架直线贯穿 | 崩拳、正拳突、直拳 |
| **螺旋钻劲** | 腰胯转动带动肢体螺旋切入 | 钻拳、穿掌、标指 |
| **短促寸劲** | 接触后极短距离内爆发 | 日字冲拳、顶肘、寸拳 |
| **鞭梢劲** | 大关节带动末端甩动 | 鞭腿、扫踢、摆拳 |
| **整身撞击** | 全身重量加冲力聚于一点 | 铁山靠、飞冲膝、摔投贯地 |
| **重心破坏** | 不拼力，破坏对方支撑 | 采手引偏、接腿推摔、扫腿绊摔 |

**为什么要分型**：写「鞭腿」却按直线整劲描述（蹬地直立出腿），出来的动作是僵的。腿法的力来自甩，不来自推。

## 四、交锋因果链

**每一次有意义的接触，必须改变至少一项：**

```
身体状态 / 武器状态 / 位置或朝向 / 速度 / 距离 / 主动权 / 环境
```

### 链条写法

```
攻击方向与目标 → 防御/闪避/反击 → 接触或落空 →
即时身体与武器结果 → 新位置与主动权
```

### 禁止「回到原点」

```
❌ 他打过去，对方挡住，两人分开，他又打过去，对方又挡住……
```

每一轮都必须让状态往前走。挡住之后要**立刻反击**；打中之后要**沿着力的方向滑开、转身、后仰、分开或飞出去**，从新位置继续。

### 接触要快、要分开

**避免长时间贴身缠斗、反复抓握、身体重叠**，除非用户明确要地面战。

摔投只写一次：进入 → 支点 → 旋转 → 落地 → 分开。

## 五、先设计空间推进

**先定路线，再选镜头。** 反过来会得到一堆漂亮但接不上的镜头。

### 六个节点

```
开场区 → 首次交汇 → 首次分开或换位 → 中点冲击或改道 →
从新位置再入 → 最终交汇与终点
```

### 追踪型打斗（人与镜头都在移动）

| 要求 | 说明 |
|---|---|
| 起手就在动 | 不要静止摆姿势开场 |
| 方向速度地标连续 | 跨镜保持 |
| 追击因果 | 逃/换位 → 拦/反击 → 突破 → 再追 |
| 动作密度与距离同时推进 | 不能只在原地打 |
| 每个运镜绑定具体动作与目的地 | 不写"镜头跟随" |
| 用视差/前景物/脚步/水雪尘叶/地形变化证明移动 | 否则看着像原地 |

**"追踪"不等于"一镜到底"。** 真正的一镜只有用户明确要求时才做，且机位路线、遮挡、重新构图、可达位置必须物理连续。

## 六、轨迹图工作流

**这是打戏最有效的一招**：先把空间关系画成图，再按图写提示词。

### 三张图，用户通常只做两张

| # | 图 | 作用 |
|---|---|---|
| ① | **初始站位全景** | 必需底图。第 0 秒的位置、距离、朝向、高低、武器状态、可用空间 |
| ② | **人物轨迹图** | 人物移动路线 + 攻击方向 |
| ③ | **人物+摄影机双轨迹图** | ② 再加摄影机路线 |

② 与 ③ **二选一**，不必都做。两个都给且路线冲突时，问用户哪个是主控。

### 三张图的提示词

**① 初始站位全景**

```text
结合当前人物、武器、画风和场景参考，生成一张用于规划打斗路线的初始站位全景图。
具体写清双方外形、服装、武器、体型和身体结构，并根据武器距离、打斗关系和真实地形
安排双方的起点、距离、朝向、高低关系与动态准备姿势。
双方全身入画，清楚保留主要地形、纵深、可利用结构和充分运动空间；两人呈斜角对位，
一人在画面前侧偏左，另一人在后侧偏右，取景带出侧向纵深。
画面不出现轨迹线、箭头、文字、编号和图例。
这张图是空间规划底图，不自动等同于视频第一帧；如果同时用作视频首帧，
让至少一方已经出现明确的起步、前冲或攻击预备方向。
```

**② 人物轨迹图**

```text
目标视频时长为具体秒数。以当前双方同框的初始站位全景图为底图，
保留原有人物、武器、场景、构图、光线和初始位置，只增加双人打斗轨迹。
为两名具体角色分别指定与背景反差明显的颜色，在空白处放置简洁图例；
用带箭头实线表示移动路线，用同色短虚线箭头表示攻击方向。
结合双方武器距离、移动特点、打斗要求和真实地形，具体写清两条路线怎样接近、
拦截、交汇、闪避、换位、追击或分离；沿时间顺序用数字标记关键节点，
每个节点只配一个简短动作标签。复杂度与目标时长匹配，交汇点清楚，
路线连续并贴合地形，每一段都绕开实体障碍，整体走向保持单向推进，两人的轨迹只在交锋点相切。
```

**③ 双轨迹图**：在 ② 的基础上加一层

```text
用蓝色带箭头曲线表示摄影机推进、横移、环绕、拉远和重新构图，
并在空白处放置简洁图例。人物路线、攻击方向和摄影机路线分层清楚。
```

### 读图转成提示词

**节点数不等于镜头数。** 一张图上 8 个节点，可能只对应 5 个镜头。

读图顺序：图例与颜色归属 → 线型与箭头 → 起点终点 → 节点编号 → 人物移动 → 攻击方向 → 摄影机路径。

**按图转写时：**

| 做 | 不做 |
|---|---|
| 把底图转成「初始空间关系」，只记第 0 秒的事实 | 把图上的线路描述原样抄进提示词 |
| 把编号交汇点转成连续时间段 | 一个节点一个镜头 |
| 在每次交汇处补：具体攻击、防御、接触结果、身体反应、主动权变化、继承状态 | 只写"按轨迹图打" |
| 保留主路线，补全因果、接触、节奏、结果 | 改掉用户画的路线 |

### 轨迹图不是最终画面

**成片里不许出现线、箭头、编号、标签、相机图标。**

必须在提示词里写：

```
轨迹线、箭头、编号和文字标签只作调度参考，最终画面不显示。
```

并在【禁止项】里重复一次。

## 七、两种观赏性

| 景别 | 观众看什么 | 怎么写 |
|---|---|---|
| **远景 / 全景** | 看**大动作**：腾空、旋转、下劈、撑地、撞墙 | 身体的空间轨迹与落点 |
| **近景 / 中近景** | 看**杀意**：拳脚交错、格挡弹开、寸拳贴脸 | 接触点、肌肉反应、呼吸 |

**15 秒内必须有至少一段（2–3 秒）上半身近景对招。**

没有近景对招的打戏 = 只有爆炸没有枪战。

### 每镜一个观看任务

每镜只承担**一项**：空间关系 / 单个角色 / 一个细节 / 一个动作结果。

**不要用连续中景装满多个复杂动作**——观众看不清，模型也画不清。

## 八、招式序列化：不要写频率

**模型对"快速""高频""机枪节奏"的执行偏差约 30–40%。**

要写成一串具体的招式 + 落点 + 对方的反应：

```
❌ 双方以极高的频率互相攻击，拳影密如雨点

✅ 右摆拳打脸 → 对方侧偏；左勾拳打下巴 → 对方下潜；
   右直拳打鼻梁 → 对方拍开；左横肘切眉骨 → 对方架桥；
   右标指刺咽喉 → 对方后撤半步
```

### 招式链长度

| 段落 | 招式数 |
|---|---|
| 短近景段 | ≥3 段 |
| 长近景段 | 4–6 段，必须含肘击或指/腕变化 |

### 手部攻击观赏性排序

```
砸肘 > 横肘 > 寸拳 > 上勾拳 > 标指/插指 > 推掌 > 冲拳 > 拍掌
```

### 近景要写"怎么中的"

```
❌ 寸拳击中腹部
✅ 寸拳贴着护臂滑进去，拳头碾过前臂肌肉，直抵肋骨缝，格挡的手臂因冲击而震颤
```

## 九、节奏：炮弹 vs 机枪

| 节奏 | 对应 | 感觉 |
|---|---|---|
| **炮弹节奏** | 远景大动作 | 砰——砰——砰，一招一停，有蓄力间隙 |
| **机枪节奏** | 近景对招 | 砰砰砰砰——砰！高密度连击穿插重击 |

### 机枪节奏三种模式

| 模式 | 结构 | 适合 |
|---|---|---|
| **3轻1重** | 三次快击 + 一次重击慢放 | 咏春、空手道、散打 |
| **左右交替加速** | 左-右-左-右，间隔越来越短 | 泰拳、拳击、八极 |
| **封-破-杀** | 两次格挡弹开 + 一次破防 + 一次致命 | 太极、擒拿、柔术 |

## 十、15 秒与 30 秒的结构

### 15 秒高燃（默认）

| 时间 | 内容 |
|---|---|
| 0–1.5s | **开局冲突**：双人同框近景，禁全景铺垫；极端招式硬撞 + 微慢镜定格 |
| 1.5–5s | 近景对招（位置 A），建立密度 |
| 5–8s | 空间变化：腾空/贴地/倒置，维度变化 ≥2 次 |
| 8–9s | 快攻升级（位置 B），给拐点蓄势 |
| 9–12s | 情绪拐点：压制型反杀 或 逆转型 |
| 12–15s | 终结技：呼吸帧（0.3–0.5s 定格）→ 破局 → 绽放 → 余震 |

**6–9 个不等长镜头**，不要等分。

### 两条铁律

**① 开局不许试探。** 1.5 秒内必须出现攻防接触。

**② 结尾不许收势。** 终结技直接延伸到最后一帧。不写"收腿站定""发丝飘落""气焰消散"。

**为什么**：AI 生成 0.5 秒不足以完成收尾，反而稀释冲击。而且以最炸裂瞬间结束，观众的兴奋带进下一条。

### 2D 动漫的特殊处理

决定性一击的收尾帧，**默认用高饱和单色**（红/白/黑），并在节奏面板标注「可移除」。

| 8 | 摇镜横移 | 横向游走试探 | 中景 |
| 9 | 甩镜闪切 | 重拳、肘击碰撞 | 近景 |
| 10 | 特写切镜 | 蓄力、情绪渲染 | 特写 |

### 五组组合

| 场景 | 组合 |
|---|---|
| 突进 | 急速推镜 → 跟拍 → 甩镜闪切 |
| 大招 | 急速后拉 → 慢动作跟镜 → 定格 |
| 逆转 | 对打镜头 → 急速推镜 → 定格 |
| 腾空 | 升降 → 高空俯拍 → 急速拉镜 |
| 环境互动 | 穿框穿梭 → 跟拍 → 甩镜闪切 |

### 运镜带物理刻度

```
❌ 镜头拉远
✅ 急速拉镜·中景→全景·45°斜拍平视·跟随两人拉开距离
❌ 镜头靠近
✅ 急推·中景→特写·正面平视·推进至拳面命中点
```

### 镜头五要素：不给模型脑补空间

一条打戏镜行必须带全这五项，缺任一项模型就自己编：

```
[景别] · [视角+角度] · [运镜] · [跟随目标]
```

| 要素 | 可选值 | 写法 |
|---|---|---|
| 景别 | 特写 / 近景 / 中近景 / 中景 / 全景 / 大远景 | `近景` |
| 视角 | 正面 0° / 斜侧 30–60° / 侧面 90° / 俯拍 / 仰拍 | `45°斜侧` |
| 角度 | 平视 / 15–30° 低仰 / 45° 斜俯 / 垂直俯瞰 | `30°仰视` |
| 运镜 | 从上表 15 种里选一种 | `急速推镜` |
| **跟随目标** | 跟随具体肢体、兵刃尖端或接触点 | `跟随右拳推进至心口` |

**第五项最容易漏，也最影响观感。** 「透镜」和「推至拳面命中点」是两种画面——后者会逼着模型把打击点放在该在的位置。

### 两条空间铁律

**① 中景及以上禁止 90° 正侧拍**（会变格斗游戏）。必须用 30–60° 斜角制造纵深。近景/中近景才可以 90° 侧拍。

**② 景别必须匹配动作幅度**：

| 动作幅度 | 配什么景别 | 为什么 |
|---|---|---|
| 大幅（腾空下劈、剑气横扫、大步位移、轻功折返） | **全景 / 中景** | 要看到舒展身形与空间位移，压到特写就只剩一团 |
| 小幅（寸劲短打、点穴、腕剑翻转、贴身截击） | **近景 / 特写** | 要放大击打密度，拉到全景就看不见 |

**这条写反了是最常见的打戏失误**：把「一剑横扫三丈」写成特写，出来只有一片模糊的光；把「指尖点穴」写成全景，观众根本看不清在干什么。

## 十二、近景↔远景怎么切

| 方向 | 步骤 |
|---|---|
| **近景→远景** | ① 近景看清打击点 → ② 中景被击者后退/被推飞，镜头跟拉 → ③ 全景撞墙/滑行/腾空 |
| **远景→近景** | ① 全景→中景：攻方突进贴脸，急推 → ② 中景→近景：拳已到眼前，微推锁面部 |

**近景→远景禁止跳切**，必须经中景过渡。

## 十三、武器格斗

每个武器镜头必须写：

```
谁持有 / 哪只手 / 武器长度 / 刃口方向 / 攻击轨迹 /
接触点 / 滑动方向 / 压刃关系 / 杠杆关系 / 受力后的震动或偏转
```

### 碰撞不能悬空

刀剑相碰必须至少体现一种：压刃 / 滑刃 / 挑刃 / 偏转 / 震手 / 卡位 / 缴械 / 余震。

**禁止**：武器穿过身体、长度漂移、突然换手、突然消失、没有接触点、刃口方向错。

武器形制与长度参照见 `10-weapon-assets.md`。

---

## 十四、动作连续性

**每一镜必须继承上一镜的状态。**

| 跟踪 | 不许 |
|---|---|
| 位置、朝向、左右站位 | 瞬间换边 |
| 重心、脚位 | 无原因换脚 |
| 手部状态、武器位置、持有手 | 突然换手 |
| 呼吸、体力、受伤 | 忽略上一镜的伤 |
| 主动权、惯性方向 | 忘记"谁刚被打飞" |

**最常出的事故**：上一镜他被击退到墙边，下一镜他站在屋子中央。

## 十五、输出格式

每条打戏提示词，格式固定：

```
【视觉风格】…
【初始空间关系】…（只记第 0 秒事实）
【角色A 战斗逻辑】…（六项）
【角色B 战斗逻辑】…
【动作时间轴】
  镜1｜0.0–1.5s｜景别·角度·运镜｜（一段连续画面描述）
  镜2｜1.5–3.0s｜…
【特效与能力】…
【禁止项】…
```

**每镜两行**：镜行头（时间+景别+机位+运镜）+ 一段连续画面。

**不要一句话一段**，也不要挤成一整块。

### 节奏调整面板（不属于生成提示）

在提示词之后单独列出，给创作者调：

```markdown
## 节奏调整面板
- 强度档：夸张 / 均衡（可切）
- 可调项：开局时长 / 近景段长度 / 终结技呼吸帧 / 收尾单色帧（2D 默认开，可关）
- 不建议改：轨迹主路线 / 武器持用手 / 胜负结果
```

## 十六、自检

### 结构

- [ ] 定了强度档（均衡/夸张），且与渲染风格匹配？
- [ ] 每个能打的人有六项战斗逻辑？
- [ ] 先写了空间路线六节点，再选镜头？
- [ ] 每次接触都改变了至少一项状态？
- [ ] 没有"回到原点"的重复交锋？
- [ ] 15 秒 6–9 个不等长镜头？
- [ ] 开局 1.5 秒内有接触，结尾不收势？

### 表演

- [ ] 有 2–3 秒近景对招？
- [ ] 招式写成序列，没有写频率词？
- [ ] 近景写的是"滑进去/碾过"，不是"击中"？
- [ ] 每镜只有一个观看任务？
- [ ] 关键三招写了完整力学链？

### 载体

- [ ] 远程写了发射/飞行/命中三段？
- [ ] 法术有固定触发器，三阶段都写了？
- [ ] 召唤说明了是光影投影还是实体？
- [ ] 变身从真实起点开始，最后才展示全身？

### 武器

- [ ] 写了持用手、刃口方向、接触点、受力反馈？
- [ ] 武器没有忽长忽短、突然换手？
- [ ] 长兵允许出画？

### 轨迹

- [ ] 用了轨迹图的话，提示词里有"轨迹只作参考，最终不显示"？
- [ ] 节点数没有直接等于镜头数？
- [ ] 每次交汇都补了因果与结果？

第 4、5、8 题决定打戏成不成立。
