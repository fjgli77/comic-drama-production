# 道具资产：四格板与状态轨迹

道具是最容易被跳过、又最容易穿帮的一环。

一件玉佩，第 3 镜在左手，第 9 镜在右手，第 15 镜变成两块——观众不会说"道具错了"，会说"这剧做得糙"。

---

## 一、什么算关键道具

**不是所有东西都要建条目。** 只建这三类：

| 类型 | 判据 | 例 |
|---|---|---|
| **承担叙事功能** | 没它这场戏不成立 | 婚书、录音笔、解药 |
| **跨镜出现** | 出现在两个以上镜头 | 主角的刀、反派的手杖 |
| **有状态变化** | 会开/关、会破、会被打开 | 信封、锁、玉佩裂纹 |

**不建的**：场景固定陈设（桌椅、台灯、烟灰缸）、一次性出现的杂物、纯背景道具。

> 场景里的陈设归 `08-scene-assets.md` 的场景锚点，不在这里建条目。

---

## 二、四格板

```
① 正面视图（整体形态与轮廓）
② 45° 侧视图（侧向体量与结构层级）
③ 顶部俯视图（顶部结构、开口、纹样分布）
④ 关键细节特写（纹样 / 结构部件 / 磨损 / 工艺）
```

### 与人物板的区别（重要）

| 项 | 人物四格板 | 道具四格板 |
|---|---|---|
| 格内文字 | **禁止**（只允许图底 ≤8 词音色标签） | **允许**：左上角标道具名 |
| 细节特写格 | **取消**（会把画布切碎） | **保留**（道具的识别点常在细节上） |
| 禁止项 | 砍头、多格、乱码 | 同款多出、悬浮、手持 |

**不要过度外推「零文字」纪律。** 道具图允许标注道具名，因为它需要和资产清单对上号。

### 什么时候改用「1+6」版式

四格板够用于**结构简单**的道具（戒指、信封、钥匙、杯子）。但**结构复杂**的道具——机械件、多部件法器、带机关的盒子——四格装不下它的设计信息，出图后模型每镜重解释一次，细节就飘了。

这时换 **1 主图 + 6 细节** 的横向拆解板：

```
左侧 50%：一张大主视图（整体外观、比例、结构、主要材质）
右侧 50%：2 列 × 3 行，六个细节区
  ① 整体结构 / 主要功能
  ② 正面或核心部件
  ③ 侧面、背面或连接结构
  ④ 材质与表面纹理
  ⑤ 关键装饰、标志或工艺细节
  ⑥ 使用状态、收纳状态或尺度参照
```

选哪种：

| 道具特征 | 版式 | 理由 |
|---|---|---|
| 单一形体、无机关、材质单一 | 四格 | 四格够，成本低 |
| 多部件、有连接结构、有工艺 | **1+6** | 不拆开，模型就自己发明 |
| 需要在多个镜头里被「看懂」 | **1+6** | 拆解图本身就是设定说明 |
| 要贴到资产清单里给美术看 | **1+6** | 信息密度高，一页说完 |

**1+6 的六个细节必须与主图完全同一身份**：尺寸比例、颜色、材质、纹理、结构、磨损、光线逻辑全部一致，只换角度与景别。不写这句，模型会给你六个相似但不同的东西。

**每个区域左上角加半透明深色标题条**（白字、无衬线），标题从内容自动生成：全景图 / 结构细节 / 材质细节 / 连接方式 / 装饰细节 / 使用展示 / 收纳展示 / 功能部件 / 磨损细节。

这条是 1+6 相对四格的核心增益：**它让图自己带说明**，美术不用回来问你「这块是什么」。

## 三、提示词结构

```
① 道具名 + 材质 + 尺寸比例（相对手掌或身高）
② 造型结构细节
③ 色彩 / 纹样
④ 年代 / 风格
⑤ 使用痕迹（磨损、包浆、缺口）
⑥ 与所属场景/人物统一的风格分支
⑦ 纯白背景（或指定背景，但不得有人物或手）
⑧ 四格版式声明
⑨ 排除项
```

### 尺寸必须写参照

| ❌ | ✅ |
|---|---|
| 不大不小 | 掌心大小，长约 8 厘米 |
| 很长 | 全长约 110 厘米，立起时到成年人胸口 |

**为什么**：道具尺寸漂移是最常见的穿帮之一。不写参照，同一把刀在不同镜头里可能是匕首也可能是长枪。

### 使用痕迹要写

新道具像贴图。写磨损、包浆、缺口、补过的裂痕，它才有年代感。

```
边缘轻微磨损，常年摩挲处有一层温润包浆，右下角有一处米粒大的磕口
```

## 四、状态轨迹

**会变的道具，必须写清「初始 → 中间 → 最终」。**

```markdown
- 状态：卷起（EP001-SC003）→ 摊开在桌面（EP001-SC005）→ 被撕成两半（EP002-SC001）
```

| 为什么必须写 | 后果 |
|---|---|
| 让分镜知道每镜该是什么状态 | 否则第 5 镜还是卷着的 |
| 让模型知道这物件会变 | 否则它按参考图死锁成初始状态 |
| 让机检能核对 | 可查「这一镜的道具状态对不对」 |

**不写状态轨迹的道具，会在整部戏里保持同一个样子。** 一封被拆开的信，后面几十镜还是封着的。

## 五、三条硬纪律

### ① 道具必须物理接地

道具第一次出现时，**必须写它搁在什么上面、或在谁手里**：

| ❌ 悬浮 | ✅ 接地 |
|---|---|
| 一把剑在画面里 | 剑斜靠在门框上，剑尖点地 |
| 一枚玉佩 | 玉佩压在桌面的信纸上 |
| 一杯酒 | 酒杯在桌沿，离边缘约两指 |

**为什么**：只写相对位置（"在画面左侧"），模型会让道具飘在空中。

### ② 反光道具零光效描写

玉佩、银镯、镜面、金属、宝石——**任何与光产生描写关联的从句都会让它发光**。

| ❌ 会点火 | ✅ 只写材质 |
|---|---|
| 玉面映着油灯火苗 | 玉面呈青玉原色 |
| 受油灯照射处有一片暖黄光斑 | 玉体呈深青色实心石质，哑光质感 |
| 银镯反着窗光 | 银镯表面有细微磨砂纹理 |

**侧受光同样点火。** 唯一解是**道具与光源彻底解耦**——动作只「把玩/佩戴」，不靠近任何光源。

### ③ 单实例锁

同款多件必须区分，否则模型会画出一堆。

| 情况 | 处理 |
|---|---|
| 两枚被交换的同款号牌 | **分建两个道具条目**，各给唯一标记 |
| 十只无连续性要求的白杯 | 归普通布景，不建条目 |
| 一把刀在两人手里传 | 一个条目 + 持有者状态轨迹 |

## 五·补、1+6 可复制骨架

复杂道具直接用这段，只换 `【】` 里的内容。**不要改动版式描述**——版式一改，模型的网格就散了。

```text
16:9 横向道具概念设计拆解板，professional prop design breakdown sheet，
prop design bible，product detail presentation board，cinematic production design reference sheet。

整张画面严格模块化网格布局，满版图片拼贴，极窄白色分隔线，几乎没有外围留白。
排版规整、对齐精准、信息层级清晰，像高端影视美术设定集、AAA 游戏道具设计稿、专业产品材质展示板。

左侧约占总宽度 50%，一张大型主视图，完整展示【道具名称】的整体外观、比例、结构和主要材质。
主图用专业商业摄影或电影级概念设计构图，主体完整，无干扰背景，不放在实际场景中，光线清晰，
能准确识别整体形态。

右侧约占总宽度 50%，划为 2 列 × 3 行六个细节区：
1. 整体结构或主要功能
2. 正面或核心部件
3. 侧面、背面或连接结构
4. 材质与表面纹理
5. 关键装饰、标志或工艺细节
6. 使用状态、收纳状态或尺度参照

每张细节图必须与左侧主图保持完全一致的道具身份、尺寸比例、颜色、材质、纹理、结构、
磨损痕迹和光线逻辑。细节图用不同角度、不同景别和局部特写，清楚呈现设计信息，避免重复画面。

左侧主图与右侧六张细节图左上角均加黑色或深灰半透明矩形标题条，白色中文无衬线字体，
标题按内容生成，例如：全景图 / 结构细节 / 材质细节 / 连接方式 / 装饰细节 / 使用展示 /
收纳展示 / 功能部件 / 磨损细节。

图与图之间约 5–8px 纯白分隔线，所有图严格网格对齐。
不得使用圆角卡片、阴影、复杂边框、装饰性 UI 或无关图标。文字仅用于区域标注，不加说明段落。

整体风格：专业道具设计资料板、影视美术制作参考图、AAA 游戏资产设计稿、
电影 Production Design presentation、产品材质拆解图。高细节、真实材质、统一光照、
清晰结构、专业构图、视觉信息密度高。

道具内容：
【道具名称】
【时代或世界观】
【主要材质】
【颜色与视觉风格】
【功能】
【磨损、污渍或特殊细节】
【使用场景信息（仅作材质与磨损参考，不生成环境）】

要求：同一道具贯穿所有画面，结构与细节一致；无人物、无动物、无水印、无 Logo、
无品牌标志、无多余文字、无不相关物品、无结构变形、无重复角度。
```

### 用于武器时的三处改动

武器不是普通道具，变量要换：

| 项 | 普通道具 | 武器 |
|---|---|---|
| 主图 | 整体外观 | **整体外观 + 明确刃口方向**（哪边是刃、哪边是背） |
| 尺度参照格 | 「与手掌对比」 | **三重参照**：绝对长度 + 人体对齐点 + 单手攻击半径（见 `10-weapon-assets.md`） |
| 第 6 格替换 | 使用状态 | **握持区与重心位置**（护手在哪、重心偏前还是偏后） |

第 6 格替换掉「使用状态」的理由：武器的使用状态就是战斗，而战斗属于分镜，不属于设定板。

## 六、道具图的排除项

```text
duplicate view angle panel, extra fifth panel, five-panel layout,
standalone oversized prop render, repeated front view,
human hand, person, silhouette, hand holding the prop
```

**禁止手持展示**。道具图里出现手，模型会连手一起学，后面生成时容易多出一只手。

## 七、道具资产自检

- [ ] 只给「承担叙事 / 跨镜出现 / 有状态变化」的道具建了条目？
- [ ] 写了「全图共 4 格」？
- [ ] 尺寸写了参照物（手掌/身高）？
- [ ] 写了使用痕迹（磨损/包浆/缺口）？
- [ ] 会变的道具有「初始→中间→最终」状态轨迹？
- [ ] 首次出现写了支撑面或持有者？
- [ ] 反光道具**没有**任何光效描写？
- [ ] 同款多件分建了条目，或归了布景？
- [ ] 排除项里有「禁止手持/禁止人手」？
- [ ] 左上角标了道具名，与资产清单一致？

第 5、6、7 题最关键。
