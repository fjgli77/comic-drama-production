# 视觉设定：锚点、连续性锁与参考槽位

这一篇管一件事：**让第 3 镜和第 27 镜里的同一个人是同一个人。**

不是靠「多写几遍描述」，是靠三件东西：**锚点逐字复用、连续性锁、参考槽位**。

> **与资产三篇的分工**：本篇管**条目本身**——有哪些人、哪些地、哪些物，事实是什么。
> 怎么把这些条目写成能出图的提示词，分别在 `05-character-assets.md`（人物）、
> `08-scene-assets.md`（场景）、`09-prop-assets.md`（道具）。
> **本篇不写提示词，资产篇不改事实。**

---

## 零、先分三类：身份、变体、瞬态

写条目之前，先把「这个对象身上会变的东西」分进三个篮子。**分错篮子，资产会越建越多，最后互相打架。**

| 类别 | 人物 | 地点 | 道具 |
|---|---|---|---|
| **持续身份**（不变则复用） | 脸型骨相、体态、永久特征、固定配饰 | 空间地理、分区关系、入口、固定锚点 | 形制、尺度、材料、永久标记 |
| **变体**（`new_variant`） | 服装、发型、妆容、伤势、湿污、年龄阶段、伪装 | 可复用观察视角、陈设阶段、时段、天气、光态 | 持有人、位置、开闭、破损、内容 |
| **瞬态**（**归分镜，不进资产**） | 瞬时表情、姿势、视线、画面左右 | 单镜机位、焦段、演员站位 | 被抬起的一瞬、画面左右位置 |

**判断步骤**：

1. 排除瞬态——「侧脸」「俯拍柜台」「杯子在画面右侧」只在单镜成立，交分镜；
2. 对齐持续身份——凭稳定锚点、剧情连续、唯一标记对齐，**不单凭名字**（两个「值班员」未必是同一人，同一人换称谓也不变身份）；
3. 变体还是状态：**跨多场持续、需独立参考图** → 建变体；**只维持半场几镜** → 写状态变化，不拆条目；
4. 仅在持续身份真的不同时建新条目（另一个人、独立地理的空间、需独立追踪的同款多件道具）。

**地点还要多分一层**：地点是**空间身份**，视图是**可复用的观察方向 + 光态**。同一间屋停电前后是两个视图，仍是一个地点。
详见 `08-scene-assets.md` 第一节。

## 零·二、先建总美术基准

**动笔写第一个条目之前，先把这一页定下来。** 它是所有资产的共同祖先——后面每个人、每间屋、每件东西都从这里派生。

### 九项基准

| 项 | 写什么 | 例（《清算日》） |
|---|---|---|
| **时代** | 明确年代或架空参照 | 当代都市，2020 年代 |
| **地域** | 城市类型与文化来源 | 中国南方一线城市 |
| **季节气候** | 影响面料厚度、空气颗粒、皮肤反应 | 夏末，闷热，多雨 |
| **社会阶层** | 决定材料纯度、染色稳定度、缝制精度 | 顶级财阀 vs 破产旧族，两极 |
| **技术水平** | 有无电、有无金属加工、有无印刷 | 现代，全电，数字办公 |
| **文化来源** | 纹样、色彩、器物风格的出处 | 现代主义 + 少量中式旧物 |
| **主色关系** | 主色 / 辅色 / 点缀色，全片统一 | 暖棕琥珀 vs 冷蓝灰，冷暖对立 |
| **材质谱系** | 这个世界主要用什么材料 | 深色实木、真丝、黄铜、玻璃、哑光金属 |
| **旧化程度** | 整体做旧基准 | 新物为主，旧物集中在她与他身上 |

### 为什么必须先定

不定基准会出现三种崩：

| 崩法 | 症状 |
|---|---|
| **阶层混了** | 破产的人穿着不该有的料子，有钱人穿得像地摊 |
| **时代混了** | 古装戏出现电灯，现代戏出现毛笔字招牌 |
| **材质乱了** | 同一部戏里，木头像塑料、金属像纸 |

**基准越具体，下游越省事。** 「现代都市」不够，要写到「深色实木 + 真丝 + 黄铜 + 玻璃」这一级。

### 共享锚点

定了基准之后，让不同资产共享可识别的元素：

```markdown
- 同一阵营共享纹样：顾氏家族用「双环含短剑」，出现在黑卡、徽章、门把、信封封蜡
- 同一阶层共享材质：财阀场景一律深色实木 + 黄铜；旧族场景一律灰白 + 木 + 布
- 同一时代共享光：全片无冷白 LED，室内只用台灯与窗外天光
```

**这些锚点是观众说不出但感觉得到的东西。** 第 20 集出现一枚新信封，上面有那个双环，观众立刻知道"这是顾家的"。

### 资产编号

```markdown
- 资产编号：图1
```

**规则**：
- `图N`，全项目唯一，**定下不改**；
- 不写会由顺序推导，新增条目时旧图号全部漂移，素材接线单失效；
- 人物、地点、道具各自连续编号，**造型不占号**（造型是变体，靠换装模板派生）。

## 零·三、四类资产的固定出图参数

每类资产有标准化的出图设置，保证同一类资产的呈现一致。

### 人物

```
专业时尚摄影质感，全身照，纯白无缝背景，单人，单一正面三分之二视角，
85mm 焦段，光圈 f/1.8，面部与皮肤毛孔清晰，
主光为左前方大型柔光箱、补光比主光低两档、后侧窄条轮廓光，
双脚完整入画，双手自然下垂且不拿任何道具，
严禁场景，严禁拼图，严禁多视图，严禁文字与水印
```

### 场景

```
广角镜头，全景或远景构图，单一视角，完整空间透视，
无人物，无动物，无剧情动作，
严禁拼图，严禁多视图，严禁文字与水印
```

### 道具

```
影棚产品摄影，纯白无缝背景，单一正面三分之二视角，
仅展示一个完整道具主体，微距细节清晰，边缘高光受控，接触阴影完整，
严禁人物，严禁手部，严禁场景，严禁拼图，严禁多视图，严禁文字与水印
```

### 服装（横向设定板）

```
横向 Costume Sheet 布局，纯白背景，均匀柔和的影棚光照，
正面、标准侧面、背面三个等高全身视图，脚底对齐同一基线，
部件拆解 + 局部放大 + 材质样片 + 颜色样片，
简体中文标注，
严禁剧情背景、环境道具、水印、签名
```

**为什么固定**：不固定，同一角色的十张图会有十种光照和焦段，剪在一起像十部片子。

## 一、四类条目

视觉设定只有四类，不要发明第五类。

```markdown
## 人物 · 沈惊歌
## 造型 · 沈惊歌-破产日
## 地点 · 顾氏总裁办
## 道具 · 黑卡
```

标题语法是硬性的：`## <类别> · <名称>`。分镜的「视觉依据」靠这个语法定位。

### 人物条目

```markdown
## 人物 · 沈惊歌
- 资产编号：图1
- 识别锚点：24岁东亚女性，鹅蛋脸，眼尾上挑，左眉尾有一道浅疤，锁骨下方一颗小痣，身形偏瘦。
- 画面代称：ShenJingge、沈惊歌
- 声音：烟熏嗓，语速偏慢，每个字都像在喉咙里撕扯。
- 本集造型：见「造型 · 沈惊歌-破产日」
- 状态变化：EP001-SC003 后右手掌心有指甲掐出的血痕。
- 连续性锁：LOCK-SHEN-SCAR《左眉尾浅疤》（镜头：入画）
```

**逐项说明**：

| 字段 | 作用 | 硬性要求 |
|---|---|---|
| **资产编号** | `图N`，全项目唯一、**定下不改** | 不写则由顺序推导，**新增条目会让旧图号漂移** |
| 识别锚点 | 身份令牌，**逐字复用** | 必须是可见的物理事实；不得写「气质清冷」「五官精致」这类不可画的东西 |
| 画面代称 | 提示词正文里怎么称呼她 | 非中文提示词时**必须**给英文代称，否则模型不认识中文名 |
| 声音 | 配音与音色参考 | 一句话，写质地不写形容词堆砌 |
| 本集造型 | 指向造型条目 | 不在这里重复写服装细节 |
| 状态变化 | 本集内会变的可见状态 | 写清「哪场之后」+「变成什么」 |
| 连续性锁 | 跨镜不该变的东西 | 见下节 |

### 造型条目（身份 vs 变体）

**这是最容易搞错的地方。**

同一个人换了衣服，不是新人物，是同一个身份的**新造型**。

```markdown
## 造型 · 沈惊歌-破产日
- 身份：沈惊歌
- 适用：EP001-SC001 至 EP001-SC004
- 锁定：灰白色旧真丝衬衫，右袖口有一处勾丝；黑色直筒西裤；裸色平底鞋。
- 配饰：左手无名指一枚素圈（已褪色）。
```

| 什么该拆成新造型 | 什么不该 |
|---|---|
| 换整套服装 | 换一件外套（写进状态变化） |
| 受伤后/受伤前 | 袖子卷起来（写进单镜描述） |
| 年龄跨度过大（少年/成年） | 头发被雨打湿（写进单镜描述） |
| 妆容剧变（伪装前后） | 摘了眼镜（同上） |

判断标准：**这个变化会不会持续一整个段落以上？** 会 → 新造型；不会 → 单镜描述。

### 地点条目

```markdown
## 地点 · 顾氏总裁办
- 空间锚点：南向落地窗（画面右），深色实木长桌居中，桌后一把高背皮椅，左侧一排书架，门在北墙偏左。
- 固定陈设：桌上一盏黄铜台灯、一个水晶烟灰缸、一叠文件托盘。
- 光线变体：
  - 夜景（主）：仅台灯与窗外城市灯，暖黄主光来自桌面右侧，人物左脸留暗。
  - 日景：落地窗自然光为主，逆光，人物成半剪影。
- 连续性锁：LOCK-OFFICE-DESK《深色实木长桌》（镜头：入画）
```

**空间锚点必须写方位**（画面左/右/中），因为模型需要知道东西在哪。不要写「宽敞明亮」「奢华大气」——那是形容词，不是空间。

### 道具条目

```markdown
## 道具 · 黑卡
- 外观锚点：哑光黑色金属卡片，边缘镶碎钻，卡面中央一枚银色家徽（双环内含一柄短剑）。
- 尺寸基准：标准银行卡大小。
- 状态：EP001-SC005 首次出现，由老管家双手呈上。
- 连续性锁：LOCK-BLACKCARD《哑光黑金属镶钻卡片》（镜头：入画）
```

**只有「关键道具」才建条目**：承担叙事功能、跨镜出现、有状态变化。场景里的普通陈设不建。

## 二、识别锚点：令牌不是描述

### 为什么必须逐字复用

同一角色在第 3 镜写「黑色齐肩直发」，第 7 镜写「黑色中长发」——**在模型眼里这是两个人**。它不会理解「中长」是「齐肩」的同义改写，它会重新推断一次发型。

所以锚点是**令牌**：一旦定下，全项目逐字复制，包括标点。

### 锚点该写什么

| 该写 | 不该写 |
|---|---|
| 年龄区间（24岁，不是「二十出头」除非原文如此） | 精确到岁的假精确（原文说二十多岁就写二十多岁） |
| 脸型、眼型、眉形 | 「精致」「高级感」「网红脸」 |
| 永久特征：疤、痣、断眉、胎记 | 临时状态：脸红、出汗、头发乱 |
| 身形轮廓（偏瘦/健壮/娇小） | 身高厘米数（模型不认） |
| 固定配饰（长期佩戴的） | 手持道具（归道具条目） |

**通用模板话术是毒药。** 「九头身黄金比例」「完美五官」「精致面容」会覆盖人物真实特征，把所有人都画成同一张脸——而这正好撞在平台治理「高频 AI 脸」的枪口上。

### 锚点长度

**30–60 字。** 短了不够识别，长了会被稀释：

- 少于 30 字：只有「年轻女性」，每次生成都是不同的人；
- 多于 60 字：模型会丢掉后半段，实际只用前 40 字，等于白写。

## 三、连续性锁

锁管的是「跨镜不该变、但容易被模型改掉的东西」。

```markdown
- 连续性锁：LOCK-SHEN-SCAR《左眉尾浅疤》（镜头：入画）
- 连续性锁：LOCK-SHEN-SUIT《灰白旧真丝衬衫》（镜头：EP001-SC001、EP001-SC003）；图片提示词项：IMG-SHEN-SHEET
```

### 语法

```
LOCK-<标识>《<锁面>》（镜头：<范围>[；图片提示词项：<IMG-...>]）
```

| 部分 | 规则 |
|---|---|
| `LOCK-` 标识 | 本集唯一，大写+连字符 |
| 锁面 | **最小名词短语**，不含标点、不含动作、不含剧情。如「左眉尾浅疤」不是「左眉尾有一道被刀划的浅疤」 |
| 镜头范围 | `入画`（所有含该条目的镜头）/ `全集` / `SHOT-...` 列表 |
| 图片提示词项 | 可选，指向 `IMG-...` |

### 哪些该上锁

| 上锁 | 不上锁 |
|---|---|
| 服装主色与形制 | 衣服的褶皱方向 |
| 发型长度与颜色 | 被风吹起的发丝 |
| 伤口位置与形态 | 伤口渗血的多少 |
| 道具颜色与材质 | 道具表面的反光 |
| 永久配饰 | 临时手持物 |

**判断标准**：跨镜保持不变吗？变了会让观众觉得「这不是同一个人/同一件东西」吗？两个都是「是」，才上锁。

### 锁面为什么要短

因为机检要**逐字比对**：锁面必须原样出现在生效镜头的关键帧提示词正文里。

锁面写「左眉尾有一道浅疤，看起来很凶」，正文里写「左眉尾浅疤」，比对失败。锁面写「左眉尾浅疤」，正文里带上这四个字，通过。

**锁面是锚，不是句子。**

## 四、画面代称

提示词正文里怎么称呼这个条目。

```markdown
- 画面代称：ShenJingge、沈惊歌
```

### 三条规则

1. **非中文提示词，所有人物必须有非中文代称**。模型不认识汉字人名，写「沈惊歌」在英文提示词里等于没写。
2. **多个写法用「、」分隔，至少两个字符。**
3. **写 `画面代称：无` 可取消名称匹配**——用于「手机」「小雨」这类容易撞普通词的条目。

碰撞的例子：道具叫「手机」，正文写「手机店的招牌」，机检会以为道具手机在画面里。这时给道具写 `画面代称：无`。

## 五、参考槽位：REF- 与 PLAN-

参考图是「实际送进模型的那张图」，和「提示词条目」是两回事。

### 三种依据，严格区分

| 依据 | 是什么 | 证明什么 |
|---|---|---|
| **视觉依据** | 指向 `视觉设定.md` 的条目 | 这个镜头画面里有什么 |
| **图片提示词项** | `图片提示词.md` 里的 `IMG-...` | 有这个提示词条目（**不代表图已生成**） |
| **输入参考图** | 实际送进模型的图（`REF-...` / `PLAN-...`） | 这张图控制什么 |

**三者不能混。** 「我写了 IMG-XXX」不等于「我有图」。

### 语法

```
REF-<槽位>（顺序：<n>）· <项目相对路径>《<中文名>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
PLAN-<槽位>（顺序：<n>）· <IMG-...或SHOT-...>《<中文名>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
```

`用途` 只能取这九个之一：

`身份` / `造型状态` / `地理` / `构图` / `尺度` / `效果` / `起始帧` / `结束帧` / `风格`

### 四种状态

| 状态 | 写法 | 含义 |
|---|---|---|
| **已绑定** | `REF-...` | 真实文件在项目里，可投产 |
| **已声明** | `PLAN-...` | 创作者在外部平台自己挂图（**默认路径**） |
| **待补** | `无（待补参考图：...）` | 创作者明确要求等图进项目，此时**阻止**出最终视频提示词 |
| **明确不用** | `无（创作者已明确选择文生视频）` | 走文生视频 |

**关键规则**：

- 一张图只占一个槽位。承担两件事时，`用途` 写主项，副项进「控制」；
- 一镜最多一张 `起始帧`、一张 `结束帧`；有 `结束帧` 必须有 `起始帧`；
- **用户没有手工指定参考图，不等于选择文生视频。** 默认走 `PLAN-`（挂图计划）。

### M0 形态怎么写

素材形态是 M0（纯提示词）时，**一个图号都不出现**，一致性全靠文字锁：把锚点、造型、空间写进每一条提示词正文。

M0 的成本是提示词更长、一致性更低；收益是零素材依赖。适合试水和纯文字交付。

## 六、时代锚点

古装、年代戏必须锁「不该出现的东西」，否则模型会自由发挥。

```markdown
## 时代锚点 · 架空古风（唐制参考）
- 必须在场：直棂窗、素面青砖、烛台、漆器、竹简或纸卷
- 禁止出现：玻璃窗、电灯、塑料、拉链、纽扣（用系带）、现代印刷字体、水泥
- 材质基调：木、石、丝、麻、陶、铜
- 光线来源：烛、油灯、天光、月光（**无电光源**）
```

**「光线来源」这一条最容易被忽略。** 古装戏里出现一束方向明确的冷白光，就是电灯——观众说不清哪里不对，但会立刻出戏。

## 七、视觉设定自检

- [ ] 每个出场人物都有条目，且识别锚点 30–60 字？
- [ ] 每个锚点写的都是**可画的物理事实**，没有「精致」「气质」？
- [ ] 同一角色的造型变化，是拆成了新造型条目，还是塞进了状态变化？
- [ ] 每个地点都有空间锚点（含方位）和光线变体？
- [ ] 关键道具都建了条目，普通陈设没有乱建？
- [ ] 跨镜不该变的东西都上了锁，锁面都是短名词短语？
- [ ] 非中文提示词的人物都有非中文代称？
- [ ] 古装/年代戏有时代锚点，且写了「光线来源」？
- [ ] 没有把「写了 IMG-」当成「有图」？

第 2、6、9 题最容易错，重点看。
