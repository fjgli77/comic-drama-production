# 采风与对标：动笔前先知道别人做到哪

**选题定生死。** 但大部分人做选题的方式是"我觉得这个会火"。

这一篇讲的不是"抄爆款"，是**用同口径把自己的计划量一遍，再跟对标量一遍**。
量完你会发现，很多问题不是审美问题，是数量问题——镜数不够、对白太密、开场太慢。

---

## 一、信源分级：先分清什么能当证据

网上关于"爆款规律"的说法，可信度差三个量级。

| 级 | 信源 | 能拿来干什么 | 不能干什么 |
|---|---|---|---|
| **T1** | 平台官方公告、创作后台数据、平台发布的榜单 | 定规格（集长、集数、分成）、判断题材是否被限 | 推断"为什么火" |
| **T1.5** | 第三方数据站（热榜、投流榜、短剧数据平台） | 看趋势、看投放强度、看生命周期 | 当精确数据用（口径不明） |
| **T2** | 媒体报道、公众号拆解、同行复盘、社群讨论 | 找线索、找解释、找手感 | 当事实引用 |

**纪律**：写进项目的每一条外部结论，都标上信源级别。
**T2 的信息可以用来启发，不能用来决策。**

---

## 二、采风四步

不要一上来就刷剧。按这个顺序，半小时能出一张卡。

### 第一步：定靶（10 分钟）

选 **3 部**对标，条件写死：

- 同一平台（不同平台的节奏完全不同）
- 同一画幅（9:16 与 16:9 不可比）
- 同一体量（单集 60~120 秒，别拿 5 分钟精品剧比）
- 至少一部是**近 30 天**上的（半年前的口径已经失效）

### 第二步：量数（15 分钟）

**只量能数的东西，不写感受。** 每部剧拆前 3 集，量这六项：

| 项 | 怎么量 |
|---|---|
| 单集时长 | 掐头去尾，正片时长 |
| 镜数 | 数切点 +1 |
| 平均镜长 | 时长 ÷ 镜数 |
| 台词句数 | 数带引号/字幕的句子 |
| 台词总字数 | 数汉字，不算标点 |
| **对白密度** | 字数 ÷ 秒（这是最有用的一项） |
| 前 3 秒有没有异常 | 有 / 无（有的话是什么异常） |
| 集尾停在哪 | 动作中 / 台词中 / 静帧 / 黑场 |

### 第三步：填卡（5 分钟）

```markdown
# 对标情报卡 · 2026-11

## ① 《XXX》 · 平台 / 上线日 / 集数
- 信源：T1（平台热榜第 3）
- 单集 96s · 24 镜 · 平均 4.0s/镜
- 台词 19 句 / 268 字 → 对白密度 2.8 字/秒
- 前 3 秒：女主被推下楼梯（异常：身体失控）
- 集尾：手机屏幕亮起，未接来电 17 个（信息悬念）

## ② 《YYY》 …
## ③ 《ZZZ》 …

## 共性（三部的交集，不是某一部的特点）
- 平均镜长都在 3.5~4.5s
- 对白密度 2.6~3.0 字/秒（**低于我原来的 4.2，说明我台词写太满**）
- 三部都在前 3 秒给了身体层面的异常（不是信息，是身体）
- 集尾三部都是"信息悬念"，不是"动作悬念"
```

**「共性」那一栏才是产出。** 单部剧的特点没有意义，三部的交集才是这一档的规格。

### 第四步：对本项目（5 分钟）

```bash
python scripts/cd.py bench ./my-drama --sec 96 --shots 24 --chars 268
```

它会用**同一套口径**把你的剧本算一遍，跟对标并排。

## 三、六条证据纪律

采风最容易变成"我看到一个说法，然后到处找证据"。

| # | 纪律 |
|---|---|
| 1 | **不写"大家都说"** —— 要么给信源，要么不写 |
| 2 | **不把个案当规律** —— 一部爆款不能推出任何结论，至少三部 |
| 3 | **不混口径** —— 拿"含广告的时长"比"正片时长"，结论一定错 |
| 4 | **不做事后归因** —— "因为它节奏快所以火"是猜测；"它平均镜长 3.8s"是事实 |
| 5 | **不抄结论，抄规格** —— 抄"对白密度 2.8"可以，抄"要爽"没用 |
| 6 | **数据会过期** —— 标上采集日期，三个月后重采 |

## 四、同口径比对什么

`bench` 比的四项，每一项都对应一个可执行的修改：

| 指标 | 算法 | 偏高说明 | 偏低说明 |
|---|---|---|---|
| **平均镜长** | 总时长 ÷ 镜数 | 镜头太长，节奏拖 | 切太碎，观众跟不上 |
| **对白密度** | 台词字数 ÷ 总秒数 | 台词太满，配音会赶 | 台词太空，全靠画面撑（漫剧可行，但要有视觉信息补） |
| **每镜台词句数** | 句数 ÷ 镜数 | 一镜塞多句，口型必崩 | 一镜一句以下，说明有大量无台词镜 |
| **集时长** | 分镜总长 | 超平台上限 | 完播率可能高但信息量不够 |

**容差**：±20% 以内视为同档。超出就要能说出为什么——
比如你的剧是强视觉型的，对白密度天然低，那就写明"刻意为之"，不要改。

## 五、什么不该对标

| 别对标 | 为什么 |
|---|---|
| 真人实拍短剧的镜长 | 实拍一个镜头能装 2 个信息点，AI 生成装不下 |
| 大 IP 改编的集长 | 它有粉丝底盘，可以慢 |
| 投流爆款的节奏 | 你看到的是"投出来的"，不是"内容跑出来的" |
| 一年前的数据 | 平台规则、用户耐心、模型能力都变了 |

**对标的目的不是"变成它"，是知道"行业基准在哪"，然后决定偏离多少。**

---

## 六、采风自检

- [ ] 三部对标同平台、同画幅、同体量？
- [ ] 至少一部是近 30 天的？
- [ ] 六项数据都量了，还是只写了"感觉"？
- [ ] 写出的是"共性"还是"某一部剧的特点"？
- [ ] 每条外部结论都标了信源级别？
- [ ] 用 `bench` 同口径比过，偏差超过 20% 的项能说出理由？
- [ ] 标了采集日期？

前三题决定这张卡有没有用，后四题决定它可不可信。
