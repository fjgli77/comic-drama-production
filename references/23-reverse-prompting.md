# 逆向提示词：从图或视频反推可复现的提示词

> 用途：拿到一张图、一段片子，反过来还原「它是怎么写出来的」。
>
> 适用场景：拆竞品、复刻风格、救回丢失的提示词、给参考素材建档、学员作业诊断。

---

## 零、先摆正：反推不是描述

三件事容易混，结果完全不同：

| 做的事 | 产出 | 有用吗 |
|---|---|---|
| **描述画面** | 「一个穿黑裙的女人站在窗边」 | ❌ 这是看图说话，写不出提示词 |
| **拆解归因** | 「黑裙是提示词控制的；窗光方向是模型默认补的」 | ✅ 中间产物 |
| **写回可复现** | 一段跑一次就接近原图的提示词 | ✅ 目的 |

**分界线是「归因」**：画面里每一样东西，你得判断它是**谁决定的**。判错了，反推出来的提示词就是错的，而且错得很像对的。

---

## 一、三种归因，必须分清

反推的每个要素都先归到这三类之一：

| 归因 | 含义 | 判定线索 |
|---|---|---|
| **提示词控制** | 有人明确写了 | 高度具体、非平均、有取舍的细节。比如「左眉尾一道浅疤」「黑曜石尾戒」 |
| **参考图带入** | 来自上传的图 | 角色/场景与实拍或既有设定高度一致；构图异常贴合；有真实摄影的瑕疵（噪点、镜头畸变） |
| **模型默认** | 模型自己补的 | 符合该模型/该画风的平均值；同类图到处都是；常见套路（暖光轮廓、飘落花瓣、光滑皮肤） |

### 判不准时看三个信号

1. **异常性**：这个东西在同类图里常见吗？常见 → 模型默认；独一份 → 提示词或参考图
2. **可描述性**：能不能用一个短语精确定位？能 → 提示词；说不出只能感觉 → 模型氛围
3. **一致性**：同一批图里它是否稳定出现？稳定 → 提示词或参考图；忽有忽无 → 模型随机

### 一条反直觉的判据

**越「好看」的东西，越可能是模型默认。**

模型默认补的都是它的审美平均值：柔光、暖调、发丝飘动、轻微空气感。真正被提示词控制的东西，往往更具体、更不平均，甚至有点难看——比如「袖口第二颗扣子掉了」「右手虎口一层薄茧」。

反推时如果满篇都是「唯美」「电影感」，说明你只读到了模型的默认值，没读到提示词。

## 二、图像反推：七步

### 第 1 步：先定「像什么介质」

不要一上来就写内容。先判断这张图是什么类型的产物：

| 类型 | 特征 | 反推重点 |
|---|---|---|
| 概念设定图 | 纯背景、单体、无场景 | 版式 + 材质 + 光位 |
| 电影剧照 | 有景深、有环境、人物在演 | 镜头 + 光比 + 氛围 |
| 插画 | 明显笔触、非写实 | 画风词根 + 色板 |
| 摄影合成 | 真实瑕疵、镜头感 | 焦段 + 光圈 + 色温 |
| 三维渲染 | 材质过于干净、边缘有 AO | 材质参数 + 布光 |

**介质判错，后面全错。** 把插画按剧照反推，会写出一堆「85mm f/1.8」但画面根本不是那么来的。

### 第 2 步：拆四层

按本 Skill 的四层结构逐层填，**不要跳层**：

| 层 | 要写出来的 | 常见漏项 |
|---|---|---|
| **叙事层** | 谁 / 在哪 / 做什么 / 什么情绪 / 什么关系 | 情绪只写「悲伤」，不写身体表现 |
| **镜头层** | 景别 / 角度 / 机位高低 / 焦段感 / 景深 | 只写「特写」，不写是俯是仰 |
| **光影层** | 光源方位 / 色温 / 光比 / 硬软 / 有无轮廓光 | 只写「逆光」，不写色温和光比 |
| **模型层** | 画幅 / 分辨率 / 风格词根 / 参考槽位 / 排除项 | 完全不写——这是最常漏的一层 |

### 第 3 步：光影必须量化

这是反推质量的分水岭。定性描述复现不出来：

| ❌ 定性 | ✅ 可复现 |
|---|---|
| 光线很美 | 主光在画面右后 45°，暖黄约 3200K，右脸亮、左脸落深影，光比约 1:4 |
| 有氛围 | 空气中有细尘，逆光下形成一道可见光束，背景比前景低两档 |
| 冷暖对比 | 前景暖橙（约 2800K）、背景冷蓝（约 6500K），交界在人物肩线 |

**怎么读光比**：看最亮处与最暗处差几档。差一档约 2 倍，差两档约 4 倍，差四档就是 1:16，接近纯黑。

**怎么读光源方位**：看鼻影方向、颈影落点、眼窝亮暗、高光位置。四处交叉验证，比单看一处可靠。

### 第 4 步：找「反向证据」

这一步最容易被跳过，也最能提升准确度。

**找那些「模型不会主动画」的东西**：六指、错位的扣子、文字乱码、多余的饰物、不合逻辑的阴影。它们暴露了：

- 文字乱码 → 说明有人要求过文字，但模型搞砸了（该模型弱文字）
- 多余饰物 → 说明参考图里有，模型抄过来了
- 不合逻辑的阴影 → 说明是多光源叠的，或者后期合成

**反向证据比正向证据可信**：正向特征到处都有，反向特征只有特定原因才会出现。

### 第 5 步：标置信度

每个反推出来的要素都标一个：

| 级别 | 含义 | 怎么处理 |
|---|---|---|
| **高** | 有明确证据（反向证据、可量化、一致性稳定） | 直接写进提示词 |
| **中** | 合理推断（符合该画风、无矛盾） | 写进提示词，跑一次验证 |
| **低** | 猜测（可能是模型默认） | **单独列出，不进主提示词** |

**低置信项单独放一个「待验证」区**，不要混进正文。混进去的代价是：你以为是提示词控制，其实是模型自带，下次换了模型就复现不出来，而你不知道为什么。

### 第 6 步：写成提示词

按四层顺序组装，注意三件事：

1. **不要覆盖全部细节**。人写不了那么细，模型也不读那么细。留 20% 给模型补，反而更像人写的。
2. **用提示词语言，不用评论语言**。「眼神里有一种说不清的疲惫」是评论；「上眼睑略垂，眼下有一层青黑」是提示词。
3. **排除项单独一段**，写清不要什么（但别写你想避免的东西的名字——见第六节）。

### 第 7 步：复现验证

反推完必须跑一次，然后比对：

| 差异类型 | 说明什么 | 怎么改 |
|---|---|---|
| 构图差一点 | 景别或角度词不准 | 补机位高度、补焦段 |
| 光不对 | 光位或光比判断错 | 重新读鼻影与颈影 |
| 画风偏了 | 风格词根选错 | 换词根，不是加形容词 |
| 人物不像 | 缺参考图 | 这一项提示词补不了，必须挂参考 |
| 多了不该有的 | 排除项失效 | 改成正向穷举（见第六节） |

**一次成功的反推很少见。** 通常要两到三轮。第一轮修构图与光，第二轮修画风，第三轮修细节。

## 三、视频反推：比图像多三样

视频不是「一张会动的图」。反推视频要多解三样东西：**运动、时间、声音**。

### 前置：抽帧

反推视频必须先拿到帧。**按动作节点抽，不按固定间隔抽**：

| 抽什么 | 目的 |
|---|---|
| 首帧、尾帧 | 起点与终点的状态，判断动作幅度 |
| 动作的每个转折点 | 动作分几拍 |
| 运镜的起止 | 镜头动没动、怎么动 |
| 出现新元素的那一帧 | 何时入画 |

固定每 0.5 秒抽一张是浪费——大部分帧是重复信息。**一次 8 秒的镜头，通常只需要 4–6 帧。**

没有抽帧工具时，让人工截图：告诉对方「截动作变化的那几张，不是每隔几秒截一张」。

### 第一样：运动归因

看到动作，先分三层：

| 层 | 谁在动 | 反推要点 |
|---|---|---|
| **主体运动** | 人物/物体 | 动作分几拍、有无预备动作、有无惯性余势 |
| **镜头运动** | 摄影机 | 推/拉/摇/移/跟/升降/环绕/手持，只有一种 |
| **环境运动** | 光、烟、水、发丝、衣摆 | 有无、方向、速度 |

**易错**：把镜头运动误判成主体运动。人物在画面里变大，可能是人走近，也可能是镜头推近——看背景是否同步放大：背景也放大 → 镜头在推；背景不变 → 人在走。

### 第二样：时间结构

把整段切成拍，标出每拍的起止：

```
0.0–0.6s  预备（她吸气，肩微沉）
0.6–1.8s  动作（抬眼，视线移到画外右侧）
1.8–3.5s  停滞（保持，只有呼吸）
3.5–4.0s  收（嘴角单侧抬起）
```

**这个结构比画面描述更有用**，因为视频模型最容易在「时间分配」上崩——你写「她缓缓抬头又笑了一下」，模型可能两秒全做完。

反推时要回答：这段里有几个「事件」？事件之间是连续还是停顿？停顿多久？

### 第三样：声音

| 项 | 判断 |
|---|---|
| 有无原生音频 | 脚步声与画面是否同步；对白口型是否对齐 |
| 音轨构成 | 环境底 / 动作音 / 人声 / 音乐，各占多少 |
| 有无静默 | 静默点在哪（静默是最容易被忽略的信息） |

**原生音频是硬信息**：有同步对白且口型对得上，说明该模型支持原生音频（Seedance 2.5 / H3 / Veo 3.1 / Kling 3.0 / Wan 3.0 都支持）；口型对不上，说明是后期配的。

### 有台词时：先把「谁在说话」钉死

反推带对白的片子，最容易犯的不是视觉错，是**说话人错**。错了会导致后面所有归因都歪——你以为是 A 的动作，其实是 B 的反应。

#### 锁一：同人归并

**同一张脸 + 同一套主服装 = 同一个人。** 以下三种变化，一律不许拆成两个角色：

| 变化 | 错误做法 | 正确认知 |
|---|---|---|
| 瞳色变了（黑瞳 → 金瞳/红瞳） | 拆成「灰衣女子」和「金眼女子」 | 同一个人，进入施法/感知状态 |
| 法相显露（收起尾巴 → 展开九尾、手掌化爪） | 拆成「老祖宗」和「狐族成员」 | 同一个人，本体或全力状态 |
| 战损妆造（衣衫整洁 → 吐血、披发） | 拆成两个人 | 同一个人，战后状态 |

**这条在漫剧里尤其重要**：特效变身、境界突破、战损，都是同一个角色。拆错了，反推出的提示词会把一个人写成两个，资产表也跟着错。

#### 锁二：用称谓反查真名

裸视频没有角色表。别用「白衣女子」「寸头男」这类外貌代称——它们是临时标签，不是名字，写进提示词会被模型当成新的身份特征。

**做法**：把全片所有直呼其名或尊称的句子挑出来，看它们指向哪个视觉人物，然后锁定唯一标准名。

```
00:05 褐衣男对树下白衣女子拱手叫「瑶瑶」
00:20 熊猫妖跑向同一棵树叫「老祖宗」
00:48 魔物对同一白衣九尾女子骂「涂山家的狐狸」
        ↓
锁定：涂山瑶（涂山老祖宗），全片统一，禁用外貌代称
```

确实无人叫出名字的配角，也要给一个**唯一且有辨识度的身份标签**（「褐衣随从」「独眼黑雾魔物」），并在全片保持同一叫法。

#### 锁三：按句抽帧，不按秒抽帧

**每隔十几秒抽一帧再猜说话人，一定错。**

正确做法：拿到每句台词的起止时间后，**在每句的正中间 `(start+end)/2` 抽一帧**，逐句核对三件事：

1. **看画面主体是谁**——这一秒镜头里是谁
2. **看嘴唇开合**——张嘴=现场对白；闭着嘴却有声音=内心独白
3. **看声线与混响**——粗犷兽吼 / 清冷女声 / 憨厚喘息，三种声音对应三个人

#### 附带：画外音怎么判

| 判据 | 结论 |
|---|---|
| 画面给到该角色特写，**嘴唇紧闭**却有声音 | 内心独白（OS） |
| 台词极具挑衅性，但对手**毫无反应** | 内心独白或旁白 |
| 角色独处时**嘴唇明显张合** | 现场自语，算普通对白，不是 OS |
| 镜头拍的是听的人，声音来自画外 | 画外对白 |

**为什么值得单独判**：OS 和现场对白的提示词写法不同——OS 不需要口型同步，现场对白需要。判错了，反推出的提示词会让模型去同步一个不该同步的口型。

### 视频反推的四层表（比图像多两列）

| 层 | 图像反推 | 视频反推还要多写 |
|---|---|---|
| 叙事层 | 谁在哪做什么 | + 这段戏的**戏剧任务**（在整场里起什么作用） |
| 镜头层 | 景别角度光 | + **运镜**（只有一种）+ 运镜速度 |
| 光影层 | 光位色温光比 | + 光是否**随时间变化** |
| 时间层 | — | **拍数 + 每拍时长 + 停顿位置** |
| 声音层 | — | 原生/后期 + 音轨构成 + 静默点 |
| 模型层 | 画幅风格排除 | + **单段时长是否吃满模型上限**（判断用的是哪个模型） |

### 从时长反推模型

这是个实用技巧，判断这条片子用了什么模型：

| 观察 | 推断 |
|---|---|
| 单镜 25–30 秒且运镜连续 | Seedance 2.5 或 Wan 3.0 |
| 单镜 12–15 秒 | Seedance 2.0 / Kling 3.0 / MiniMax H3 |
| 单镜 8 秒且切得很碎 | Veo 3.1 |
| 一镜里出现多个不同机位且过渡自然 | Seedance 2.5 的多镜头模式 |

**知道对方用什么模型，反推才有意义**——你按 Seedance 2.5 的写法反推一条 Veo 的片子，结论一定是错的。

## 四、复刻的三档深度

反推结果能用到什么程度，取决于你要复刻多少：

| 档 | 复刻什么 | 改什么 | 风险 |
|---|---|---|---|
| **A 形似** | 画风、光、构图 | 换人物、换场景，保留视觉语言 | 低。合法，但容易撞车 |
| **B 神似** | 戏剧机制、节奏、爽感算式 | 换外壳（人物身份、世界观、具体事件），保留结构 | 中。需要剥壳，见下 |
| **C 复刻** | 全部 | 几乎不改 | 高。原创性存疑，平台会判搬运 |

### B 档的做法：剥壳留核

这是最实用的档，也是唯一需要方法的档。

1. **剥壳**：列出原片的外壳——具体人名、地名、职业、道具、台词、标志性桥段。这些全部禁用。
2. **留核**：提炼戏剧算式。不是「她复仇」，而是「被剥夺者用被剥夺的东西反杀剥夺者」。
3. **换皮**：换三个维度——换身份（律师→医生）、换场景（法庭→手术室）、换时代（现代→民国）。
4. **防撞车四问**：
   - 有没有同一句台词？
   - 有没有同一个标志性道具？
   - 有没有同一个反转触发点？
   - 有没有同一个场景构图？
   四条都要是「否」。

**只有 B 档值得投入。** A 档学不到东西，C 档有法律风险。

## 五、反推的边界：有些东西反推不出来

必须承认这三件事：

### 1. 参考图反推不出来

如果原图是靠一张参考图锁的形象，你光看结果**无法反推出那张参考图**。你能写出「24 岁东亚女性，齐肩黑发」，但拿不到那份具体的脸。

**结论**：参考图带来的特征，反推只能写「此处需参考图锁定」，不能假装能用文字替代。

### 2. 随机种子反推不出来

同一提示词跑十次是十张不同的图。你看到的那张，是某次抽卡的结果。反推能还原「提示词 + 参数」，还原不了「这一次」。

**结论**：反推目标是「能出同类」，不是「能出一模一样」。

### 3. 后期处理反推不出来

调色、抠图、合成、加字、加特效——这些在生成之后做的，图里看不出来。

**判据**：如果某处「太对了」，好到不像模型能做出来的（比如完美的中文字、精确对齐的排版、干净的抠图边缘），大概率是后期加的，不要写进提示词。

## 六、反推时的三条禁忌

### ① 不要写「不要什么」

模型对否定词响应很差，写「不要有文字」经常反而出现文字。这是普遍的「别想大象」效应。

**正确做法：正向穷举。** 不想有文字，就写「画面为纯图像，无任何字符」。区别很大——前者是提了一次「文字」，后者是声明了画面的属性。

### ② 不要用评价词

「唯美」「电影感」「高级」这类词，模型不认，只会让它往平均值靠。

反推时看到「很美」，要追问：美在哪？是光？是色？是构图？是材质？把它拆成具体项。

### ③ 不要把「模型缺陷」写成「风格」

六指、乱码、畸形——这些是缺陷，不是风格。除非你**故意**要那个缺陷（有些风格化作品要），否则不要写进提示词。

---

## 七、输出格式

反推结果按这个结构交付，别人拿到能直接用：

```markdown
# 反推：〔源文件名〕

## 基本判断
- 介质类型：
- 推测模型：（依据：单段时长 / 音频 / 运镜特征）
- 推断用途：（剧照 / 设定图 / 分镜预览）

## 四层拆解
### 叙事层
### 镜头层
### 光影层
### 模型层

## 归因表
| 要素 | 归因 | 置信度 | 依据 |
|---|---|---|---|

## 可复制提示词
```

## 待验证项
（低置信度的猜测放这里，不进正文）

## 复现记录
| 轮次 | 改动 | 差异 | 结论 |
|---|---|---|---|
```

三项最有价值：**归因表**、**待验证项单列**、**复现记录**。没有这三项的「反推」，本质上还是看图说话。

## 八、反推自检

- [ ] 判断了介质类型，没有把插画当剧照反推？
- [ ] 四层都填了，没有漏「模型层」？
- [ ] 光影量化了（方位/色温/光比/硬软），不是只有定性？
- [ ] 找了反向证据（乱码、六指、多余饰物）？
- [ ] 每个要素标了置信度？
- [ ] 低置信项单独列出，没有混进正文？
- [ ] 视频反推分了运动三层，没把推镜当人走近？
- [ ] 视频反推写了时间结构（几拍 + 停顿）？
- [ ] 视频反推判断了音频是原生还是后期？
- [ ] 排除了参考图 / 随机种子 / 后期处理这三样反推不出来的？
- [ ] 排除项用了正向穷举，没写「不要 X」？
- [ ] 跑过复现验证，记录了差异？
