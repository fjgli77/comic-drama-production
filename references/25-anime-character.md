# 动漫人物：二次元的词法和写实不是一套

**拿写实人像的词去写二次元，出来的是"半写实"——脸是动漫的，皮肤是照片的，光影是影楼的。**

这是动漫人物最典型的一种崩：不是画得差，是**两套审美系统在同一张图里打架**。

这一篇讲二次元人物提示词该写什么、不该写什么，以及为什么写实那套在这儿会失效。

---

## 一、第一件事：脸的结构不一样

写实提示词里的「颧骨」「下颌线」「法令纹」「皮肤纹理」在二次元里**没有对应物**。
二次元的脸是靠**位置与比例**成立的，不是靠骨骼。

| 部位 | 写实怎么写 | 二次元怎么写 |
|---|---|---|
| **眼睛** | 眼窝深度、眼睑褶、卧蚕、睫毛根 | **占脸宽的比例**（约 1/5 脸宽）、眼角角度、上眼睑线的粗细、虹膜占比、高光位置与形状 |
| **鼻子** | 鼻梁高度、鼻翼宽度、鼻头 | 一个**点**、一条**短线**、或一块**斜向阴影**——三选一，不要写"鼻梁挺直" |
| **嘴** | 唇峰、唇珠、唇角、唇纹 | 一条线（闭合）/ 一个小三角（微张）/ 一个弧（笑），要有**厚度感**靠下唇阴影 |
| **脸型** | 颧骨、下颌角、下颌线 | 脸的**外轮廓线**走向：从额角到下巴是直线还是弧线，收在哪 |
| **皮肤** | 毛孔、血丝、油光、次表面散射 | **平涂或两段式渐变**，只保留一处高光；写"皮肤纹理"会立刻写实化 |
| **头发** | 发丝、发量、蓬松度 | **发束分组**：整块头发分成几组，每组有起点、走向、端点；端点尖锐或钝圆；有几根游离的碎发 |

**一句话**：写实写**质感**，二次元写**形状与位置**。

### 眼睛的五层写法（二次元最吃这一项）

```
① 眼型：内眼角〔尖/钝〕，外眼角〔上扬 5°/平〕，上眼睑线〔粗/细〕，双眼皮〔有/无/内双〕
② 虹膜：占眼高约〔70%〕，上缘被上眼睑遮住〔1/5〕，虹膜上方〔深〕、下方〔浅〕的渐变
③ 瞳孔：〔圆形 / 竖椭圆〕，占虹膜〔1/3〕，边缘〔清晰 / 柔化〕
④ 高光：位置〔虹膜左上 1/4 处〕，形状〔圆点 / 十字 / 弧形窗光〕，大小〔约瞳孔的 1/2〕
⑤ 下眼睑：一条〔细线 / 加粗线〕，下方〔无 / 有〕一道浅阴影
```

写"眼睛很大很亮"什么也得不到。写这五层，出来的是同一双眼睛。

### 发束分组（第二吃重）

```
❌ 长直黑发，柔顺有光泽
✅ 黑发，中分，共分 7 组：额前两组刘海（端点在下眼睑高度，尖端分叉）、
   两侧鬓发两组（贴颊，端点在下颌角）、后脑三组（走向向下，端点及腰）；
   发束边缘有 5~8 根游离的细发，方向与主发束一致
```

**组数 + 每组端点位置 + 游离发数**，这三样决定发型能不能复现。
写"柔顺""蓬松""有光泽"是质感描述，对二次元几乎无效。

## 二、风格锚：四选一，不许混

**混搭是二次元人物最隐蔽的死法。** 「赛璐璐 + 柔焦渐变」这种写法，等于让模型自己决定听哪句，
结果是半张图硬边、半张图糊边。

| 锚 | 判别特征 | 适合 | 不要在同一张图里配 |
|---|---|---|---|
| **赛璐璐（cel shading）** | 两到三段平涂色块，阴影边界硬、有明确边缘线；高光是形状不是渐变 | TV 动画、漫剧、需要跨镜一致的资产 | 厚涂、次表面散射、胶片颗粒 |
| **柔焦渐变（soft shading）** | 阴影过渡柔和、无硬边；高光弥散；整体低对比 | 主视觉、轻小说封面、宣发 | 硬边赛璐璐、强轮廓线 |
| **厚涂（painterly）** | 笔触可见、色彩有层叠、边缘不规则 | 概念设定、写实向国漫 | 平涂、动画线稿 |
| **水墨 / 淡彩** | 线有枯笔、色有洇散、留白多 | 国风、古风、文艺向 | 高饱和、荧光色、强渐变 |

**写法**：只写一个锚 + 两个可量化的限定。

```
✅ 赛璐璐上色，阴影为两段平涂、边界硬边，高光为形状而非渐变；线稿为干净的等粗细线。
❌ 精致的赛璐璐与柔和渐变结合的高级画风，电影级光影
```

第二句里，"精致""高级""电影级"三个词不指向任何画法，唯一确定的信息是"渐变"，
于是模型给了你一张糊边的赛璐璐——正好混搭。

## 三、七槽 + 两槽

动漫人物的提示词按这个顺序写，**槽位顺序影响权重**，越靠前越强：

| # | 槽 | 写什么 | 留空的后果 |
|---|---|---|---|
| ① | **身份** | 职业/角色 + 一句性格 | 变成"通用美少女" |
| ② | **年龄段** | 「16 岁」「24 岁」——影响比例大于影响脸 | 老少不分 |
| ③ | **头发** | 颜色 + 分组 + 端点 + 游离发 | 每次都换发型 |
| ④ | **眼睛** | 五层写法 | 眼神不稳 |
| ⑤ | **服装** | 一件标志性单品 > 一页时装清单 | 衣服平均化 |
| ⑥ | **姿势** | 她在干什么（重心、手、视线） | 军姿、僵硬 |
| ⑦ | **场景/光** | 一句背景 + 一句光 | 背景空或乱 |
| ⑧ | **画风锚** | 四选一 | 风格漂移 |
| ⑨ | **构图** | 画幅 + 占比 + 取景边界（见 `26-figure-layouts.md`） | 裁头裁脚 |

**留空任何一槽，模型都用它训练集里的平均值补。** 平均值就是"路人"。

## 四、三大翻车点

### ① 手

二次元的手比写实更难，因为线稿干净、错误藏不住。

- 写「手部结构正确、五指分明、指节朝向自然」
- 姿势上**尽量不要让手指张开**：握、扶、插兜、握拳，都比"五指张开"稳
- 手在画面外（插兜、背手、持物遮挡）是合法的简化手段

### ② 眼睛

两只眼睛大小不一致、水平不齐、高光位置不对称——一眼就废。

- 写「双眼等高、等大、高光位置对称」
- 侧脸时写「远侧眼被鼻梁遮挡约 1/3」，不写"两只眼睛都看得见"

### ③ 对称

耳环一只、领口歪、袖长不等。

- 先写「左右对称」再写「不对称设计点在〔左耳〕」——**先给对称基线，再给例外**
- 不写基线，模型会随机给你一处不对称

## 五、顺序：先全身，再特写

**这是效率问题。**

人物设计的成败在**剪影**（轮廓），剪影只有全身能看出来。
先出头像，等于在一个还没定下来的设计上做局部优化。

```
① fullbody 全身立绘 —— 定剪影、比例、配色
② 改到满意后，把这一段描述一字不改地复用
③ portrait 头像 / expression 表情集 —— 只改变量（表情、景别），不动角色锚
```

**一致性来自"复用同一段文字"，不是来自"跟刚才那个一样"。**
模型没有"刚才"。

## 六、动漫专属的排除项

中文否定词会被当关键词渲染（见 `15-video-prompts.md` 词根清洗），**这部分用英文写**，
放在提示词最后一段：

```text
no photorealistic skin texture, no visible pores, no 3d render gloss,
no extra fingers, no malformed hands, no six fingers,
no asymmetric eyes, no watermark, no signature, no text,
no oversaturated neon colors, no lens flare, no depth-of-field blur
```

**注意**：`no depth-of-field blur` 只在需要"平"的图式里加（三视图、表情集）。
主视觉要景深，加了这句会变全实焦。

## 七、三种二次元的分野

同样叫"动漫"，中日韩三套审美不能混。

| | 日系 | 国漫二次元 | 韩系 |
|---|---|---|---|
| 线稿 | 等粗细线，靠阴影分层 | 线略粗，轮廓强调 | 极细线，近无 |
| 上色 | 赛璐璐为主 | 赛璐璐 + 局部渐变 | 柔焦渐变为主 |
| 眼睛 | 大、虹膜分层复杂、高光多 | 中偏大、瞳色偏沉稳 | 细长、上眼睑重 |
| 脸型 | 圆润，下巴短 | 尖下巴，脸部纵向拉长 | 修长，颧骨略见 |
| 配色 | 高饱和、亮 | 中低饱和、青灰/赭石系 | 低饱和、粉灰/雾蓝系 |

**写「国漫二次元」是不够的**，要落到上表的具体项：「线略粗、轮廓强调、赛璐璐加局部渐变、
中低饱和青灰系」。否则模型默认给你日系。

## 八、动漫人物自检

- [ ] 风格锚只有一个？没有"结合""融合""混搭"这类词？
- [ ] 眼睛写了五层（眼型/虹膜/瞳孔/高光/下眼睑）？
- [ ] 头发写了组数 + 端点 + 游离发数？
- [ ] 鼻子和嘴是不是简化成了点/线/阴影？（写成"鼻梁挺直"就写实化了）
- [ ] 没写"皮肤纹理""毛孔""次表面散射"？
- [ ] 九槽填满了吗？填空的写「无」了吗？
- [ ] 手部写了结构正确？姿势避开了五指张开？
- [ ] 排除项用英文写的？
- [ ] 是"先全身后特写"的顺序吗？

第 1、2、3 题决定出来像不像二次元；第 5 题决定会不会变成半写实。
