# 人物资产：从设定到能出图的四格板

这一篇解决一件事：**怎么把一个人物写成一张能锁定形象的提示词。**

人物资产不是"画一张立绘"，是造一个**可复用的身份令牌**。后面几十个镜头都靠它锁脸。

---

## 一、先分三类：身份、变体、瞬态

动笔前，把「这个人物身上会变的东西」分进三个篮子。**分错篮子，资产会越建越多，最后互相打架。**

| 类别 | 包含什么 | 去哪 |
|---|---|---|
| **持续身份** | 脸型骨相、体态、永久特征（疤/痣/断眉）、固定配饰 | 人物条目 |
| **变体** | 服装、发型整理、妆容、伤势、湿污、年龄阶段、伪装 | 造型条目（`new_variant`） |
| **瞬态** | 瞬时表情、姿势、视线、景别、画面左右 | **归分镜，不进资产** |

### 变体 vs 状态变化的分界线

| 拆成新造型 | 只写状态变化 |
|---|---|
| 换整套服装 | 换一件外套 |
| 受伤后 / 受伤前 | 袖子卷起来 |
| 年龄跨度过大（少年/成年） | 头发被雨打湿 |
| 妆容剧变（伪装前后） | 摘了眼镜 |

**判据**：这个变化会不会持续一整个段落以上、且需要独立绑定参考图？两个都是「是」→ 新造型；否则 → 单镜状态变化。

### 什么该新建人物，什么不该

| 新建 `new_asset` | 归原人物造型变体 |
|---|---|
| 剧本确认是另一个人（含双胞胎、冒名者） | 易容、制服伪装、戴面具 |
| 需要独立引用、有独立台词的配角 | 背景群演（无台词、无跨镜连续） |

**命名约定**：主角用实名；功能人物用「姓氏+职务」；变体写在身份名后（「苏晚—火灾后」）。

## 一·补、从剧本自动提取角色

写完剧本，不要凭印象决定给谁建卡。跑一次：

```bash
python scripts/cd.py cast ./my-drama
```

它会做三件事：

1. **提取**：从听觉轨的 `名字（语气）：台词` 拿说话人，从画面轨拿**已登记**的人物名
2. **分级**：按出场强度判 A / B / C
3. **出稿**：对 A/B 级逐个生成四格板提示词骨架，锚点、年龄、性别、服装自动填进去

### 分级口径

| 级 | 判据 | 处理 |
|---|---|---|
| **A 主角** | 台词 ≥6 或 出场 ≥8 场 或 跨 3 集 | 必须建四格板 |
| **B 重要配角** | 台词 ≥2 或 出场 ≥3 场 | 建板，或共享主角锚点 |
| **C 龙套** | 其余 | **不建板**，文字描述即可 |

**为什么要分级**：四格板要花钱、占资产槽。给一闪而过的人做板，是双重浪费——钱花了，还把资产槽挤掉了真正需要的人。

### 缺什么要人补

自动填的是：锚点（逐字）、年龄、性别、服装（顺「本集造型」找到造型条目）。

**仍然留 `【】` 的三项**，因为它们不是结构化字段：

- **身份**（「沈家独女」「顾氏总裁」这类）
- **职业标识物三件套**
- **体型**（锚点里已含身形的，此行自动省略）

### 提不到的情况

剧本里出现一个新角色，**既没台词、也还没进视觉设定**——提不到。

这不是提取失败，是流程没走到位。先补 `## 人物 · X` 条目，再重跑。

**为什么不做人名猜测**：中文没有分词与词典，靠「X的」「X把手」这类模式猜出来的多是「白旧衬衫」「靠在桌后」这类噪声。误判比漏判更麻烦——漏了你会补，误判了你会照着错的清单去建卡。

## 二、先写三张卡（给人和给 AI 看的）

四格板解决"长得像"，但**像不等于活**。开画之前先写三张卡。

### 卡 1 · 身份卡：让人一秒代入

```
身份 + 缺陷 + 执念
```

| 项 | 作用 | 例 |
|---|---|---|
| **身份** | 负责代入 | 外卖员 / 实习律师 / 单亲妈妈 / 被裁的 35 岁程序员 |
| **缺陷** | 负责心疼 | 嘴笨、怕被拒绝、左手有疤、说话不敢看人 |
| **执念** | 负责让人想看下一集 | 一定要让女儿上那所学校 / 一定要把那句道歉说出口 |

**三个都有，角色就活了。** 只有身份没有缺陷，是工具人；只有缺陷没有执念，是可怜人；只有执念没有缺陷，是纸片超人。

### 卡 2 · 外形锁定卡：给 AI 看的，不是给人看的

这一栏必须**具体到能测量**，拒绝一切形容词。

| 项 | ❌ 形容词 | ✅ 可测量 |
|---|---|---|
| 发型 | 好看的短发 | 齐耳黑色短发，右侧别一枚银色发卡，发尾内扣 |
| 服装 | 酷酷的外套 | 酒红色短款机车外套 + 黑色高领内搭 + 银色细链项链 |
| 体型 | 身材好 | 身高 168，肩窄，站姿略含胸 |
| **标志物** | 有个道具 | 左手腕缠一圈旧绷带，永不取下 |

**标志物是性价比最高的设计。** 它让观众一眼认出角色，也让模型在多格里保持一致——
比任何"精致五官"都有效。

### 卡 3 · 行为卡：让角色会演戏

写**三个专属动作**：

```
紧张时摸项链 / 生气时不吼反而笑 / 走路永远靠右
```

**这些动作写进分镜提示词，比十句"她很焦虑"都管用。**

模型不认识"焦虑"，但认识"手指反复摩挲项链扣"。

### 三卡与四格板的关系

```
三卡（设计与判断）  →  四格板（视觉锁定）  →  分镜/关键帧（执行）
```

三卡不进图，只进 `视觉设定.md` 的人物条目。四格板才是给模型看的。

## 三、多格参考图：四视图只是其中一种

**先选图式，再写提示词。** 全部 11 种见 `26-figure-layouts.md`。

人物图不是一个模板。同一个角色，要"能当参考图"和"能发出去"是两套完全不同的写法，
版式选错，后面所有细节都是在错的地基上添墙。

| 你想要 | 图式代号 | 格数 | 画幅 |
|---|---|---|---|
| 只要体态、不要脸 | `three-view` 三视图 | 3 | 16:9 |
| 一张脸 + 三视（本 skill 默认人物资产） | `four-view` 四视图 | 4 | 16:9 |
| 头像 / 卡面 | `portrait` | 1 | 1:1 或 3:4 |
| 全身立绘（宣发、出图） | `fullbody` | 1 | 2:3 |
| 设定集海报 | `profile` 角色档案 | 5 区块 | 2:3 |
| 表情参考 / 表情包 | `expression` | 4 / 6 / 9 | 16:9 或 1:1 |
| 服装资产 | `outfit`（真源在 `06`） | 3 + 样片 | 16:9 |
| 打戏、演出参考 | `pose` | 4 | 16:9 |
| 封面 / 头图 / 预告首帧 | `kv` 主视觉 | 1 | 9:16 或 16:9 |
| 周边、表情包 | `chibi` | 1 或 4 | 1:1 |
| 片头、群像介绍 | `lineup` | 3–6 人 | 16:9 |

```bash
python scripts/cd.py figure ./my-drama --list                    # 看全部图式
python scripts/cd.py figure ./my-drama --char 苏衔 -l 三视图      # 按图式出提示词
python scripts/cd.py figure ./my-drama --char 苏衔 -l fullbody --out 人物资产/
```

### 四视图（原「四格板」）的规格

**一张人物资产图 = 四格，不多不少。**

```
① 面部特写（全图唯一清晰的脸）
② 正面全身（无脸）
③ 90° 侧面全身（无脸）
④ 背面全身（无脸）
```

### 为什么是四格

| 原因 | 说明 |
|---|---|
| **面部锚点唯一** | 一张图里出现多张清晰脸时，模型会把这些脸互相平均，脸型漂移。收成一格，像素预算集中，脸更准 |
| **三视给体态** | 正面/侧面/背面让模型知道这个人的体积与轮廓，不是只认识一张脸 |
| **只出四格** | 格数越多，每格越小，脸和细节越糊 |

### 三条硬纪律（适用于所有多格图式）

**① 不许"砍头"**

多格里的全身格**必须头部完整入画**，只是**面部不刻画五官**。

```
❌ headless / 头部不入画 / 自颈部截断 / 砍头
✅ featureless face, no facial features, smooth untextured facial plane
```

**为什么**：模型靠画面里的头锚定**头身比例**。头不入画，它就失去参照，出来头忽大忽小、头身比走形。

**② 格数写死，并堵住第 N+1 格**

```
❌ 一张大立绘，右侧附四格视图
✅ 全图共 4 格，横向并排：① 面部特写 ② 正面全身 ③ 90°侧面全身 ④ 背面全身
      仅此 4 格，不设独立大主图、不重复任何视角、不出现第 5 格
```

**为什么**：写成「主图 + 四格」，模型会按加法出成 5 格——正面被画两次。
三视图就写"全图共 3 格……不出现第 4 格"，表情集写"全图共 4 格……不出现第 5 格"。

机检 `A1` 查格数声明，`A15` 查"仅此 N 格"这句上限声明。**只有格数、没有上限，等于给模型留了加格的口子。**

**③ 除图底一行短标签外，零文字**

图上不标角色名、不标编号、不标"正面/侧面/背面"、不加水印 logo 边框。

**为什么**：每多一行字，模型要分配像素预算去"画字"，中文极易渲染成乱码，还容易被判成水印。

**唯一例外**：图底可以有一行 **≤8 词的英文音色速览标签**（见第四节）。声纹波形属图案，不占文字名额。

**⛔ 禁用词**：`mosaic / pixelated / 马赛克 / 打码` —— 模型会渲染出真实像素块和审查条纹理。要"无脸"就写"无脸"。

## 四、职业标识物：防"外卖员被画成协警"

**这是最容易漏、后果最尴尬的一条。**

写「28 岁的男外卖员」，模型不知道外卖员长什么样，就给你一个"城市里穿制服的公职人员"——粉丝实测被画成了协警。

**光有身份词不够。每个主要角色必须落三件套：**

| # | 项 | 写什么 | 正例（外卖骑手） | 反例 |
|---|---|---|---|---|
| ① | **职业标识物**（身上配饰，不算独立道具） | 至少 1 个一眼认出行当的硬标识 | 胸前橙色方形外卖箱（保温内胆外露）、平台工牌挂绳 | 无 |
| ② | **服装形制与材质** | 形制 + 材质 + 磨损 + 标志色 | 橙色骑手冲锋衣·尼龙面料·袖口磨白起毛·肩背双反光条掉漆 | 「穿制服」「穿工作服」 |
| ③ | **气质体态写进身体** | 长期职业塑造的身体习惯 | 常年骑车致含胸驼背、右肩偏低、手掌粗大、指节发红 | 无 |

### 还要写反漂移清单

正向描述禁不住漂移，必须同时给禁止项：

```
禁写成协警警服 / 公文包 / 对讲机 / 肩章
```

## 五、提示词结构

按这个顺序写（顺序影响权重）：

```
① 版式声明（图式 + 画幅 + 格数）+ 年龄区间 + 性别 + 身份
② 头身比（防头大身小）
③ 职业标识物三件套 + 反漂移清单
④ 脸型与轮廓
⑤ 五官特征
⑥ 发型
⑦ 服装（八字段，见下）
⑧ 配饰
⑨ 各格的姿态与构图（多格图：无脸、完整含鞋）
⑩ 背景
⑪ 图面纪律（零文字 + 排除项）
⑫ 风格分支（写实 / 3D / 2D 三选一）
```

### 年龄与体型必须具体

| ❌ | ✅ |
|---|---|
| 青年男子 | 28~32 岁男性 |
| 高大健壮 | 178cm·精瘦，肩窄腿长 |

「青年」「高大」不可复述，每次生成都不同。

### 服装八字段

每套造型的服装必须逐项写，无内容写「无」，不许留空：

| 字段 | 例 |
|---|---|
| ① 整体类型 | 交领右衽长袍，内搭中衣 |
| ② 颜色体系 | 主色灰青，辅色土黄，袖口深褐镶边 |
| ③ 面料材质 | 粗麻布，质地粗糙，多处磨损起毛 |
| ④ 纹样图案 | 素面无纹，仅领口有简单回纹镶边 |
| ⑤ 结构细节 | 交领右衽，宽袖口，腰间系粗麻绳腰带，衣摆及踝 |
| ⑥ 服装状态 | 多处补丁，肘部和膝盖磨破，衣摆沾泥渍 |
| ⑦ 鞋袜 | 黑色粗布鞋，鞋面磨损露白，无袜 |
| ⑧ 造型专属配饰 | 头顶破毡帽，颈间围脏灰布巾 |

### 五官十项（面部特写格专用）

脸型骨相 / 眉形 / 眼型眼窝 / 瞳色反光 / 鼻梁山根 / 唇形唇色 / 下颌线 / 耳廓 / 标志性特征 / 面部肌肉与肤色

末尾用「28~32岁男性（身份代称）」收尾，锁定性别与年龄。

## 六、音色：完整版不进图，短标签进图

配音和形象是同一个角色的两个面，但**它们的信息量不该都塞进图里**。

| 项 | 内容 | 去哪 |
|---|---|---|
| **完整 Voice Description** | 英文 2–4 句：音高/质感/语速/情绪层次 | **纯文本交付**，给配音和 TTS 用 |
| **音色速览标签** | ≤8 个英文词 | **渲染在图底**，全图唯一文字 |
| **声纹波形** | 频谱/波形图案 | 图底，非文字，做跨图匹配用 |

**为什么缩短**：生图模型渲染上百字符的长英文会崩字、缺字、变形，还会被当成字幕水印。缩到 8 词以内，崩字率大幅下降；波形抗模糊，两者互补。

### 写法

```markdown
**Voice Description（不进图）:** A low, gravelly female voice, slow and deliberate,
each word pushed out from the throat. Cold and controlled on the surface, drops to a
cutting edge when threatened. Ideal for anime dubbing or short drama.

**音色速览标签（进图 · ≤8 词）:** low, gravelly, slow, cold-edged voice
```

## 七、换装：锁脸改衣

同一人物多套造型时，**第二套起用换装模板，不要从零重写**。

核心指令一句话：**保持脸型、五官、肤色、年龄感完全一致，只改服装。**

```markdown
【人物锁定（不可变更）】
- 脸型与轮廓：与图1 中沈惊歌完全一致（逐字复用第一套描述）
- 五官特征：与图1 完全一致（逐字复用）
- 肤色与肤质：与图1 完全一致，年龄感不变
- 发型：（不变则写一致；变化则写新发型，但发色发质不变）
- 音色：与图1 一致（音色跟人物，不随服装变）

【服装提示词】
① 整体类型：…… ② 颜色体系：…… ③ 面料：…… ④ 纹样：……
⑤ 结构细节：…… ⑥ 状态：…… ⑦ 鞋袜：…… ⑧ 专属配饰：……

【其余同第一套】四格版式、零文字纪律、风格分支
```

**换装造型不重复写音色、不重复渲染标签**——同一角色同一条声纹波形。

## 八、表情与动作板：见专项篇

**默认不做。** 表情和动作是**镜头瞬态**，归分镜和关键帧。

只有两种情况值得做板：角色有 5 个以上镜头需要**同一种极端状态**，或有标志性武打/施法动作。

做法（十二表情宫格、十五动作格、强度梯度、物理规律）见 `07-expression-and-pose.md`。

## 八·补、人物比例铁律：防「幼态化」

这是人物板最容易漏、也最破坏一致性的一条。

### 症状

同一个 27 岁的成年角色，四格板出来像 16 岁。或者九宫格里某几格头变大、脸变圆、眼睛变大——**幼态化**。

**为什么会这样**：模型的训练数据里，动漫/插画的「人脸平均值」偏年轻。它不知道你要成年人。而且**小格子会加重这个偏差**——格内像素越少，模型越倾向于用「通用可爱脸」去填。

### 修法：三件套一起上

```
【人物比例铁律】人物为 27 岁成年女性，成年身材比例约 6.5 头身，肩宽腿长符合成年人。
严禁儿童幼态、娃娃脸、Q 版、大头娃娃、头身比失调；
严禁把头部裁切出画（每格人物头部完整在画面内）。
五官端正、左右对称、不变形、不糊；
发型选符合该年龄的成熟款式（高马尾优先，不用丸子头等显幼款）。
```

三条缺一不可：

| 项 | 写什么 | 只写这个会怎样 |
|---|---|---|
| **具体年龄 + 头身比** | 「27 岁，约 6.5 头身」 | 只写「成年」无效，模型不认这个词 |
| **显式禁幼态** | 列出「幼态/娃娃脸/Q 版/大头娃娃」 | 不写就默认往年轻走 |
| **发型承担年龄感** | 「高马尾，不用丸子头」 | 发型比脸更能定年龄，丸子头一出就幼 |

### 还有一个参数层的原因

**格内像素不足**。九宫格九格分一张图，每格分辨率低，脸必糊、必变形。这时改提示词没用，要**提高出图分辨率**（2K 提 4K）。

**提示词管形状，分辨率管清晰。** 两件事都要做。

### 顺带一条：全身格必须完整

「头顶至鞋完整入画」不只是为了看鞋。**头被裁掉，模型就失去头身比参照**，同一批图里的头会忽大忽小。

所以：**允许去五官，不允许裁头。**

## 九、常见崩坏与修法

| 症状 | 病根 | 修法 |
|---|---|---|
| 出了 5 格，正面画两次 | 提示词写了「主图」+「四格」 | 改成「全图共 4 格，不设独立大主图」 |
| 头忽大忽小 | 三格全身砍了头 | 改成「无脸」：头保留、只去五官 |
| 全身格没有鞋 | 只写到膝盖，或指望特写格补 | 写「头顶至鞋完整入画，含鞋袜，不裁脚」 |
| 外卖员被画成协警 | 只有身份词，没有职业标识物 | 补三件套 + 反漂移清单 |
| 图上全是乱码 | 写了要标注角色名/视角名 | 删掉所有文字要求，只留图底短标签 |
| 脸上有像素块 | 写了「马赛克」 | 改成「无脸（无面部细节）」 |
| 换装后换了个人 | 从零重写提示词 | 用换装模板，锁脸改衣 |
| 三格全身风格不一致 | 没写「同一人、同一时刻、同一造型」 | 补这句 |

## 十、人物资产自检

- [ ] 分清了身份 / 变体 / 瞬态，瞬态没进资产？
- [ ] 每个角色有条目，锚点 30–60 字全是可画事实？
- [ ] 提示词写了「全图共 4 格」？
- [ ] 三格全身写的是「无脸」不是「砍头」？
- [ ] 写了「头顶至鞋完整入画，含鞋袜」？
- [ ] 主要角色有职业标识物三件套 + 反漂移清单？
- [ ] 年龄写的是区间，体型写的是数字或明确词？
- [ ] 服装八字段都填了，没留空？
- [ ] 脸型五官在面部特写格写全了十项？
- [ ] 图面纪律写了零文字，且没写"马赛克"？
- [ ] 图底有 ≤8 词音色标签 + 声纹波形？
- [ ] 换装用了模板，没从零重写？

第 2、4、6 题最容易错。
