# 出稿前检查清单

按阶段打勾。每条后面标了级别：`结构` = 违反阻断，`受审` = 违反阻断，`默认` = 可偏离但须说明，`风格` = 随意。

---

## P0 锁

- [ ] 制作形态已定，画风词根能落成一句话 `结构`
- [ ] 画幅已定（9:16 / 16:9），全片一致 `结构`
- [ ] 目标视频模型已定，语法契约已知 `结构`
- [ ] 目标模型**在服役**（Sora 2 已于 2026-09-24 停服）`结构`
- [ ] `duration_cap_sec` 等于该模型的单段上限 `结构`
- [ ] 素材形态已定（M0 / M1 / M2）`结构`
- [ ] 单集目标时长有依据（不是拍脑袋）`默认`
- [ ] 备案档位已定（按投资额）`结构`
- [ ] 题材红线自检已过 `结构`

### 模型与资产分派（见 `22-model-matrix.md`）

- [ ] 每镜参考图数不超该模型的参考上限 `结构`
- [ ] 人物板 / 场景板 / 表情板 → Nano Banana Pro（一致性最强）`默认`
- [ ] 道具板 / 武器板 / 封面 → GPT Image 2（中文标签与标题最准）`默认`
- [ ] 留了 fallback 模型，防主力限额或涨价 `默认`
- [ ] 试运动用最便宜档，锁定提示词后才上分辨率 `默认`

## P1 故事

- [ ] 核心戏剧动作能用一句话说出「谁想要什么、谁在阻止」`结构`
- [ ] 主角的 Want 与 Need 分别是……且冲突 `默认`
- [ ] 每集的一句话弧光写得出来 `默认`
- [ ] 反庸俗三题答得出来（套路禁区 / 不可推导细节 / 观众手里能拿着什么）`默认`
- [ ] 反派有主动意志（不是命运/系统/家族安排）`默认`

## P1·改 小说改编（有原著才走）

- [ ] 四问快评过了（爽点密度 / 可视性 / 人物立场 / 单集承载）？
- [ ] 每章都提取了情节点，白描去心理化？
- [ ] 载体记录写了「靠什么传达」，心理叙述的段标了 `needs_carrier`？
- [ ] 信息密度章没被当成水章砍掉？
- [ ] 爽点表列出来了，集数跟着爽点走，不按章节 1:1 切？
- [ ] 第 1 集用了哪个入口（时序/收益/冷开）？冷开有时间定位？
- [ ] 改编契约四类都写了，不可改承诺没动？`受审`
- [ ] 先删线后合并人，五项/六项核对过了？
- [ ] 删线时孤儿铺垫清理了？
- [ ] 心理描写都走了五级阶梯，没改成「倒水/看窗外/攥拳头」这类假忙活？`受审`
- [ ] 因果桥每环都接上了（原因→理解→选择→反制→后果→新压力）？
- [ ] 重排的都登记了，原位置处理了（没原样再演一遍）？
- [ ] 每场都有目标/阻碍/结果/进集理由？

- [ ] 语气位与画面动作一致 `默认`
- [ ] 主要角色的说话方式能区分开 `默认`
- [ ] 删掉所有台词，画面轨还能讲清故事 `默认`
- [ ] 折算时长与目标偏差 ≤ 15% `默认`

## P3 视觉设定

- [ ] 全季一份，不是每集一份 `结构`

- [ ] 每个出场人物有条目，锚点 30–60 字 `结构`
- [ ] 条目写了资产编号（图N），且全项目不重复 `结构`
- [ ] 锚点全是可画的物理事实，没有「精致」「气质」`受审`
- [ ] 造型变化拆成了新造型条目（不是塞进状态变化）`默认`
- [ ] 地点与视图分开了（停电/换时段没拆成两个地点）`受审`
- [ ] 独立地理、独立入口的空间分建了地点并注明连接 `默认`
- [ ] 方位用锚点相对关系写，没写裸的「左侧」`受审`
- [ ] 人会靠坐的固定物写了高度 `默认`
- [ ] 每个地点有空间锚点与光线变体 `结构`
- [ ] 关键道具建了条目，普通陈设没乱建 `默认`
- [ ] 会变的写进状态变化，不会变的上了锁 `默认`
- [ ] 锁面是短名词短语，且写清了镜头范围 `结构`
- [ ] 非中文提示词的人物都有非中文代称 `受审`
- [ ] 古装/年代戏有时代锚点，且写了「光线来源」`默认`

## P4 资产生产

### 总美术基准（先定这个）

- [ ] 九项基准都定了（时代/地域/气候/阶层/技术/文化/主色/材质/旧化）`结构`
- [ ] 基准具体到材质级（「深色实木+真丝+黄铜」，不是「现代都市」）`受审`
- [ ] 共享锚点写了（同阵营纹样 / 同阶层材质 / 同时代光）`默认`
- [ ] 每个条目有资产编号，且全项目不重复 `结构`
- [ ] 四类资产用了固定出图参数 `默认`

### 人物建卡（先跑 cast）

- [ ] 跑过 `cast`，角色表覆盖了剧本里所有有台词的人 `结构`
- [ ] A 级角色都已登记视觉设定、都有四格板 `结构`
- [ ] C 级龙套**没有**建板（省下的槽给需要的人）`默认`
- [ ] 自动填的锚点/年龄/性别/服装已人工核对过一遍 `结构`
- [ ] `【身份】` 与 `【职业标识物】` 已补（这两项自动填不出来）`受审`

### 人物四格板

- [ ] 写了「全图共 4 格」，没有正向的「主图/大主图」`结构`
- [ ] 三格全身写的是「无脸」不是「砍头」`受审`
- [ ] 写了「头顶至鞋完整入画，含鞋袜」`受审`
- [ ] 主要角色有职业标识物三件套 + 反漂移清单 `受审`
- [ ] 年龄写的是区间，体型写的是数字或明确词 `默认`
- [ ] 服装八字段都填了，没留空 `默认`
- [ ] 面部特写格写了五官十项 `默认`
- [ ] 图面纪律写了零文字，且没写「马赛克」`受审`
- [ ] 图底有 ≤8 词音色标签 + 声纹波形 `默认`
- [ ] 换装用了模板，没从零重写 `默认`

### 服装设定板

- [ ] 是拆解参考图，不是重新设计 `受审`
- [ ] 参考图没有的部件都写了「无此结构」`受审`
- [ ] 八字段都填了（类型/颜色/面料/纹样/结构/状态/鞋袜/配饰）`默认`
- [ ] 下装只拆实际存在的类型，没额外设计 `默认`
- [ ] 纹样/刺绣/面料/缝线/工艺都拆了，不确定的标「待确认」`默认`
- [ ] 颜色用中文名+明度饱和，没用十六进制 `默认`
- [ ] 三视图等高、脚底对齐、侧面不是压扁的 `受审`
- [ ] 全季有服装演进表，每套标了适用区间与变化原因 `受审`
- [ ] 换装锁了脸与比例，只改衣服配饰 `受审`
- [ ] 配饰的去向写清楚了 `默认`

### 表情与动作板（需要时才做）

- [ ] 确实有 5 个以上镜头需要同一极端状态，或有标志性动作 `默认`
- [ ] 表情板正好 12 格，动作板正好 15 格 `结构`
- [ ] 十二格是同一人同一时刻，光线完全一致 `受审`
- [ ] **强度梯度写了**（微笑<开心<大笑）`受审`
- [ ] 恐惧有「眉内侧靠拢+下眼睑绷紧」，不是只有睁大眼 `默认`
- [ ] 悲伤没有靠眼泪表达 `默认`
- [ ] 没有用手势/换装/换妆表达情绪 `受审`
- [ ] 动作每格头顶到鞋底完整，基线一致 `结构`
- [ ] 每个动作标了重心与支撑面 `默认`
- [ ] 有惯性余势与反向配重 `默认`
- [ ] 写了服装滞后（衣摆发丝慢半拍）`默认`
- [ ] 「攻击」格没有命中与伤口，「防御」格没有对手 `受审`

### 场景母版 + 九宫格

- [ ] 先出了母版，九宫格从母版派生 `默认`
- [ ] 九宫格写了「全图共 9 格，不多不少」`结构`
- [ ] 选了模式 A 还是 B，锁定段与之匹配 `受审`
- [ ] 机位名与空间类型吻合，没硬凑 `受审`
- [ ] 同地点同状态的所有视角，主光/色温/光比/灯具状态一致 `受审`
- [ ] 场景图里没有人物 `默认`
- [ ] 标注写了降级方案（数字 + 对照表）`默认`
- [ ] 整板写了 16:9，内部 3×3 另定 `默认`
- [ ] 跨集延续用了「逐字复用 + 参考图锁定」`默认`
- [ ] 一条提示词能单独投喂（没有「同上/见母版」）`结构`

### 道具四格板

- [ ] 只给「承担叙事 / 跨镜出现 / 有状态变化」的道具建了条目 `默认`
- [ ] 尺寸写了参照物（手掌/身高）`默认`

- [ ] 反光道具**没有**任何光效描写 `受审`
- [ ] 同款多件分建了条目，或归了布景 `默认`
- [ ] 排除项里有「禁止手持/禁止人手」`默认`

### 武器板

- [ ] 只给战斗角色建武器条目 `默认`
- [ ] 给了三重长度参照（绝对/人体/攻击半径）`受审`
