# 场景九宫格模板

复制整段，替换 `〔〕`。**八字段缺一即不合规**，锁定段按模式选，不要混用。

---

## 第一步：定两件事

| 项 | 选 |
|---|---|
| **内容分配模式** | `A 单场景多机位` / `B 多子区域` |
| **空间类型**（决定用哪张机位矩阵表） | `室外独立建筑` / `室内半封闭` / `自然场地街巷` |
| **锁参考图** | `关`（首次出现）/ `开`（跨集延续，须传上集图） |

---

## 第二步：八字段模板

```text
只生成一张整板固定 16:9 横版的图，内部布局为 3×3 九宫格（全图共 9 格，不多不少，
不得出现第 10 格、不得拆成多张散图）。九宫格内所有格子共享同一套建筑与场景资产，
元素保持完全一致，同一建筑连续摄影。

【场景定位】
- 场景名称：〔顾氏总裁办〕（资产图编号：图〔3〕）
- 时代/地域：〔现代都市〕
- 建筑类型：〔写字楼顶层办公空间〕
- 建筑风格：〔现代商务，深色实木 + 落地玻璃，克制无装饰〕
- 空间类型：〔室内半封闭空间〕
- 子区域清单：〔主办公区〕、〔会客区〕
- 时间段/天气：〔夜间，晴，无风〕

【场景画面描写】（完整画面语言，禁止纯名词罗列）
- 整体画面：〔夜间办公层，落地窗外是城市灯带，室内只开一盏黄铜台灯，
  暖黄光在深色实木桌面上铺开，周围沉入暗部，安静而冷硬〕
- 〔主办公区〕：〔南向落地窗在画面右，深色实木长桌居中，桌后高背皮椅，
  左侧一排低矮书架，北墙偏左一扇门。桌面有台灯、水晶烟灰缸、文件托盘〕
- 〔会客区〕：〔靠窗一组深色皮质沙发，中间矮几，几上一只空杯。
  地面为哑光深色木地板，无地毯〕

【九宫格内容分配】〔模式 A 单场景多机位：9 格为同一场景的 9 个不同机位，不拆分区域〕

【参考场景锁定模式】〔模式 A 档 · 仅允许摄影机移动〕
完全相同的建筑设计，完全相同的建筑结构，完全相同的建筑比例，完全相同的场地规划，
完全相同的空间布局，完全相同的景观系统，完全相同的道路系统，完全相同的背景环境，
完全相同的装饰细节，完全相同的材质表现，完全相同的色彩体系，完全相同的光照方向，
完全相同的阴影方向，完全相同的体积光效果，完全相同的天气状态，完全相同的时间段，
完全相同的光线亮度与曝光水平。
建筑锁定，环境锁定，材质锁定，灯光锁定，场景锁定。
禁止重新设计建筑，禁止改变建筑结构，禁止改变建筑比例，禁止增加建筑，禁止删除建筑，
禁止改变环境布局，禁止改变背景元素，禁止改变景观系统。
仅允许摄影机移动。

【九宫格摄影机矩阵】（室内半封闭空间 · 表②）
一左：进门视角——人眼高度从门向内看，交代整体空间与第一印象
一中：主活动区全景——空间内面积最大、事件最密的区域
一右：窗侧光位——靠窗一侧，交代自然光源落点与窗边陈设
二左：门框反打——从空间内部回看入口，交代出入口位置与纵深
二中：俯视平面——高位俯拍，交代家具布局、动线与地面关系
二右：对角长焦压缩——从一角向对角长焦压缩，交代纵深与空间层次
三左：陈设特写——标志性家具/器物特写（带材质与使用状态）
三中：墙侧细节——墙面/挂饰/破损/痕迹，交代年代感与空间状态
三右：窗外或顶光空镜——窗景或顶部结构，交代时令与封闭/通透感

【摄影机参数】
统一焦段 50mm；统一曝光（曝光充足、不欠曝）；统一白平衡；统一动态范围；
统一景深；统一色彩风格；统一构图逻辑。

【光照与曝光控制】
〔主光：仅桌面黄铜台灯，暖黄，位于桌面右侧；辅光：窗外城市冷蓝；
冷暖在长桌上分界，光比约 1:5；暗部保留细节，不出现死黑〕
禁止暗调（除本提示词已显式声明）、禁止大面积死黑与死白。

【画面标注要求】
每个格子内用文字标注对应的机位名，名称与资产图编号完全一致。

标注降级条款：若中文标注渲染失败——乱码 / 缺字 / 文字截断 / 糊成一团，
不得无标注裸格交付，改走降级路径：
1. 格内只保留小尺寸阿拉伯数字编号（1~9）；
2. 随交付附一份《编号—机位对照表》；
3. 重试上限 2 次；2 次仍失败即按降级路径交付并写明「已降级」；
4. 降级版仍须保留 9 格结构。

【画面纯净要求】
本图是纯场景资产图：九宫格各格画面中禁止出现任何人物、人影、人体部位或动物。

【风格分支】〔国漫二次元：清晰轮廓线、平整色块、硬边阴影 / 
UE5 次世代 CG：PBR 材质、体积光、自然景深 / 写实摄影：真实材质纹理、克制颗粒〕
```

## 第三步：跨集延续时追加

```text
【延续拍摄声明】
- 本场景为第〔3〕集「〔顾氏总裁办〕」的延续拍摄；
- 建筑结构、家具位置、地面材质、门窗、陈设、杂物全部与第〔3〕集完全一致；
- 材质表现、色彩体系、光照方向、阴影方向、天气状态、时间段、亮度全部不变；
- 禁止新增、删除、移动任何场景元素，禁止重新设计建筑；
- 仅允许摄影机移动。

【参考图锁定（必须执行）】
- 生图时必须传入第〔3〕集该场景已生成的图作为参考图（图生图模式）；
- 参考图强度：0.7–0.85；
- 参考图中的所有元素必须 100% 保留，禁止 AI 自行优化、美化、替换。
```

**场景定位与画面描写逐字复用首次出现集的文字**，只改时段/天气（并写明变化原因）。

## 三张机位矩阵速查

### 表① 室外独立建筑

正面全景 / 正面近景 / 侧面全景 / 侧面近景 / 背面全景 / 背面近景 / 俯视全景 / 俯视近景 / 环境交代景

### 表② 室内半封闭

进门视角 / 主活动区全景 / 窗侧光位 / 门框反打 / 俯视平面 / 对角长焦压缩 / 陈设特写 / 墙侧细节 / 窗外顶光空镜

### 表③ 自然场地街巷

入口全景 / 主场地全景 / 反向全场 / 侧向全景 / 低位贴地 / 高位俯瞰 / 地貌细节 / 通道窄口 / 天际环境空镜

**机位名与空间类型不符就是违规。** 室内不许写「背面全景/高空鸟瞰」，自然场地不许写「正面近景/立面细节」。
