# 人物四格板模板（四视图）

复制整段，替换 `〔〕` 与 `<>`。**四格版式与三条硬纪律不要改**——那是踩过坑的。

> 这只是 11 种人物图式里的**四视图**。
> 要三视图 / 立绘 / 头像 / 角色档案 / 表情集 / 姿态集 / 主视觉 / Q 版 / 阵容图，
> 看 `references/26-figure-layouts.md`，或直接生成：
>
> ```bash
> python scripts/cd.py figure ./my-drama --list
> python scripts/cd.py figure ./my-drama --char 〔角色名〕 -l three-view
> ```

## 〔角色名〕角色设定板（〔造型名〕）

### 立绘提示词

```text
一位约〔28~32〕岁的〔性别/身份〕站立立绘，真人〔6.5~7.5〕头身。
全图共 4 格，横向并排：① 面部特写　② 正面全身　③ 90°侧面全身　④ 背面全身。
仅此 4 格，不设独立大主图、不重复任何视角、不出现第 5 格。

【职业标识物】（身上配饰，不算独立道具）
- ① 硬标识：〔胸前橙色方形外卖箱，保温内胆外露；平台工牌挂绳〕
- ② 服装形制与材质：〔橙色骑手冲锋衣·尼龙面料·袖口磨白起毛·肩背双反光条掉漆〕
- ③ 气质体态写进身体：〔常年骑车致含胸驼背、右肩偏低、手掌粗大、指节发红〕
- ⛔ 反漂移：〔禁写成协警警服 / 公文包 / 对讲机 / 肩章〕

【第①格 · 面部特写】（全图唯一清晰的脸，头部占该格高度 ≥70%）
脸型与轮廓：〔鹅蛋脸，下颌线柔和，颧骨略高〕
五官：〔眼尾上挑 / 眉形细长微挑 / 瞳色深棕 / 鼻梁窄直 / 唇薄色淡 / 耳廓小 / 左眉尾一道浅疤〕
皮肤质感情：〔哑光自然，鼻翼与两颊可见细小毛孔，太阳穴有细软汗毛〕
收尾：〔28~32 岁女性（Shen Jingge）〕

【第②③④格 · 无脸全身】
三格均为同一人的正面 / 90°侧面 / 背面，端正站立（no pose），身体直立，
头部完整入画但面部不刻画任何五官（featureless face, no facial features,
smooth untextured facial plane）；头顶至鞋全部入画（含鞋袜，不裁脚、不裁头、
不截断、不露底），各格人物占该格高度 85%~95%。双手自然垂放身体两侧。
禁止坐姿 / 蹲姿 / 行走 / 任何动作姿态；禁止手持道具、禁止身前身侧放置道具。

【服装】〔八字段见下〕
【配饰】〔腰间素圈已褪色 / 左耳一枚小银钉〕

背景：纯白无接缝。

【图面纪律】画面上不得出现任何文字——不标角色名、不标编号、不标"正面/侧面/背面"、
不标脸部处理、不加边框文字/水印/logo/角标/UI。整张图只有图案。
唯一例外：图底部一行英文音色速览标签（≤8 词），文字清晰正确、无乱码缺字变形。
（图底另有一条声纹波形/频谱可视化细节条，属图案不属文字，不占用文字名额。）

【风格分支】〔国漫二次元：清晰轮廓线、平整色块、层数克制的硬边阴影 / 
UE5 次世代 CG：PBR 材质、次表面散射、体积光 / 写实摄影：自然毛孔绒毛、克制高光〕
```

```text

【人物锁定（不可变更）】
- 脸型与轮廓：与图1 中〔角色名〕完全一致（〔逐字复用第一套描述〕）
```

## 交付前七问

1. 提示词里写的是「全图共 4 格」吗？有没有出现正向的「主图/大主图」？
2. 数一数：全图是不是正好 4 格？
3. 全图有几处清晰可辨的五官？>1 就 FAIL。
4. 有没有哪一格把头裁掉、抹掉、推出画框？有就 FAIL。
5. 图上除图底短标签外，还有其他文字吗？
6. 三格全身到鞋了吗？
7. 图底有声纹波形 + ≤8 词英文标签吗？

## 常见错误

| 写完发现 | 病根 | 改法 |
|---|---|---|
| 出成 5 格 | 写了「主图」+「四格」 | 改成「全图共 4 格，不设独立大主图」 |
| 头忽大忽小 | 砍了头 | 改成「无脸」：头保留、只去五官 |
| 没有鞋 | 只写到膝盖 | 写「头顶至鞋完整入画，含鞋袜，不裁脚」 |
| 画成协警 | 只有身份词 | 补职业标识物三件套 + 反漂移 |
| 满图乱码 | 要求标注角色名/视角名 | 删掉所有文字要求 |
| 脸上有像素块 | 写了「马赛克」 | 改成「无脸（无面部细节）」 |
