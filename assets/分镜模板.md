## 字段填写要点

| 字段 | 常见错误 | 正确做法 |
|---|---|---|
| 职责 | 「展示她很生气」 | 「让观众看见她在忍，且忍得很辛苦」 |
| 起点 | 「她准备掐手心」 | 「五指张开放平，掌心朝上」 |
| 唯一动作 | 「掐手、咬牙、流泪、转身」 | 「五指收拢，指甲压进掌心」 |
| 终点 | 「她离开了」 | 「五指仍扣着，血线停在掌纹里」 |
| 运镜 | 「缓慢推镜」（无理由） | 「极缓推近；把观众推到那道血线上」 |
| 视觉依据 | 写了但条目不存在 | 逐字对上视觉设定的标题 |
| 关键帧 | 写了动作过程 | 只写这一瞬间能看见的东西 |

## 快速自检

- [ ] 每镜有「起点 → 唯一动作 → 终点」三行
- [ ] 唯一动作真的只有一件
- [ ] 每次切镜带来信息/权力/情绪/空间/节奏的变化
- [ ] 镜长由声音事件倒推，台词镜有余量
- [ ] 关键帧只写起点，氛围六件套至少三件
- [ ] 视觉依据逐字对上视觉设定
