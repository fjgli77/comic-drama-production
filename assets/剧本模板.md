# 剧本模板

复制整段，替换 `〔〕`。**语法不要改**——机检靠 `## EP001-SC001` 和全角冒号定位。

---

```markdown
# EP001 〔集名〕

## EP001-SC001 〔内/外〕 · 〔地点〕 · 〔日/夜〕

### 画面轨
- 〔只写摄影机拍得到的东西。禁心理描写、禁括号暗示、禁比喻。〕
- 〔一条一个可见事实：谁在做什么、什么东西是什么状态。〕
- 〔三到五条，覆盖这一场的视觉信息。〕

### 听觉轨
- 〔角色名〕（〔语气位：音量/速度/质地/态度〕）：〔台词，≤15 字〕
- [SFX] 〔音效，写具体：什么物件发出什么声音〕
- [BGM] 〔音乐，写性格不写曲名；无则省略〕
```

---

## 填写要点

### 场次标题

```
## EP001-SC001 内 · 顾氏总裁办 · 夜
```

| 部分 | 规则 |
|---|---|
| `EP001-SC001` | 集号 + 场号。**全局唯一，定下不改** |
| `内/外/内外` | 空间性质。三选一，不能写别的 |
| 地点 | 必须与 `视觉设定.md` 的「地点」条目名一致 |
| 日/夜/黄昏/清晨 | 时间。影响光照变体 |

### 画面轨

**三到五条，每条一个可见事实。**

| ❌ | ✅ |
|---|---|
| 她心里很乱 | 她把杯子放下，又拿起来，又放下 |
| 气氛很压抑 | 对面五个人同时低下头 |
| 他们吵了起来 | 他把文件摔在桌上，纸散了一地 |

**判断法**：这句话能被摄影机拍到吗？拍不到就删。

### 听觉轨

**台词必须有语气位。** 括号里至少给两层：生理状态 + 表达策略。

```
沈惊歌（声音微颤，字字清晰）：这是沈家最后的东西了。
```

- 生理：声音微颤
- 策略：字字清晰

**只写一层不够**：「愤怒地说」——配音只能猜。

### 特殊标记

| 标记 | 用于 | 例 |
|---|---|---|
| `[VO]` | 内心独白、旁白 | `[VO] 沈惊歌（很轻）：原来是这样。` |
| `[OS]` | 画外但对世界内发声 | `[OS] 顾城（从门外）：开门。` |
| `[SFX]` | 音效 | `[SFX] 玻璃碎裂，碎片落地` |
| `[BGM]` | 音乐 | `[BGM] 低频持续音，无旋律` |
| `[画面文字]` | 手机屏、招牌、文件上的可读字 | `[画面文字] 清算完毕` |
| `[转场]` | 场末转场方式 | `[转场] 切` |

## 完整示例

```markdown
# EP001 清算日

## EP001-SC001 内 · 顾氏总裁办 · 夜

### 画面轨
- 一只女人的手从无名指上褪下一枚素圈，动作很慢，指腹在戒面上停了一瞬。
- 素圈被放在深色实木桌面中央，推向对面，停下。
- 沈惊歌坐在长桌外侧，灰白旧衬衫的右袖口有一处勾丝，视线落在桌面上。

### 听觉轨
- [SFX] 金属圆环刮过木面的细响，很长
- 沈惊歌（很平，像在报数）：先算这个。

## EP001-SC002 内 · 顾氏总裁办 · 连续

### 画面轨
- 一叠白纸被推到桌面中央，首页印着猩红的「清算完毕」钢印，纸边卷起泛黄。
- 沈惊歌的手还按在纸叠边缘，五指张开，指节泛白。
- 桌上一盏黄铜台灯，光从右侧斜切过来，把她的手切成明暗两半。

### 听觉轨
- 沈惊歌（声音微颤，字字清晰）：这是沈家最后的东西了。
- [BGM] 大提琴独奏，音量很低
```
