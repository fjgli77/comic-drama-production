# 视觉设定模板

复制整段，替换 `〔〕`。**全季一份，不要每集复制。**

---

## 文件开头

```markdown
# 视觉设定 · 〔剧名〕

> 全季共用一份。不要每集复制。
> 造型变化用「适用区间」表达，不新建文件。
```

---

## 人物条目

```markdown
## 人物 · 〔角色名〕

- 资产编号：图〔1〕
- 识别锚点：〔24岁东亚女性，鹅蛋脸，眼尾上挑，左眉尾一道浅疤，锁骨下方一颗小痣，身形偏瘦。〕
- 画面代称：〔Name、角色名〕
- 声音：〔烟熏嗓，语速偏慢，句尾下沉，每个字都咬得极重。〕
- 本集造型：见「造型 · 〔角色名〕-〔造型名〕」
- 状态变化：〔EP001-SC003 后右手掌心有指甲掐出的血痕。无则写「无」。〕
- 连续性锁：LOCK-〔SHEN-SCAR〕《〔左眉尾浅疤〕》（镜头：〔入画〕）
```

### 填写规则

| 字段 | 规则 |
|---|---|
| **资产编号** | `图N`，全项目唯一，**定下不改**。不写会由顺序推导，新增条目时旧图号全部漂移 |
| **识别锚点** | 30–60 字，**全是可画的物理事实**。禁「精致」「气质」「高级感」 |
| **画面代称** | 非中文提示词时**必须**给英文代称，否则模型不认识中文名 |
| **声音** | 写质地，不写组合词。禁「温柔的女声」 |
| **状态变化** | 写清「哪场之后」+「变成什么」 |
| **连续性锁** | 锁面是最小名词短语，不含标点、动作、剧情 |

## 造型条目

```markdown
## 造型 · 〔沈惊歌〕-〔破产日〕

- 身份：〔沈惊歌〕
- 适用：〔EP001-SC001 至 EP001-SC005〕
- 锁定：〔灰白色旧真丝衬衫，右袖口一处勾丝；黑色直筒西裤；裸色平底鞋。〕
- 配饰：〔左手无名指一枚素圈，已褪色。〕
```

### 拆造型 vs 写状态

| 拆新造型 | 只写状态变化 |
|---|---|
| 换整套服装 | 换一件外套 |
| 受伤后 / 受伤前 | 袖子卷起来 |
| 年龄跨度过大 | 头发被雨打湿 |
| 妆容剧变（伪装前后） | 摘了眼镜 |

**判据**：跨多场持续且需独立参考图 → 新造型；只维持半场几镜 → 状态变化。

## 地点条目

```markdown
## 地点 · 〔顾氏总裁办〕

- 空间锚点：〔南向落地窗在画面东；深色实木长桌居中，桌后一把高背皮椅；
  左侧一排低矮书架；门在北墙偏左。长桌高约 75 厘米，桌面齐成年人髋。〕
- 固定陈设：〔桌上一盏黄铜台灯、一个水晶烟灰缸、一叠文件托盘。〕
- 光线变体：
  - 夜景（主）：〔仅台灯与窗外城市灯，暖黄主光来自桌面右侧，人物左脸留暗，光比约 1:5。〕
  - 日景：〔落地窗自然光为主，逆光，人物成半剪影。〕
- 连续性锁：LOCK-〔OFFICE-DESK〕《〔深色实木长桌〕》（镜头：〔SPECIFIC_SHOTS〕）
```

### 方位怎么写

| ❌ 反打会翻车 | ✅ 稳定 |
|---|---|
| 左侧一扇大窗 | 窗在书柜墙靠门一端 |
| 左后角有扇门 | 北门通走廊，门正对办公桌 |

**人会靠坐的固定物必须写高度**，否则各镜台面落在人身上不同位置。

## 道具条目

```markdown
## 道具 · 〔黑卡〕

- 外观锚点：〔哑光黑色金属卡片，边缘镶碎钻，卡面中央一枚银色家徽（双环内含一柄短剑）。〕
- 尺寸基准：〔标准银行卡大小。〕
- 状态：〔EP001-SC005 首次出现，由老管家双手呈上。〕
- 连续性锁：LOCK-〔BLACKCARD〕《〔哑光黑色金属卡片〕》（镜头：〔SHOT-EP001-018〕）
```

**只给关键道具建条目**：承担叙事功能、跨镜出现、有状态变化。场景固定陈设不建。

## 时代锚点（古装 / 年代戏才写）

```markdown
## 时代锚点 · 〔架空古风（唐制参考）〕

- 必须在场：〔直棂窗、素面青砖、烛台、漆器、竹简或纸卷〕
- 禁止出现：〔玻璃窗、电灯、塑料、拉链、纽扣（用系带）、现代印刷字体、水泥〕
- 材质基调：〔木、石、丝、麻、陶、铜〕
- 光线来源：〔烛、油灯、天光、月光——无电光源〕
```

**「光线来源」最容易被忘。** 古装戏里出现一束方向明确的冷白光，就是电灯——观众说不清哪不对，但立刻出戏。

## 连续性锁语法

```
LOCK-<标识>《<锁面>》（镜头：<范围>[；图片提示词项：<IMG-...>]）
```

| 部分 | 规则 |
|---|---|
| `LOCK-` 标识 | 本集唯一，大写 + 连字符 |
| **锁面** | **最小名词短语**，不含标点、动作、剧情。写「左眉尾浅疤」，不写「左眉尾有一道刀划的浅疤」 |
| 镜头范围 | `入画`（所有含该条目的镜头）/ `全集` / `SHOT-...` 逗号分隔列表 |
| 图片提示词项 | 可选，指向 `IMG-...` |

### 什么该上锁

| 上锁 | 不上锁 |
|---|---|
| 服装主色与形制 | 衣服褶皱方向 |
| 发型长度与颜色 | 被风吹起的发丝 |
| 伤口位置与形态 | 伤口渗血多少 |
| 道具颜色与材质 | 道具表面反光 |
| 永久配饰 | 临时手持物 |

**判据**：跨镜不变吗？变了会让观众觉得「不是同一个人/同一件东西」吗？两个都「是」才上锁。

## 完整示例（片段）

```markdown
# 视觉设定 · 清算日

## 人物 · 沈惊歌
- 识别锚点：24岁东亚女性，鹅蛋脸，眼尾上挑，左眉尾一道浅疤，锁骨下方一颗小痣，身形偏瘦。
- 画面代称：ShenJingge、沈惊歌
- 声音：烟熏嗓，语速偏慢，句尾下沉，每个字都咬得极重。
- 本集造型：见「造型 · 沈惊歌-破产日」
- 状态变化：EP001-SC003 后右手掌心有指甲掐出的血痕。
- 连续性锁：LOCK-SHEN-SCAR《左眉尾浅疤》（镜头：SHOT-EP001-005、SHOT-EP001-011）

## 造型 · 沈惊歌-破产日
- 身份：沈惊歌
- 适用：EP001-SC001 至 EP001-SC005
- 锁定：灰白色旧真丝衬衫，右袖口一处勾丝；黑色直筒西裤；裸色平底鞋。
- 配饰：左手无名指一枚素圈，已褪色。

## 地点 · 顾氏总裁办
- 空间锚点：南向落地窗在画面东；深色实木长桌居中，桌后一把高背皮椅；
  左侧一排低矮书架；门在北墙偏左。
- 光线变体：
  - 夜景（主）：仅台灯与窗外城市灯，暖黄主光来自桌面右侧，光比约 1:5。
- 连续性锁：LOCK-OFFICE-DESK《深色实木长桌》（镜头：SHOT-EP001-003、SHOT-EP001-007）
```
